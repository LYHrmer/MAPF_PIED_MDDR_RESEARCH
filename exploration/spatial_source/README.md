# 当前主线的显式仿真来源

本模块服务固定路径、固定次序的空间占用研究。`model.py` 给出理想单轮车的闭式梯形速度原语，SI 单位，车身与 S1 一致；不来自 LIMO 或旧拖车标定，不采样概率分布。

首轮：`Initial` 限定沿程 ±.02 m、横向 ±.01 m、朝向 ±.002 rad，任务内定位偏置每轴 ±.01 m；速度 .5 m/s、加减速 1 m/s²，路长 [.25,3] m，只支持东行或北行，无倒车。未满足条件直接拒绝。零输入 WAIT/HOLD 保留实际残差；不重置状态。

连续界由 `|sin ψ|≤|ψ|`、`1−cos ψ≤ψ²/2` 得到，三米沿程 .020006 m、横向 .016 m，S1 保守使用 .03/.02 m。闭式探针只核对接口和单位，不用采样最大值证明整窗覆盖。当前模型没有待学习的未知动力学。

返回的 `sensor` 仅含任务、机器人、动作、条件、capture 与定位输出；`evaluation` 单独含同时刻参考/真实姿态、观测、控制、速度及两类误差。中心仅接收前者。R1 联合检查覆盖加速、巡航、制动、等待、驻留、残差保持及变速拒绝；无 world 时间推进，无任务数据集。

共同验收入口位于执行分支 `exploration/spatial_constraints_s1_20261016/verify_integration.py`。本模块保持一个目录，后续轮次原地迭代；历史版本由 Git 提交保留。G2c 两次失败与未授权短 IPC 清单不变，也不作为本模块的运行许可。

第二轮：新增 `Envelope`、连续直行传播、停稳 90° 转向后坐标投影与永久驻留条件。最坏初态经过三米直行后界为 (.020006,.016,.002)，转向后为 (.016,.020006,.002)，其横向已超过下一直行允许的 .01 m，因此拒绝直接拼接。该失败不代表所有多转弯控制器不可行，只说明当前原语适用集不封闭；禁止在路点清零残差。移动中转向和非零永久漂移也拒绝。若需要多转弯任务，应先设计并验收闭环原语/较大传播界，不静默沿用首段界。
