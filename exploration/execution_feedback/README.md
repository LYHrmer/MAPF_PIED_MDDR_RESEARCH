# 当前主线的公共反馈与配对工具

本目录只服务合法观测、事件日志、配对比较及费用，不开展“查询谁”或旧查询学习。复用 L17 `execution_receipt.py` 的来源绑定、精确字段、拒绝回退和单位区分原则；旧协议/授权和冻结实现不修改。新协议不与旧 END-only 协议混称。

R1：`protocol.py` 将公开定位观测绑定 task/robot/action/condition/不可撤销后缀承诺，生产带 seq、capture、delivery 的包。`Inbox` 拒绝未交付、重放/倒序、错误任务或条件、擅自缩界；记录消息数和规范序列化字节数。各对照收到同一包字节，各自独立收件。包不包含参考位置、真实位置或名义释放时刻。

Producer 的身份是可信仿真进程内的对象/合同绑定，并非网络密码认证；主机恶意伪造不在本例威胁模型内。中心接口不接收真值，并不单独证明整个仿真进程的信息隔离，联合执行时还需分别记录两条输出通道。

共同验收由执行分支 `exploration/spatial_constraints_s1_20261016/verify_integration.py` 调用。新协议初始仅生产 PROGRESS_BOUND；完整 END 及端到端计量在下一轮补入。旧学习代码已退出当前 Git 列表，历史与本机原路径保留。
