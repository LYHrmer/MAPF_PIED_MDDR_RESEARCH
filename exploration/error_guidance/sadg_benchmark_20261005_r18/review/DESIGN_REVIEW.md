# R18 independent design and execution review

Status: CONDITIONAL exploration. The author SADG core has a verified R0 and R16/R17 mechanisms, but a multi-map learned information-value claim remains to be tested. This review concerns the new standard-map benchmark only. It does not modify the author engine, policies or datasets and launches no native or solver episode. Source basis is the clean author checkout `c2626d996121a9d6c128844a167b917db24418ac`, the R16 isolated compiler/all-head guard, and R17 complete-history/shift evidence.

## Immediate execution gates

1. **Empty stationary plan.** Author `compiler.compile_sadg` emits a vertex only when locations differ; start=goal or all-WAIT paths therefore produce empty vertex lists. Author `get_first_agent_vertex()[0]` and the optimizer's `vertices[-1]` cannot handle these. A named common resident adapter may remove such agents from the optimization arrays only while retaining their full-horizon physical occupancy. Every other route must avoid that permanent cell; no invented zero-distance MOVE or erased agent is acceptable.
2. **Initial, interior and terminal residence.** Leading/interior duplicate ECBS positions are accumulated into the next movement vertex; `Vertex._update` estimates duration from distance/2 and does not preserve ECBS wait duration. This is author schedule resynthesis, not execution of ECBS timestamps. The actual trace must cover initial HOLD, dependency WAIT, disturbance stalls, every movement segment, and terminal GOAL_HOLD through a common horizon. A path ending on another agent's route needs its original nonswitchable last-visit protection.
3. **Current cursor enforces type 1.** Author `Vertex.can_execute` checks active type-2 dependencies only. Type-1 order must be maintained by one current vertex per agent and `get_next`; iterating over every STAGED vertex can launch later actions illegally. At most one active MOVE per agent is required.
4. **Compiler/group repairs are common.** Preserve the explicit k=0 reverse exclusion and require every forward/reverse group's head to be STAGED before switching. Cached first-head eligibility alone is insufficient, as R16's counterexamples establish. All policy arms use the same registered adapter and author optimizer.
5. **Adoption is transactional.** Save all group directions/statuses before optimization. A solver failure, infeasible/no incumbent result, invalid cycle, changed committed incoming relation, incomplete relation family or unsafe visit order must cause restoration of the entire parent graph. No partial switches may survive a rejected candidate. Do not silently retry for a better optimum; record status, time limit, gap/bound, actual work and fallback.
6. **The author geometry is point based.** `core.geometry.intersects` is equality of locations. Full-time continuous point separation and map-valid paths must be independently checked; that does not imply nonzero-footprint, acceleration or real robot safety. Any larger-body claim needs an explicit added geometry contract shared by all arms.
7. **No phantom completion.** Final path completion is an actual endpoint event, never an optimizer goal-time prediction. Include failed/unfinished episodes and missing gates in denominators. A stationary resident is complete at its initial goal under the declared task convention but remains physically present.

Author source entry points: `sadg/compiler.py` (movement-only vertex emission and `vertices_i[k-1]`), `sadg/vertex.py` (`can_execute`, `get_next`, distance-only duration, progress stub), `sadg/dependency_group.py` (cached first-head switchability), and `sadg/sadg.py` (boundaries, unconditional optimizer result consumption and direction changes). These code facts are distinct from claims about the paper's theorem.

## Common public information and strongest simple rule

Use the frozen `PUBLIC_SCHEMA.json`. Features may use public clock/current occurrence/START, delivered END duration histories, previously delivered POSITION and its capture age, remaining budget, public graph relations, revealed route lengths, and candidate age. Exclude case/map identifier, split, seed, disturbance name, private profile, true current progress, future stall/recovery, completion heap and realized counterfactual outcomes.

The same complete-history estimator must serve every arm: per agent, public duration ratio = sum completed MOVE durations / sum corresponding original nominal durations, prior 1 if absent. Dependency WAIT before START does not count as the MOVE duration; a real pause during a MOVE does. Publish precisely whether CV divides the unweighted per-MOVE mean ratio or the weighted history ratio, and use the same convention in model and rule. Zero nominal-duration objects cannot enter this estimator.

A useful strong comparator scores an active candidate by public downstream impact times residual uncertainty, instead of querying only the oldest or regressing a hidden disturbance class. A concrete suggested score is

`blocked_agents * min(remaining_estimate, nominal_duration * max(0.25, history_cv) * max(1, history_ratio)) * (1 + min(2, downstream_nominal / nominal_duration)) / (1 + measurement_count)`.

The 0.25 floor is a declared prior for new history mismatch, not an observed-condition switch. Supplement with current elapsed / predicted duration, number of history samples, current measurement age and upcoming switchable influence. Stable complete history alone need not reveal a new pause; absence of an END can inform current duration only under the declared END delivery semantics. These are proposed features/rules for root to freeze, not claims of optimality. Any cooldown or eligibility restriction must be common to all budgeted methods if used to define their action space. A rule-specific cooldown can instead remain an explicitly named policy behavior.

For the model, include the same original public fields and a small fixed set of interactions such as `blocked_agents × residual_uncertainty`, `upcoming_switchable_influence × residual_uncertainty`, `elapsed / predicted_duration`, history sample confidence, measurement age / nominal duration, and remaining budget. A small ridge or shallow value tree is adequate. The target is complete-episode consequence, not private speed/pause labels. Report its comparison with the strongest simple history rule even if that rule wins. Raw query cost and solver work remain separate objectives; do not select a time-per-query price after seeing results.

## Matched full-episode value labels

At a preselected public gate, branch between querying one publicly selected eligible active occurrence and querying none. Both paths execute from time 0 with the same deterministic history policy before that gate. After the intervention both return to the same budget-aware continuation. The query branch naturally has one less unit of budget; do not compensate it with a free query. Common disturbances must be bound to immutable agent/action occurrence and the registered time coordinate, not to the order of calls to a mutable random generator.

The target is paired final sum-completion difference, with makespan, completed tasks, restricted completion at horizon, total queries and solver calls/work also retained. A positive local progress error correction is not a value label. Disturbance identity/hidden truth is available to the physical executor and offline auditor only; the policy snapshot must be serialized separately and audited before callback.

One unmodified history-policy episode is **not automatically** the no-query outcome at both probe gates. If the history policy would purchase there, the no-query arm requires a genuine `probe_override={gate: []}` full episode. A query arm uses `{gate: [agent]}`. Reuse is allowed only for the identical input, all earlier interventions, full prefix, selected gate/occurrence, continuation policy, budget and disturbance binding. A second probe cannot splice a prefix from a different first-probe intervention. Do not label two locally different solver objectives as a matched causal outcome.

Select probe gates and targets before observing gains: the frozen rule uses history-score top candidate at gate 1 and greatest downstream nominal duration at gate 3, with stable agent-ID tie order. Keep missing gates, no eligible candidate and exhausted-budget cases as explicit no-intervention/missing-label records; do not replace them with responsive cases. If two gates are chosen per each of 54 TRAIN worlds, 108 is the maximum number of pair labels, not a promise of 108 informative independent samples. The runner uses 54 baseline episodes plus at most 216 paired arms before exact reuse, an upper bound of 270 unique full episodes.

## Split, workload and claim boundaries

The proposed 3 map families × N={8,16,32} × scenarios 1..5 uses TRAIN scenarios 1/2, CAL 3, TEST 4/5. Keep all N values, disturbance variants, observation ages, budgets, repeated gates and paired arms of a map/scenario seed family together. Scenario-file numbering alone does not establish start/goal disjointness: retain the official row indices and hash overlap audit. Nested N8/N16/N32 prefixes are correlated scale views, not independent samples. Report paired family/instance results, all three map families and all sizes; do not silently drop hard planner/solver/collision cases.

Freeze the three disturbance mechanisms before running: stable history control, finite local pause, persistent speed shift. Trigger changes after a declared public-history period or immutable action ordinal, with agent selection fixed by input seed; never expose condition names to callbacks. The physical future perturbation and control horizon stay identical across policies even when order changes. If disturbance is defined in wall time, reordering legitimately changes which action encounters it; if defined by action ordinal, retain that distinction in the claim.

The root froze full-episode receding updates: `solve_period=max(4, public ECBS nominal makespan/12)`, horizon 5, with no three-epoch cutoff. This supersedes the reviewer's initial workload-cap suggestion. Realized completion time cannot choose the period. All arms share total budget N and gate cap ceil(N/8), except the explicitly unbudgeted dense reference. Fixed TRAIN probes are zero-based gate indices 1 and 3: highest history score at gate 1, greatest downstream nominal duration at gate 3, then agent_id ties. Every arm reaches the same scheduled optimization clock and query latency; END continues during latency, and a reply for a completed/changed occurrence is discarded without resetting active successor progress.

All budgeted policies share total query budget, per-gate cap, delivery latency, same solver/guard and scheduled solves. Charge every captured query even if stale or unhelpful, unless the registered API explicitly bills a different event. A dense unbudgeted POSITION reference is an information upper reference, not a fair equal-budget learned-policy baseline. An equal-budget periodic/round-robin query rule and complete-history no-query baseline should remain visible. Solver time is recorded rather than treated as free, and any extra decision-time solves required by a policy must be counted.

The frozen implementation uses 22 public features and family-weighted ridge, choosing alpha in {1,10,100} by TRAIN leave-one-map/scenario-family-out mean MSE. Standardization is fitted inside each training fold; final model uses all TRAIN. The same CV selects alpha, so its selected scores are model-selection diagnostics, not nested unbiased policy generalization. CAL is diagnostic only and cannot tune any parameter. Threshold is fixed at predicted value >1e-8 before CAL/TEST. A failure of learned value to beat a rule is a valid result and does not authorize changing thresholds or adding test-derived training labels. Avoid calling fixed-path finite-goal throughput “lifelong MAPF” unless the benchmark actually introduces and completes a public task stream.

Single-query training labels estimate an intervention under the fixed history-rule continuation. Deployed learned decisions change later continuation and may buy multiple queries per gate (2/4 for N16/32). Those batch interactions are not identified by adding single-query predictions. This is an explicit value-learning heuristic whose actual full-episode CAL/TEST executions must establish its performance; paired-label regression metrics alone do not. Deterministic public candidate selection also limits training support to the registered probe targets.

## Independent execution audit planned

The verifier will read immutable map/ECBS path, compiled graph, every query snapshot/capture/delivery, candidate/adopted graph and complete execution trace, plus receipt/source hashes. It will reconstruct:

- map bounds, obstacle legality, cardinal path continuity, initial/terminal identities and stationary residents;
- type-1 cursor order, active type-2 completion-before-start, group reversals and locked occurrences at each adoption;
- continuous piecewise-linear minimum distance across all overlapping MOVE/WAIT/GOAL_HOLD segments, including interior minima, with declared numerical tolerance;
- unique START/END/goal completion, no overlapping moves per agent, complete temporal coverage to common end;
- delivered-history ratios and eligible candidate public features, query cap/budget accounting and stale-discard identity;
- episode and pair input/prefix equality, same disturbance binding, target gate/continuation and complete-outcome labels;
- all logs/receipts/source pins, solver failures/fallbacks, duplicate keys, grouped split membership and model-freeze chronology.

The raw schema and engine interface will be read before implementation. The review may inspect archived artifacts and recompute mathematics, but will not run a duplicate physical episode or author solve. Raw observations, source-enforced semantics and untested assumptions will be labelled separately.
