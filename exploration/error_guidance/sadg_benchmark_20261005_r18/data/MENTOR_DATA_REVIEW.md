# R18 数据与原生路径资格复核

结论：本轮达到标准地图初始路径数据的 R0 可执行、可追溯资格，允许后续在共同初始路径上比较固定更新、历史规则和学习查询。尚不能据此评价 SADG 连续执行安全、恢复效率或查询收益。

本评审由数据实现者完成，是相对于作者 ECBS 的独立几何/时序验证，不是盲评或独立人员认证。根代理另行负责方法和全链审计。

事前登记固定了三个地图、每图五个官方随机场景、8/16/32 三种规模及 TRAIN/CAL/TEST 划分。登记文件早于所有求解收据；45 次原生尝试均保留，没有因结果选择地图、替换超时实例或反复求解。全体使用同一未改作者二进制、w=1.5 和相同资源上限。结果为 45/45 离散有效，累计包装器计时 6.2684 秒，最慢 0.8670 秒。该计时只证明当前准备规模可行。

准备脚本逐行保留官方场景前 N 个起终点，保持 x=列、y=行，不根据路径长短重排代理。正式地图中的 T 是不可通行树木，@ 是界外；脚本对其他未识别地形拒绝继续。准备时发现 T 后显式修正解析器，此时尚未开始任何路径求解，没有修改地图或场景。首次沙箱 DNS 失败后按授权获取相同固定官方来源；这些属于输入准备，不是隐藏的求解尝试。

独立检查直接重新读取官方地图和场景，不以转换后的 YAML 作为唯一真值。原始 YAML、全部计划状态、官方起终点、障碍集合和坐标范围交叉一致。每个状态时间是整数并从 0 连续增加；每步是等待或单元四邻移动。联合时域逐时检查顶点冲突和对向边交换，短路径在最后目标无限保持。检查显式走到 H+1，并确认最终目标各不相同，因而之后静止尾段不会新生冲突。审计脚本还核对原生统计 cost/makespan 与路径长度，十个合成挑战覆盖合法保持以及交换、到达后占用、非法时间、起终点、步长、边界和障碍等拒绝情况。

保持在证据允许范围内的解释：

- 三个显示地图族各只有一张图，warehouse 在本规模下较稀疏；不能宣称覆盖所有地图拓扑、拥挤度或百机器人场景。
- 各场景的 8/16/32 代理是嵌套前缀。统计配对块应为 map_name + scenario_id；family 字段只是 random/maze/warehouse 显示标签。
- TEST 初始路径可用性检查只用于准备共同输入；策略选择、阈值和模型仍必须在 TEST 执行结果揭示前冻结。
- ECBS 的 w=1.5 是事前指定的作者算法参数，不等同于本轮另做了最优成本证明。
- 离散无碰撞不自动推出未经检查的连续插值或 SADG 重排序安全；坐标变换 (2y,-2x)、作者编译器适配、执行 guard 和目标保持需要后续执行链单独验证。
- 数据来源页面未确认独立的地图许可，不能把作者软件许可证扩大到 MovingAI 数据。发布包保留来源和原始许可文件，公开发布前仍须核实数据条款。

后续最有信息量的工作是同一真实执行状态上的完整后缀比较与扰动下全体任务结果。无需为这些已经有效的共同初始路径重新求解或优化初始化。
