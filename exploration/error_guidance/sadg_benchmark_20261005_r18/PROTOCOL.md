# R18：标准地图上的 SADG 信息获取实验

## 问题、身份和完成要求

本轮承接用户的明确目标：把 SADG/误差方向扩到标准地图、多规模、扰动，并实际比较固定更新、完整历史规则、学习查询。已有 R17 两车例只提供机制动机，不充当新测试数据。

SADG 保留固定路径，通过原作者混合整数优化器切换可切换的依赖顺序。本文只改变公开进度预测所需信息的获取决策；所有实验臂使用同一作者优化器、承诺约束和执行器。新观测不能直接更改物理位置、当前动作承诺或未来扰动。

来源：作者论文 <https://arxiv.org/html/2312.04190v1>；作者工件 <https://github.com/alexberndt/sadg-controller>，固定 `c2626d996121a9d6c128844a167b917db24418ac`；MovingAI MAPF benchmark <https://movingai.com/benchmarks/mapf/index.html>。原优化器不改；R16 已公开的 k0 和 all-heads 编译/承诺修正由全部实验臂共用，不能把它们的效果算作学习收益。

科研导师资格卡：问题合同、已发表锚点、官方核心工件、公开基线身份均 PASS，证据在 R16/R17 与本轮作者源码核验。标准数据计划和公开来源 PASS；本轮大规模可执行性及正式外推证据在实际运行前 UNKNOWN。继续进行已经授权的隔离探索，不预称正式选题或投稿证据已通过。

本轮完成需要：标准地图/场景文件及作者路径生成可追溯；至少三地图族和 8/16/32 规模的登记结果（含失败）；三扰动条件的全程执行；真实训练并冻结的查询模型；独立测试中全部对照的实际完整输出；输入/承诺/连续轨迹/费用计数/模型隔离独立核验；汇总表、可视化和全部可复现命令。模型取得正收益不是完成条件，隐去负结果不允许。

## 数据和隔离

固定地图 `random-32-32-10`、`maze-32-32-2`、`warehouse-10-20-10-2-1`。各取官方 random 场景文件 1–5 的前 N 项，N 为 8、16、32，共 45 路径集。场景 1/2 为 TRAIN，3 为 CAL，4/5 为 TEST。同地图、同场景下不同 N 的前缀嵌套，所有扰动与预算版本均属于同一任务族，不作为独立样本或跨集合拆分。

原作者依赖的 libMultiRobotPlanning ECBS 使用统一 `w=1.5`、30 秒 wall timeout、单 solver worker；未改变其搜索算法。初始路径所有方法共享。超时或非法路径保留为规划失败，不能按实验结果补选场景。地图、场景原始文件、命令、版本和离散顶点/交换/障碍/起终点/终点驻留校验由 data/ 工件记录。

不把新模型拿到 TEST 上调参。不读取旧项目 TEST 的结果来训练本轮模型。CAL 仅用于冻结模型的开发诊断；本轮阈值与正则选择均在 TRAIN 固定规则内完成。不同地图类型均出现在训练与测试，结果只支持新场景泛化，不能宣称整类未见地图泛化。

## 共同执行和扰动

全路径用连续分段运动执行；原计划等待可由依赖等待实现，但必须记录实际初始 HOLD、MOVE、扰动停顿、等待和终点 GOAL_HOLD。每个机器人仅当前 cursor 动作可启动。原图和每个候选均保持 DAG 与当前 IN_PROGRESS 承诺；求解失败或非法图回退父图并记录，不删除该 episode。

三组扰动为 stable、bounded_pause、speed_shift。真实扰动由固定种子、agent 和动作 ordinal 确定，不能用策略或执行先后顺序来重新抽样；各策略共享同一潜在物理世界。具体幅度与触发方式由 `EXPERIMENT_REGISTRATION.json` 在科学运行前冻结。完整原始扰动日志只属于执行器和审计器，policy 输入仅有 `PUBLIC_SCHEMA.json` 的字段。

公共时长模型用全部已交付 END 的真实运动时长与原名义时长之比，缺历史时 prior=1。观察年龄通过公开速率模型投影，只影响优化估计，不是控制器安全证书。查询只捕获指定的当前动作；捕获后仍真实执行，固定延迟 0.25 到达。到达时若 occurrence 已结束，记录过期，不把旧信息安装到后继动作。

固定原作者 horizon=5。每个实例的更新周期由公开 ECBS 名义 makespan 决定：`max(4, nominal_makespan / 12)`，所有方法完全一致，并持续至 episode 结束。每次 gate 先形成公共快照并选择查询，在相同的 gate+latency 时刻求解；没有查询的臂也沿用相同时钟。模拟时间不伪装为实际在线求解用时，全部 solver wall time 单独报告。

预算臂总预算 N，每个 gate 最多 ceil(N/8) 个 active 机器人观测。Dense-position 参考每 gate 查询全部 active，明确不受同预算约束，只比较信息充分时的作者方法后果，不称公平预算优势。完成时间均由执行日志重建，所有未完成任务纳入统一时域 H 的受限完成时间和。

## 对照与学习

1. `history_only`：原作者 SADG 优化器，公共全历史预测，零额外 POSITION。
2. `fixed_update`：相同作者优化器，每 gate 固定循环扫描机器人，受共同预算/数量限制。
3. `history_rule`：相同作者优化器，按公共时长不确定性、阻塞影响、观测年龄与下游工作量选择；固定 0.25 失配 floor，避免完整历史方差零时永不查询。
4. `learned_query`：相同作者优化器，以实际配对完整后果训练查询价值回归，选择预测正收益的候选，受完全相同预算限制。
5. `dense_position`：相同作者优化器和公共历史时长模型，每 gate 全量观测，作为有额外信息成本的原方法参考。

作者 SADG 是共同的已发表算法底座；固定、历史规则和学习查询是其信息策略对照，不把内部规则单独包装成发表基线。

训练收集固定公开 gate index 1 与 3。gate 1 候选为最高历史规则得分；gate 3 候选为最多下游名义工作量；同分按 agent_id 排序，不看真实扰动或后验收益。缺 gate、无 active 或预算不足记录缺失，不挑新的“有收益”gate 替补。两臂分别实际执行该 gate 空查询和单目标查询，其他 gate 沿用相同历史规则；购买后的剩余预算自然不同。不能把原历史策略的有查询尾误当无查询尾。

标签为 `restricted_sum(noquery) - restricted_sum(query)`，来自两条合法完整执行日志。同一事件前缀及扰动、后续规则一致。22 个公开特征定义在 `policies.py`，没有 map ID、场景、私有速度或扰动标签。ridge 的标准化与样本权重只用对应训练折；按 map/scenario 族留一选择 alpha ∈ {1,10,100}，每族等权，MSE 相同时选更小 alpha。最终使用全部 TRAIN 拟合并在 CAL/TEST 执行之前保存 hash；查询阈值固定为预测收益 > 1e-8，不根据 CAL/TEST 再调。

单目标标签的后续策略是历史规则，而部署后的后续策略是模型，并且一个 gate 可同时选多个目标；存在后续策略变化和批次互作。不能把各目标预测值相加当作已验证的批次因果收益，结论取自新 TEST 的真实完整执行。用于选择 alpha 的 TRAIN 留一误差是调参诊断，不冒充嵌套无偏泛化成绩。两臂发生碰撞、死锁或代码异常的配对保留但不进入合法价值标签；登记时域内合法未完成以共同 H 删失。

## 缓存、统计和审计

同一完整作者输入、版本、图状态与预测内容可以复用作者求解，必须保存完整内容键和来源。不能只按场景名/最后图相同推断同输入。复用记录同时报告原调用参考用时与本轮新增用时；后跑的策略不能因命中缓存被宣称更快。完整物理轨迹只有同输入、扰动、策略、代码和结果 hash 一致才可复用，不重复运行已有有效 episode。

主指标：完成机器人/任务数、固定任务集受限完成时间和、全部完成时 makespan。并列报告查询数量/过期率、求解次数/求解状态/参考与新增 wall time、非法候选/死锁/碰撞/超时。不同量纲不在看到结果后任意换算成单分数。

逐任务族报告配对差，并按 map/scenario 族做重采样不确定性；同族的规模/扰动不能充作独立重复。缺少有效配对、规划失败、执行失败和训练 gate 缺失分别报告完整分母。

独立核验需覆盖起终点驻留及 MOVE/WAIT 全时域，逐对连续距离而非只看采样帧；状态/END 只完成一次，type1/type2 依赖满足，已启动动作不被重排，观测捕获前缀正确且私有字段不进入 policy，预算和计数一致。点机器人结果不能宣称非零足迹或真实控制器保证。本轮是标准 MAPF 固定路径执行，不改名为已经完成开放 LMAPF。
