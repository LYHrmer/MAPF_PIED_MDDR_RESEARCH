# 空间误差约束下的路径引导探索

分支 `explore/error-aware-guidance`，起点 `main@af17410`。本目录研究：在固定足迹和空间误差安全层不变时，学习预测占用或等待代价能否帮助 lifelong MAPF 选择路径。首先验证路径选择确有可利用的误差相关差异，再决定是否训练模型。

首个有限预检已实际通过：**790 项断言，严格编译和运行均退出 0**。同起终点的两条路径在零误差与非零误差盒下都可组件执行，但等待造成的到达时间排序反转。没有训练模型、运行 lifelong 任务流或完成生产费用链。

| 空间误差盒半宽 | 上绕路径到达时间 | 下绕路径到达时间 | 较早到达 |
| --- | ---: | ---: | --- |
| 0 | `4√3 ≈ 6.928204` | `2√3 + 2√6 ≈ 8.363081` | 上绕 |
| 1/5 | `4 + 3√3 ≈ 9.196152` | `2√3 + 2√6 ≈ 8.363081` | 下绕 |

所有决策和断言都使用 FLINT 实代数数精确比较；表中小数仅供阅读。程序输出精确向外包围区间，没有将代数数静默转为浮点后判安全。

上绕路径是 `(0,0) → (0,1) → (4,1) → (4,0)`；下绕为 `(0,0) → (0,−2) → (4,−2) → (4,0)`。另一个机器人固定沿 `(2,3/2) → (8,3/2)` 运动。每个误差组的请求者和阻塞者都使用该组相同误差盒 Z。四种组合使用同一足迹、资源划分、控制参数、阻塞机器人轨迹，以及同一个预定 `t=4` 观察机会；每种组合都提交这一次观察，包含没有等待的组合。只有误差半宽为 1/5 的上绕路径被真实几何责任阻塞，在第二段开始前等待 `4−√3`，退休阈值由真实 Index 得到 `61/20`。

这是一份**离线配对的有限参考潜力预检**。反转是误差包络、固定观察策略与保守准入规则共同产生的条件结果；更早观察可能恢复上绕优势，不代表任何观察策略都会反转。两条路线由人工预定，其合法性不表示在线规划器能自动选择它们。比较使用实际执行后的结果，未将结果冒充在线可用信息；它不是全局最优 oracle，也不证明学习有用。下一步优先对照观察时机与几何间隙/误差盒变化。完整前提、失败标准和与既有工作的区别见 [研究合同](RESEARCH_CONTRACT.md)。
