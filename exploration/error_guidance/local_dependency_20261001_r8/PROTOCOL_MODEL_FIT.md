# R8 two-step buffer execution protocol

Exploratory isolated prototype. No original author method or old frozen package is changed. The original S1 no-MOVE-merge controller and normal ACK/STATION semantics are shared. At an actual joint-settled boundary, two calls to persistent official OBJ3 planning create a two-step joint path under the same public current task head. The second call uses the first public planned frontier; it is not a measured physical state or completed transition. Original algorithm objects are retained for hm; candidate search uses the frozen R7 nonnegative edge overlay and ridge checkpoint. Neither adapter records virtual transitions as completed physical traffic. OBJ3 with input_type=flow is mandatory.

Each current task is annotated once at the first occurrence of its goal, including the initial point if already there. No future head is exposed until normal STATION END is processed at the next batch boundary. The original multi-point parser is used without edits. Each complete batch executes before the next planning request. Local execution uses unchanged ADG admission, type-2 edges and ACK updates. Global execution additionally blocks all parsed actions with logical time >=1 while any time-0 action from that batch remains uncompleted. It is an internal extra-gate ablation and is not the old one-step joint-settled benchmark. Both execute the same two-step buffer contract; neither rewrites any in-flight action.

Mechanical phase: 4 agents on an 8x8 empty constructed map, independent trajectories and a following dependency; nominal and original active-MOVE pause (20 ticks), global/local. Two steps are identical registered paths across arms. Require original normal predecessor ACK before dependent admission, independent second-step execution before paused first-step END, exactly once service, point endpoint and sampled geometry consistency. Preserve failures.

Evaluation after mechanical pass: empty-32-32 and random-32-32-10; 8 robots; two new task seeds 941821,941822; nominal and axis execution error; global/local × hm/history/learned =48 native runs, each4000 ticks at10Hz. Public scenario starts are inherited, complete fresh1002-item per-agent FIFO lists are generated before runs, identical within world. Model/scale/calibration margins are copied unchanged from R7. No new training or test tuning. The R7 label/feature convention is preserved and model transfer across buffer duration-label change must be reported as a limitation.

Primary outcome: normal STATION END count at4000. Secondary: sum over the first10 registered FIFO tasks per agent of min(normal service END,4000), service differences on common FIFO identities, action difference, normal-ACK dependency waits and extra global gate waits, public prediction error and computation time. Fixed FIFO metric avoids policy-dependent task-release denominator. Unknown or negative performance remains a valid result. Tests have four independent map/task families, with paired conditions; do not treat48arms as independent worlds or claim general superiority.

Model histories accept only delivered view, proposal, admit, normal END, drop private pose/control fields. A supervised row is identified by (proposal_id,agent,logical_step), with features frozen before either step executes and final MOVE node bound by public admission. Duration is batch proposal to that step's final MOVE normal END, not a private motor error or isolated step duration. An additional per-step execution duration may be reported descriptively using previous-step END, but is not fed into the frozen R7 predictor. The changed second-step duration target is reported separately.

## Pre-test orientation correction and refit (before any48test)

Source audit found public LSMART orientation E,N,W,S differs from planner action E,S,W,N. The R7 quarter-turn feature compared them without conversion. R8 explicitly maps public orientation to action orientation before turn distance, and reconstructs all historical features and residuals causally from the original R7 12train+6cal public event streams. Refit lambda1 ridge with unpenalized intercept and original train-only standardization; recalculate separate history/learned calibration90percent absolute margins on original6cal only. No R7test data are loaded; no R8test has run. Old model retained as model_r7_transfer_diagnostic.json. New corrected checkpoint supersedes earlier direct-checkpoint reuse language. This is same-source-data semantic correction, not new native training evidence. Buffer second-step duration domain shift remains, and is reported separately.
