# Source, license, public information and scope

The author method is [Speedup Techniques for Switchable Temporal Plan Graph Optimization](https://ojs.aaai.org/index.php/AAAI/article/view/34487), He Jiang, Muhan Lin and Jiaoyang Li, AAAI 2025, DOI10.1609/aaai.v39i22.34487. The publisher page and [fixed official README](https://raw.githubusercontent.com/DiligentPanda/STPG/25fb931eff03f1cce23a22a68ab42b7533f85ab3/README.md) were read again for R13 on2026-10-04. The GitHub directory-page fetch returned a cache error; the raw official file was available. No unverified literature claim is substituted for it.

Upstream repository: https://github.com/DiligentPanda/STPG ; commit25fb931eff03f1cce23a22a68ab42b7533f85ab3. MIT license is retained verbatim in AUTHOR_LICENSE.txt. AUTHOR_SOURCE.json pins the same43 compilation/header inputs verified in frozen R9/R10; all are unchanged. Its inherited adapter_before_build field is historical R10 provenance; R13 adapters are pinned by REGISTRATION.json.source_pins. AUTHOR_SOURCES.tar.gz retains these files for an offline rebuild. This is the minimal previously audited compilation subset, not a claim of archiving the full upstream repository/submodules or its entire experiment dataset.

author_online.cpp is a new research JSON/Graph adapter to the original Astar, Graph, grouping and heuristic implementation. It imports the suffix edges and actual checkpoint states, with public nominal weights, and records the original author solver's returned graph. It is not the original CLI and is not a self-written substitute for GSES. GSES and Improved GSES retain their R10 search settings, fixed16s timeout and deterministic seed10. Group construction and search wallclock are separate metadata.

executor.py is a byte-identical local copy of frozen R11. online.py supplies checkpoint capture, public serialization, suffix lifting, the commitment guard and actual live dependency replacement. audit_events.py is the R11 independent event/resource audit extended to change its expected dependency map at the recorded adoption boundary; it does not import the executor, but is maintained by this implementation agent. The root's continuous/geometric and commitment audit is independent and separately reported. My mentor pre/post assessments are nonblind because I implement this line after making the preliminary judgment.

The source instances are two reused author R10 original exports: random-32-32-10 N60 and warehouse-10-20-10-2-1 N110, instance1/situation0. REGISTRATION.json pins their archive paths/hashes. Every full original graph is also present in this package's original trace, so checkpoint continuation and independent resource checks can replay offline without those external absolute paths. The public graph message preserves full author paths and identifiers; existing edges rather than synthesized path conflicts define every reversible family.

At the checkpoint, actual ARRIVE states, controller action identities, present reservations and footprint cells are declared public in this finite interface. This is not a demonstration that obtaining those observations is free under the main line's paid-information contract. The optimizer receives no private simulator event heap, future segments, true movement residuals, profile identifier or future pauses. Known original pre-move hold delays remain public; their remaining nominal integer hold can enter author weights. Future unit edge weights are only search estimates and never become execution times.

Virtual time is frozen during each solver transaction. Host computation delay is measured and not inserted into robot motion. Claims exclude real-time asynchronous solver latency, hardware dynamics, original ARGoS feedback-controller equivalence, online task allocation, new paths, lifelong MAPF, learning improvement and heldout author-planner superiority. Failures and signed sum-completion/makespan effects are retained.
