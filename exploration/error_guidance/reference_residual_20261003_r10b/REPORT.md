# R10b：只投影超出训练参考时长的部分，仍无学习吞吐收益

本轮是看到R10负结果后提出、在执行前另行登记的32臂新探索，不与原64臂拼成事前96臂。32臂全部成功完成，结果不支持把这项修正作为学习吞吐提升方法：hm185任务，旧full184，残差history185，残差full182。完成本轮后停止扩量和调参；负结果完整保留。

## 唯一算法变化

原overlay把每个候选parser边的全部TURN、两次半MOVE及到站服务时长投影到其他机器人的目的地代价。新接口仅用 `max(0, predicted_edge_ticks − training_reference_edge_ticks)`，之后仍以原depth2/0.5折扣及0.025系数投影。训练参考为冻结d0 M_first17/M_second17/T9/S20，不冒称真实motor nominal。S20在代数上相消，所有预测等于参考时附加代价严格0，负超额截断为0。

同一R10完整checkpoint逐字节不变；无拟合/校准、λ或深度调整。hm与旧full为同新world上的执行对照，残差history是内部消融。原本地ADG、正常服务、原生控制器及作者OBJ3不改。两图×新种子971041/971042×nominal/axis×四策略，N8/H4000，四个独立map/task family，32臂不是32独立样本。

## 接口实际改变了什么

所有实际候选边都独立核对了 `max(0,pred−reference)`。旧full平均投影48.537235tick/候选边；残差history为4.472703、残差full为5.353325。后两个分别4797/18688与2674/18624个记录候选边投影为0。这里候选边重复出现且不是独立科学样本，数字只说明新算式确实生效。

残差history初次零历史时overlay严格0，没有在tick1就与hm分叉；但后续8条件均有动作变化。残差full在8条件全部于tick1与hm及残差history发生首次动作分叉，此时没有在线完成历史。它仍保留完整模型的离线先验：相对训练中位参考的正偏差在零历史时也可产生代价。因此“只加超额”不等于“只有在线误差才改变决策”，不能把这些首步分叉称在线适应。

S20在实际浮点加总中的去除前后残差最大差7.11e−15tick，属于普通加减舍入；并非额外服务惩罚。预检的全参考/全零超额成本严格为0。原full分支在有非零历史的合成机制输入上与R10公开forecast逐值一致。新公式仍是两步最短路径概率启发项，不是实际占用、拥堵真值或任务价值；减去参考没有使这一启发式自动具备收益保证。

## 核验与封存

32份原ADG/FIFO/公开forecast审计、32份物理包络采样审计全通过，最小中心距0.499340m、最大ACK端点误差0.029774m。独立从原生parsed/admit/END重建43,722个已完成primitive标签，公开特征差0，STATION D恒20；500个删失primitive保留。`INDEPENDENT_FIFO_REPLAY.json`另行重算所有任务和固定FIFO，不导入候选builder。

模型SHA256仍为`9222333ca80d7a2b119a9cd51ddfcb03ce74eabce8f411f2617a549f21819704`；1898个执行冻结项不变。已知本机socket需权限，获权限后原生32臂无启动或运行失败。32个raw包总压缩102,129,777bytes，对应原始1,346,263,702bytes，最大单包3,373,369bytes，每成员均解压核SHA。源码继承、MIT许可证和模型来源见`SOURCE_AND_LICENSE.md`；最终验证与可公开文件清单见`FINAL_VERIFICATION.json`、`PUBLICATION_MEMBERS.json`。

这轮修正使“超额代价”的语义更清楚，却没有救回学习收益。已有ridge可作为监督与执行接口诊断，不宜继续列为论文核心性能贡献。下一研究应先让可学习输出对应一个有真实任务后果的明确选择，例如在固定已承诺路径上对可合法切换的依赖次序或有限候选动作预测同续策任务—成本差；先验证简单对照下决策确有价值，再选择是否需要模型。不能继续依据这批测试寻找更好权重或扩量直到出现正数。
