# R8：近邻正文核查与研究差异

本轮在实施同时读取下列原文相关方法段，而不只依据标题/摘要。状态按当前 arXiv 页面记录为预印本；不把它们伪装为已发表期刊基线，也不据一次检索宣布首次。

|近邻与定位|原文已覆盖的内容|对本项目的约束|
|---|---|---|
|[REMAP / ExecTimeNet / ESADG v2，III–V节](https://arxiv.org/html/2511.21886v2)|将计划的依赖图与机器人动力学参数输入学习模型，预测动作完成状态，用于规划和执行顺序优化。IV-C还用在线贝叶斯回归决定是否调用昂贵预测器。|“学执行时间”“GNN建模依赖”“选择何时调用模型”均不能单独作为本项目新颖性。|
|[Should I Replan?，III-C、IV、VI、VII节](https://arxiv.org/html/2604.25567v1)|从当前ADG的延迟与传播特征回归一次重规划的收益；实验也检查计入规划开销后的结果。未来工作包括连续多次重规划。|“回归延迟收益”“学习重规划时机”“计入计算开销”已有直接近邻。|

以上是原文事实。以下是本项目的研究推断，尚待有效比较验证：更有区分度的对象是**持续任务下，有限且有成本的物理进度证据应向谁、何时取得，以及这些证据怎样改变合法资源释放与后继服务**。调用执行预测器与购买新的物理位置证据是不同决策；需要在问题定义、信息可见性、费用和真实任务结果上把区别做实。

建议统一接口为：公开地图与当前任务头、已承诺路径、已交付END、已购买的进度证书、已发生费用构成策略信息；未公开FIFO、当前私有位姿、将来扰动以及反事实标签仅在离线环境。模型估计的是候选证据相对等待的后继任务价值；资源/空间约束继续由执行机制检查。普通END先到时过期证书必须按生命周期处理，已发生费用仍结清。

本轮三项实现各补这个问题的一部分：主线补普通END和过期费用；查询线补公开分层机会、任务优先标注与共同分段预算；第三线检验两步承诺内的依赖执行能否把预测差异传至任务服务。第三线的两步缓冲和恢复局部执行首先是实验接口改进，单独不宣称新ADG算法。

正式论文仍须以PIE-D、hm+GPIBT、OnlineGGO等可核验作者方法建立同问题对照。若采用上面预印本作直接性能比较，须另核原作者工件、输入信息与执行语义，不能把自写近似冠上论文名。局部机制正例、预测MAE、调用次数与完整任务收益应分列；后两项不能由前两项代替。

这批已发表工作直接说明：传统图算法、时间推理和执行协调仍有研究空间；“不用学习就没有创新”不成立。相反，单加学习预测器也不自动形成贡献。本项目的选择应依据可改变的决策：有限信息下证据分配属于第二线；延迟后的通行顺序优化可作为第三线下一替代方向；两者应各用对应的作者基线，不共用一个人为削弱的全队屏障来论证优势。
