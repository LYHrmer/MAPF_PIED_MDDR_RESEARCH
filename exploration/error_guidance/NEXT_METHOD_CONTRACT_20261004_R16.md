# R16 后继方法合同：把信息价值接到可采用执行后果

这是 R16 结果后的设计，不追称已冻结的新实验，不授权改写旧结果。三条 Git 分支继续保留；科研导师的当前排序是主线闭合接口、第三线扩大合法信息响应、查询线利用已测尾策略。

## 1. 主线：从预览到真实调用入口

下一实现输入只接同一 world、生产者几何、执行 occurrence 的正文与公开时钟。独立验证正文/身份/时效，再产出可用进度区间、剩余距离外包、资源需求候选；估计 ETA 与认证几何分开。没有正速度下界时 ETA 上界保持未知，不能用模型的均值或分位数替代安全凭据。

将新 consumer 插入已存在的付费 POSITION 成功消费之后、原候选承诺之前。先用现有真实长例的同一几何运行一个新适配 smoke，核绑定、边界、原 live root 的候选改变以及旧的 AUTH/RUN/END/服务/结账，而非重新跑十二臂。对输入、代码和真实提交增加新的执行内容键，适配确有改变才新增执行。

验收产物为一条逐事件可追踪的 receipt：SOURCE 正文 hash→当前 occurrence→资源/顺序候选→guard→实际提交→原 RUN 与服务→按账户费用。费用先按原量纲分别报告，不能拿查询次数替代工作步，也不能把账户 0/1/3 之和解释成因果 marginal cost。跨主线与第三线之前必须统一实际 world/几何，不能移植不同实验的证书身份。

## 2. 查询线：先学可测价值与预算取舍

现有动作库固定为 C、LD、STOP 三种完整续策。单次 gate 的价值标签必须来自相同 prefix，后继行为完整登记。模型输出任务差和固定 FIFO 时间差，并另记查询/计算代价；先按预算约束或 Pareto 比较，不在看到结果后挑一个加权和。

新模型的训练先限于既有 TRAIN，按 family 分组验证，预算对视为同组。强规则至少包含完整公共历史、固定 C、固定 LD、固定 STOP 和由 TRAIN 预先确定的简单时间/预算门槛。R16 的 CAL 已用于本次判断，不再作为新方法最终 TEST。训练算法的选择与超参需要先在 TRAIN 内固定，再登记新任务族/地图留出。

现有实测有限空间的任务上界只有 1080，对固定 LD1078 的空间很小，加入 STOP 未提高已有上界。下一优先验证是否可在保持任务指标的同时减少信息开销，而不是扩大网络期待吞吐突增。若对同一完整尾的选择已形成确定决策，可按前缀与执行内容键复用结果；真正多次改策、不同预算轨迹才需要新原生。

正式论文要证明模型的增量：同信息、同计算预算、同动作库，超过最强固定/历史规则；仅相对 C 更好不够。查询收益也需区分信息变化和简单提早停买的效应。

## 3. 第三线：连续时间调度与历史失配

保留作者 SADG 原版身份回归；共同执行比较采用明确命名的 k0/承诺适配版，并把相同修补用到所有比较臂。与 GSES 的比较在其可表达共同域内进行，时长量化或其他改变单独列明。原代码 TODO 的 progress stub 仅做身份检查，不能作为性能上的唯一对手。

后继先登记有执行依据的三类条件：稳定速度偏差、已完成历史之后的短暂停滞、速度条件发生转换。所有候选策略共享同一真实扰动；正常 END 历史只由已交付事件产生，POSITION 含真实年龄，任何策略均不能读未来停止时刻或私有 profile。明确登记一个无新增价值的稳定历史控制组，不只保留信息有效场景。

先固定公开历史时长模型，再比较无新测量和同模型加测量；若需要学习，预测的是当前残余/未来执行的条件分布或动作价值，先使用可解释的小模型。合法性由共同承诺 guard 和实际执行层负责。预测区间的校准与安全保证是不同论证，不将经验覆盖率表述为碰撞保证。

预检需记录：连续输入变化、可切换组、候选图差异、guard结果以及求解预算。只有新增可采用图才执行共同后缀；同图同真实状态直接复用。最终比较累计完成时间、makespan、求解延迟、信息开销；固定路径单次执行与持续任务 LMAPF 分开报告。

## 4. 研究资格与投稿证据

候选贡献是“有代价与时效的执行信息，驱动承诺约束下的合法调度”，不是“三个模块加模型”。主线给精确语义和执行链，查询线给信息预算选择，第三线给作者方法和连续时长接口。能否形成单篇论文取决于它们是否在共同域展示同一机制，不能用三个独立试验台的数值拼接一条因果链。

正式实验开始前保存原始地图/任务文件 hash、作者版本、规模、扰动参数生成过程、任务流、运行预算、失败口径及统计单位。不能以内部 C/STOP、oracle、stub 替代已发表外部基线；也不需要为“传统方法已经穷举”这一未证实判断强行引入模型。学习有贡献就进入主方法，无增量则保留为消融与问题诊断。
