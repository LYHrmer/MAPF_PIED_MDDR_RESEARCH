## Same estimator, separately verified measurement

Current occupancy implies progress interval: origin only [0,2/5], both [2/5,3/5], destination only [3/5,1]. MOVE_START is the time origin. With a public ENTER/EXIT landmark, extrapolate its start-to-landmark mean speed (2/5 or3/5 divided by elapsed landmark time) to now; without a landmark use nominal speed1. Project that estimate into the currently public interval and [0,1]. For both views, residual estimate is age*(1-alpha)/alpha when age>0 and alpha>0, otherwise1. It is a fixed constant-observed-average-speed prediction, not a physical bound or knowledge of future speed/pause. Future pauses remain unknown.

Only the selected active agent may replace public alpha with an independently issued current-position measurement. All other agents use the exact same public estimator. Current active type1 becomes max(1,ceil(residual)); non-active current edges retain the R13 known initial-hold/otherwise-unit nominal rule; future edges stay1. TURN/STATION durations are not newly added to either search view. This is a deliberately limited extension of the author unit model, not a complete duration model. Physical execution never uses these search weights as true durations.

The separate measurement service reads the saved private affine segments solely to interpolate the requested position at checkpoint time, and emits only domain, current identity/geometry/time and exact position. A receipt binds checkpoint/request/body/source. The consumer receives the body and trusted local issued receipt, validates allow-listed provenance, context, active identity, geometry, time, public interval and position/progress consistency. It never receives private trajectory/heap. This is research simulated measurement with production_cost=null and request_count=1, not the production main guest certificate/cryptographic mechanism or production fee. A content receipt is not claimed to authenticate malicious arbitrary issuers. Main real capture body, if available, remains a separate domain and is rejected here.
