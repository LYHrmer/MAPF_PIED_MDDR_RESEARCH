# 统一真实状态的完整事件后缀协议

在后缀运行前追加：根独立核验者要求将已经求得的 mini 两种方向放到同一真实状态，检查实际执行后果。此处不新增优化配置，不按后缀表现调参。

输入固定：原 `mini_public_elapsed` / `mini_public_history` 采用的 A 先图，与原 `mini_measured` 采用的 B 先图。实际当前进度统一为 A=0.25、B=0.50；每动作名义长度2、速度2，当前残余分别0.75/0.50秒。未来动作实际用时均1秒，无新增未来随机扰动；这是事前合成例的固定真实后缀，不是生产测量。

按作者原 `Vertex.can_execute()` 核全部 active type2 入边；每 agent 按原 vertex next 链串行推进，原 current IN_PROGRESS 动作不能撤销、修改目标或改为 STAGED。动作完成后调用原 `set_status(COMPLETED)`，下一动作仅在允许执行后才启动。离散事件直接跳至最早完成时点；同刻完成全部处理后再派发。与作者 controller 的2秒周期不同，此处是明确命名的事件执行 adapter，不称ROS全栈或论文原始统计复现。

两种方向去重后只运行2条后缀。保存所有开始/完成事件、逐动作连续线段、完成时间和ΣT/makespan；另以全部线段对做点机器人最小距离检查。点轨迹无相交不代表机器人完整足迹、加速度与真实控制器安全认证。测量费用 `production_cost=null`；无查询价值、学习优势或实时运行结论。
