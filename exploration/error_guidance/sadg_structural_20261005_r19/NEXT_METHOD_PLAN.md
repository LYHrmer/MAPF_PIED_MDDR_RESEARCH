# 从三条实现线收敛到一个论文问题

本轮科学矩阵已经冻结；以下是下一方法设计，不用于修改 R19 模型、阈值、测试场景或结果。定量结论以 REPORT / RESULT_TABLES 为准。

建议继续加入轻量模型，但论文问题应是：**执行信息有延迟和获取代价时，如何只为能够改善后续合法调度的信息付费？** 模型负责估计未完成运动的未来，结构推理负责判断可改变哪些排序，原执行约束负责合法性，真实费用回执负责后续报价。三者有明确分工，比“传统规划器加一个预测网络”更有可检验内容。

## 主线：从报价准入走向时间收益与代价的联合决策

R19 首要验收是原费用回执进入非空后继决策，预算充足/不足确实改变第二次调用，且第二次调用完成物理执行和结算。保留经验报价与实际结算的差额，特别是前后动作几何复杂度不同的误差。此时的预算门只保证“估计报价可支付”，不自动提供实际费用的硬上界。

下一步固定公开的桥接记录：`occurrence, geometry/source identity, START, nominal physical duration, delivered END/POSITION cut, capture/delivery age, prior charged work, available next budget`。运动时间、计算工作量、网络延迟分开保存。主线动作长度与 R19 单格动作不同，不能直接把单位 nominal=1 上训练的模型称为已验证的跨尺度模型。

后续比较应保持同一原控制器与安全核，包含全程/后继不查询、固定查询、原选择机制、增加预测、增加查询价值估计等消融。已有原生前缀和收费实例按哈希复用；更大的标准任务实验只补缺失的接口与条件。加入公开几何/报文复杂度的费用预测，需要独立费用标签，不能用运动时长标签替代。

## 学习线：学习剩余时长，进一步检验决策价值

R19 的条件分布目标为 `E[D−e | D>e, 已送达历史]`。先比较 held-out 预测误差、校准、完整任务时间，保留 EWMA+survival 的强简单控制。已完成动作数不是独立样本数，按地图×场景分族；跨地图、跨动作尺度和未见扰动强度另行留出。

若下一轮确需更换模型，优先检验能表示“正常运动 / 临时暂停 / 持续减速”的小型混合分布或状态模型，而非直接扩大网络。评价未完成条件下的尾部概率与决策损失。只有在相同信息、相同合法动作及强简单方法之外产生稳定完整执行收益，才把学习列为主要贡献。

还要把经验时长分布的条件均值作为简单控制，防止复杂模型仅胜过不合适的单一对数正态假设。固定暂停长度和速度倍率会形成很简单的标签分布，须另以未见暂停长度、速度和变化点检验迁移。当前位置一旦送达，R19 共同采用的是旧线性投影，会覆盖 END-only 条件残余；因此“预测改善但加查询退化”应先检查观测融合，而不是立即归咎于模型容量。下一联合模型应显式条件于整段 START 年龄、捕获时刻与进度，不能把固定暂停时间随剩余路程一并缩小。

不继续从本轮 TEST 挑一套效果最好的参数宣布提升。R19 可成为下一轮已消费开发数据；新的确认实验必须另冻结模型并使用新的场景/地图。

## 执行线：把结构机会升级为带延迟的信息价值

R19 结构查询是可解释的机会筛选：可达合法切换边界或阻塞前沿才考虑查询。它还没有估计查询后究竟会改善多少时间；可达性也不保证信息有用。

下一方法可在每个公开合法依赖组上比较少量候选方向。设 `F_t` 为已送达信息，`a` 为合法排序候选，`J(a,X)` 为给定剩余时长 X 的完成时间估计，查询 q 的观测在 `t+L_q` 才可用。先实现一个明确标注为模型估计的价值：

`V_hat(q) = min_a E[J(a,X) | F_t] − E_y[min_{a in A(F_(t+L_q),y)} E[J(a,X) | F_t,y]] − estimated_query_cost(q)`。

这里必须把查询等待期间原有执行继续前进、承诺导致候选消失、过期观测以及失败回退纳入 rollout；不能用捕获时刻仍可切换来代替送达时刻可切换。时间和工作量不同量纲时，先报告预算—完成时间 Pareto 关系，再登记具体换算权重。安全许可继续由原约束产生，V_hat 只用于选择是否以及向谁查询。

首个可做版本只针对一个合法切换组及其公开后继子图，用 DAG 时间传播比较当前/反向两个候选；验证计算代价后再扩多组。它是信息价值的近似，不是已经证明最优的策略，也不是现有 R19 模型的实现。先用已有日志诊断候选覆盖与预测—决策分歧，真正反事实完整后果仍需新登记的配对执行。

## 作者基线与论文证据

当前 SADG 原作者优化器可继续作为连续时长执行底座；其求解数值拒绝要单列，不能将 fallback 导致的所有差异归为预测精度。冻结接入还会通过 expected_duration 改变作者 horizon 资格，残余预测与边界变化应分开解释。

聚焦检索已确认，时序不确定性下的通信成本优化、按决策变化选择通信对象、按关键依赖减少执行通信都有近邻。上述价值公式是设计工具，不能作为宽泛首创声明。需要证明的具体差别是：送达时刻未来合法候选可能已经消失、已承诺动作不可撤销，以及在同一安全执行核下对完整尾部价值和真实查询费用的共同处理；这一组合的新颖性还要与全文逐项对照。见 NOVELTY_CHECK.md。

下一外部优化器对照优先评估已有 ImprovedGSES/STPG 作者复现，复用 R13 已有合法采用与连续执行工作。源码中的单位时间间隔假设、active 承诺、目标驻留、权重范围和单位必须先对齐；仅见到 `float` 类型不足以认定支持任意连续预测。WinkTPG 是另一个相关执行框架，其时间信息/速度优化机制需按原任务契约核对。详 EXTERNAL_BASELINE_NEXT.md 的原论文和作者仓库入口。

最终主表需要真实发表方法、官方地图/场景、统一初始路径与任务流、同硬件/时间预算、相同公开信息以及完整失败分母。内部 history/rule/EWMA 是消融，不能代替发表方法。固定路径完成时间与 LMAPF 新任务吞吐分表；在没有在线补任务实验前，不把固定批次结果改称 LMAPF 性能。

推进顺序：收尾 R19 全量证据 → 固定主线报价/证据接口 → 对齐一个真实外部执行基线 → 实现上述最小信息价值决策 → 新留出数据确认。三条线继续并行，但共同围绕一个方法与一组可比较结果收敛。
