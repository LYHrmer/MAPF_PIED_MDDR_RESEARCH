Full ridge is unchanged; geometry uses the same lambda1 and preprocessing on masked features. Original source/inputs/model pins and the public program freeze are verified before every run. Existing R7 raw archives and R9 training rows are required for full reconstruction; the package is not a self-contained container. Host ARGoS, external libraries and recorded local binary paths remain dependencies.

Expanded R10 raw data live only in the ignored main-repository evidence directory with the same basename; public per-run gzip archives are complete and member-hashed. Initial socket-denied startup failures are separate archives. The independent refit/live-label/FIFO checks import no candidate builder; physical geometry checks are a reused independently authored audit.
