# R10 geometry/history attribution protocol

Registered before model fitting and the 64 test runs. Exploratory successor to R9, not a selection approval or submission claim. R9/R8 source, frozen models, tests and manuscript remain unchanged. Native execution, original local ADG, two-step acknowledged batches, controller, normal STATION20, author OBJ3 hm and edge-overlay bridge are unchanged R9/R8 artifacts.

Test matrix: two existing MovingAI maps empty-32-32 and random-32-32-10 × four entirely new task families per map (seeds 961031, 961032, 961033, 961034, FIFO RNG string r10:seed:map:agent) × nominal/axis × hm/history/geometry/learned. Exactly 64 arms; N8, H4000 ticks at10Hz, 1002 fixed FIFO goals per robot, same original starts. These are eight independent map/task families, with perturbations and policies paired within family. Native concurrency at most2. No test-driven replacement or parameter changes; startup failures retained separately, retry only infrastructure failures with unchanged frozen inputs.

Full learned ridge is copied byte-for-byte as a nested ridge object from frozen R9 checkpoint, fitted to R7 TRAIN only. Geometry ridge uses exactly those 14,542 completed R7 TRAIN motion rows and the same 14-slot architecture, lambda1, unpenalized intercept, train-only centering/scaling, baseline d0, prediction clipping[1,200], margin0, depth2 projection and 0.025 objective-unit/tick penalty. Raw history slots7..13 are zeroed in fit and inference; their train means become0 and constant scales1. The remaining primitive/compass slots0..6 are identical. R7 CAL is descriptive only; neither CAL nor any R9 TEST may select parameters. Known service S returns20 and is excluded from fitting. Completed-case fit and all censored rows remain explicit.

Same public target D=E−max(A,Eprev), frozen at proposal, enters online history only after its accepted END. Public view/proposal/admit/END are the only information; private controller and future events excluded. D still includes any post-public-lower-bound scheduling/controller effects, not pure motor time. Event projections retain unmasked features for independent feature/label audit; geometry prediction masks them internally.

Before tests: generate complete inputs, fit geometry, independently refit both models from R7 using augmented least squares, verify old training labels/features via raw parser/admit/END, and mechanical feature intervention checks (geometry invariant to arbitrary history, known S20, full history sensitivity). Freeze all executable/input/model bytes and source pins. No extra native preflight is needed because native paths are unchanged and masking is a pure predictor intervention.

Primary: normal accepted STATION END tasks. Secondary: fixed first10 FIFO tasks per robot, missing completion assigned H4000, sum of absolute ticks. Report each condition and eight paired family effects; do not count primitives or64 arms as independent samples. Report all signs, losses and zeroes; bootstrap eight family deltas using fixed seed103064 and10000 resamples only for descriptive uncertainty.

Same-trace prediction: replay all history/geometry/full on the16 heldout hm traces, report MAE/RMSE/bias/median and95th-percentile absolute error grouped by primitive×direction, logical step, world and completed-history availability. Report between-family means so a long trace does not silently dominate conclusions. Censoring and admit/own-prefix waits remain visible. Prediction accuracy and closed-loop throughput are separate outcomes.

Attribution: for history↔full, geometry↔full and history↔geometry, report earliest action divergence, exact common view/frontier, tick, public completed-history count, changed agents and primitive/edge estimates. Edge-duration and overlay-cost rankings are explicitly heuristic diagnostics, not the unexposed final internal author action ranking. On the first shared decision and common first-divergence frontier, separately recompute full model with zero history; classify offline-prior versus online-history influence without attributing causality from different post-divergence traces. No post-test tuning/expansion.

Audit full raw native parser lineage, ADG, FIFO head/20tick service, task totals, public forecasts, labels/features and sampled physical clearances; preserve receipt failures and raw archives under45MB. Author licenses, inherited source pins, independent refit, execution freeze and publication allowlist are delivered. Internal history/geometry/full are ablations; hm is author OBJ3 on this declared continuous adapter, not an original-paper numerical reproduction.
