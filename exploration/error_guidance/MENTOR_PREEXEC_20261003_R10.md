# R10 科研导师独立实施前判断

本判断应用 research-mentor 技能，读取 R9 三线结果、导师后评及下一方法合同后形成，未读取本轮 Astra 评估。它是研究判断，不是统计独立复验。研究阶段是用户授权的隔离探索；正式论文适用范围与统一作者基线仍未闭合，不能据此锁题或承诺可投稿。

选题资格卡沿用本轮 `implementation_binding_evidence/R10_WORK_PLAN_20261003.md`：通俗问题、发表锚点、既有官方工件、探索所需事件数据均 PASS；最终统一外部基线与投稿规模纯仿真证据 UNKNOWN。现有原生接口足以支持预注册最小机制试验，正式结论以任务结果和可核费用为准。

三条线面临的共同问题是：模型虽然能改变局部事件，但局部变化是否传到最终服务仍缺证据。R9 主线四次服务受固定日程限制；查询线十四次实际 WAIT 改变物理流，却被共同续策消解；误差线学得模型仅单条件多两任务，同轨迹运动 MAE 反而全部较差。继续放大模型会掩盖这三个不同的识别问题。

主线应先把正常 END、服务完成、下一 head 与付费结账解耦，并预注册短、中、长三种移动。验收不是“所有脚本通过”，而是正常服务能按合同及时发生，陈旧/重复证据不能多释放或多消费，增量费用确实绑定所执行的路径。短例没有正收益也必须保留；付费获取信息不自动构成效率改进。

查询线应将“等一个事件”和“本次 occurrence 永久不查询”分开，后者以完整 agent/action 身份在正常 END 结束时失效，不能影响后继 MOVE。标签分支和部署必须共享该公开状态与续策。先在新训练 world 验证动作可造成持久预算或服务差异，再冻结学习器与新留出。若差异只有次数而无任务改善，应写成预算配置研究的负结果，不能把较少查询直接当净收益。

误差线当前最有价值的试验是同训练数据、同 λ、同架构的 geometry-only 与 full-history 对照。只屏蔽历史槽位 7–13，保留 primitive/方向和其他预处理；原 hm 与强历史继续作为作者接口基线和内部消融。新增两图各四个未见 task family，nominal/axis 两种扰动，四策略共 64 臂，N=8、H=4000。模型在测试前冻结，不读取 R9 TEST 来拟合或选择参数。首个动作分歧需报告当时完成历史量：零历史分歧只能支持离线先验作用，有历史分歧也不能独立证明在线历史价值。

第三线主要结局是每个 map/task family 配对的真实 FIFO 服务任务数与固定前缀时间；预测诊断在相同 hm 轨迹上对所有模型重放，按 TURN/半 MOVE × 方向报告 MAE、RMSE、偏差及尾部误差，保留删失与依赖等待边界。D=E−max(A,Eprev) 是公开下界后的时长，不是纯 motor time。几何模型若重现 full 收益，应收缩“误差适应”的表述；full 若跨新 family 独立改善，才有理由进一步研究时变误差与依赖传播。

作者 STPG 固定路径调度和 OnlineGGO 重路由是不同问题。先做共同承诺前缀、依赖和时长语义的可执行适配，不把两类成本直接排成优劣表。三线推进不能相加成统一增益，也不把内部规则命名成外部基线。本轮完结时应由新原始流重新审计训练隔离、FIFO、首分歧与费用，再据结果更新判断。
