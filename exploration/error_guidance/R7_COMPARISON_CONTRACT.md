# R7 方法与比较口径

本轮是已授权的隔离探索。三线共用“执行误差下，信息或执行历史如何改变有效决策”的研究问题，但各运行器的任务、时间和成本单位分开报告，不能把三张表拼成同一系统的性能排名。

|实验层|实际对照对象|应比较的结果|不能据此推出|
|---|---|---|---|
|主线收费与资源释放|同物理输入的原等待／真实付费 POSITION；原 owner、需求、控制器与费用链|明确时刻的资源退休、原 MOVE 启动/闭合、公开 END 与附加 fixture 服务分别列示；已实际计量费用|fixture 等于作者 STATION、未实现的 END AUTH 已完成、未计费 WAIT 的整次净费优势|
|查询选择器|同一作者规划器、相同已承诺路径与 FIFO 下，WAIT、RR、同历史条件规则、有/无历史学习|正常任务完成、阻塞、候选数、实际选择、查询量、推理耗时、删失/失败|内部 RR/条件规则是已发表规划基线、使用常数查询量预算就已测生产收费|
|执行误差引导|作者 OBJ3 hm 与 OBJ4 冻结流量模型；新残差候选及同历史非学习估计|真实路径/动作变化、正常 STATION END、完整运行失败、预测误差与推理成本|只降低预测误差就有吞吐收益、修改后的 search 对象仍是原作者未改算法|

作者来源：[OnlineGGO，AAAI 2025](https://ojs.aaai.org/index.php/AAAI/article/view/33614)改进 PIBT 的自适应引导；[PIE-D，AAAI 2025](https://ojs.aaai.org/index.php/AAAI/article/view/34506)研究延迟下并行规划与执行。已有正式版本与原版最小运行继续保留，新的执行适配必须列出差异。两篇论文的原生任务/执行语义不同，只有建立兼容共同合同后才能同表比较。本轮论文页面于 2026-10-01 再核验。

新 query 规划状态中的 frontier 是已承诺终点，不是猜测机器人实际当前位置；承诺路径不能被后续规划覆盖。每个新目标必须在真实服务或该运行器原定义的正常完成后揭示。用实际执行记录核对任务 owner 和 FIFO ordinal，不能以方法间可能分叉的全局 task ID 硬配对。离散长环能否由连续资源独占接口启动必须如实记录，不通过删除失败或换成自写 planner 获得成功率。

学习输入与离线诊断分离：原始 pose、隐藏速度参数、未来扰动和未揭示任务只用于核验/标签。actor 可读的信息由协议逐项列出；admit→END 或相邻公开 END 的耗时标签须说明包含哪些排队、转弯与运动阶段。强非学习估计器取得同样已交付历史。权重、代价尺度/单位、合法候选、截断和预算在新留出前固定；旧 R6 数据用于开发时不能再被称作未见测试。

新 search 代价必须明确非负性和与原指导代价的单位关系；模型不得绕过原碰撞、ADG 或空间资格检查。至少分开记录预测数值变化、路径代价变化、搜索顺序/动作变化和真实服务变化。样本少时给完整逐运行配对表，不把动作、tick 或任务当独立实验重复去构造显著性。

主线指令计费、native wall-clock、物理仿真秒、通信字节和查询次数分别报告。模型训练是离线成本，在线推理需计入对应运行开销；初始化与每次查询/收据/选择增量也分开。结束时全部揭示但未完成任务保留删失。超时、死锁、适配不支持和原算法失败按实际来源标记，原日志不删除。
