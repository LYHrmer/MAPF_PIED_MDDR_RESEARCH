# MAPF／LMAPF 论文实验要求与已登记材料

2026-09-30。按用户最新要求，三线以多智能体路径规划领域的可比较问题、正式方法和标准实验组织。本文件规定后续主实验；不是已完成主实验或录用保证。先导机制试验继续运行，不新增审批步骤。

## 领域依据与本文问题

[PIE-D，AAAI 2025](https://ojs.aaai.org/index.php/AAAI/article/view/34506)针对持续分配目标时的执行延迟与并发规划。[OnlineGGO，AAAI 2025](https://ojs.aaai.org/index.php/AAAI/article/download/33614/35769)以持续任务吞吐为目标，报告公开及仓储地图、机器人数量曲线、1000步运行、50次模拟平均值和95%区间，并比较正式hm+GPIBT等方法。这些是本项目的具体参照，不是所有MAPF论文统一规定的最低数量。

本文候选问题是：在有界空间执行误差、非瞬时反馈及有限查询资源下，选择哪个机器人提供真实执行证据，怎样通过合法释放/依赖传播改善持续任务执行。学习只负责决策或价值估计，安全释放仍由确定的空间证据机制控制。若最终方法只改执行，不改变路径搜索，就应准确定位为LMAPF execution framework/coordination，而非新路径搜索算法。

## 三线证据的作用

| 当前工件 | 可以支持 | 不能替代 |
|---|---|---|
| 主线精确数值/所有权/费用实跑 | 单查询实现与费用来源、空间证据接线 | 规划算法优势、全局吞吐、通用CPU效率 |
| 查询四机器人/两head R5 | 同world历史→决策→释放/任务的机制辨识 | 100机器人原作者LMAPF、无限持续任务或跨图结果 |
| GPIBT→LSMART双机器人FIFO R4c | 真实控制历史、可达争用和预测动作敏感性 | 标准MAPF规模实验或连续无碰撞证明 |
| 官方800机器人hm/OnlineGGO比较 | 已发表方法原生复现与公平任务输入 | 新误差模型相对这些算法的收益 |
| 本目录官方材料 | 标准输入可用性、坐标/可达性/容量 | 新的native性能实验 |

论文主表不得把上述不同环境的数据拼作同一比较。

## 已完成的标准材料登记

直接从[MovingAI官方MAPF benchmark](https://movingai.com/benchmarks/mapf/index.html)下载原map zip及四份random-scenario zip，原档未改，SHA与URL见registry.json。依据[官方许可页](https://movingai.com/benchmarks/)，材料使用Open Data Commons Attribution License，需保留Moving AI Lab/Nathan Sturtevant来源归属。

| 地图 | 可通行格 | 已核场景 | 每场景固定机器人数量 |
|---|---:|---:|---|
| empty-32-32 | 1024 | random 1..25 | 32/64/128/256 |
| random-32-32-10 | 922 | random 1..25 | 32/64/128/256 |
| maze-32-32-2 | 666 | random 1..25 | 32/64/128/256 |
| room-32-32-4 | 682 | random 1..25 | 32/64/128/256 |

register.py已逐场景核地图名、尺寸、所有起终点合法及四邻接可达、前N起点和终点各自不重复，400种map/scenario/N组合均具备输入。没有按算法成功、模型收益或拥堵结果筛选；原scenario距离字段只保留，不擅自当四邻接最优距离。相同N在不同图的实际密度另列。加上既有作者sortation/warehouse域作为应用补充，不能只选学习最有利的图。

这些100个精确场景登记为后续完整benchmark留出输入；未来训练不得使用它们。先前是否接触相同地图另查，因此现在不声称未见地图泛化。真正跨图泛化需整图留出后重新训练/冻结；当前两个小模型不自动取得该资格。

## 固定主实验设计

1. **统一问题。** 四邻接图、顶点/交换冲突、机器人尺寸、连续误差界、驻留服务时间、任务释放/揭示与完成判据、反馈时机全部写出。MAPF一次性到达与LMAPF持续任务分别评估，不能用两head的完成流时冒充长期吞吐。各baseline可用信息一致；理论已知延迟概率与可学习未知误差另列。
2. **持续任务输入。** 官方scenario只给起点/首任务；后续任务由共同环境事前固定逐agent FIFO流，在相同可达分量内采样，所有算法读同一文件且只揭示相同数量。任务采样器与误差采样器分离，不能由某策略完成顺序消费共享随机数。Kiva W/E任务继续交替并保持同流，R5配对比较已实现此接口。未来误差轨迹以环境时钟及agent绑定；若以动作序号绑定，明确这种耦合并做替代耦合敏感性。
3. **规模与重复。** 主离散执行域用已登记32/64/128/256，25官方scenario各2个事前固定任务/误差流，即每map/N/condition 50完整run。配对比较在同场景同流内进行，统计重采样按scenario聚类，不把共享起点的复制当完全独立地图。物理执行器先完成8/16/32/64的可运行性并单列表格；最终规模由事前资源上限约束，超时/死锁必须进入分母，不能观察收益后删高密度。上述规模是项目设计，不是刊物门槛。
4. **时域与预算。** 离散作者R0先1000步，持续执行共同域按1000个名义动作时长定义物理截止，换算dt后事前冻结；再以更长固定截止检验短时域偏差。规划、特征、推理、证书查询/排队、初始化分别计时；同CPU/线程/内存及每次决策deadline，训练成本另报。主线1048576指令供给是本实现合同，不能替代全部方法共同wall-clock预算。主方法整体和原组件时间都需报告。
5. **误差条件。** 无误差；作者离散延迟条件；空间误差/速度异质/时序相关误差；未知扰动或分布转移分别列出。物理参数、空间界与采样律在正式主实验前冻结，不能通过选择对学习友好的合成规律保证结论。更改误差规律时全部方法重测同批输入。
6. **指标。** LMAPF首指标=真实完成任务/共同物理时间；报告完成数、每机器人分布、队列与停滞、反馈/查询量、超时率，以及完成任务流时和未完成任务数。若以min(completion,H)-release作受限流时需明确删失；不能只平均完成任务。一次性MAPF再用success rate、SOC、makespan。模型MAE/Brier仅解释机制，不能代替规划/执行收益。
7. **统计与泛化。** 展示每图密度曲线、完整条件结果和配对效应区间；不只总体均值或最好一图。完整episode/任务组划分训练校准测试，最后冻结权重；地图/机器人规模/未知误差分别检验，训练失败及零收益保留。不能用数百万动作行充当独立样本数。
8. **安全。** 安全性命题写明适用图/动力学/误差/反馈假设，学习失败只影响效率还是可能影响安全要区分。连续空间保证需解析占用管或完整区间验证；离散无顶点交换冲突、低频pose无碰撞与严格连续无碰撞是不同证据。两例中间ACK>0.03m的结果保持可见，不能用原作者不同谓词替换本文严格判据。

## 正式基线与内部消融

| 对象 | 正式来源/版本 | 当前状态与主表条件 |
|---|---|---|
| PIE-D及原文执行变体 | [作者LMAPF-delay](https://github.com/YueZhang-studyuse/LMAPF-delay)，74cfba3c | 作者原生R0已跑；须保留作者强配置及原延迟语义，再公布共同空间误差适配差异 |
| GPIBT | [作者Guided-PIBT](https://github.com/nobodyczcz/Guided-PIBT)，7f4b91e4；AAAI2024 Traffic Flow Optimisation | R0及LSMART共同接口已跑；GP-R100/Re10等配置需按原文公开，不能将缩小group2称原大规模R0 |
| hm+GPIBT | [OnlineGGO作者实现](https://github.com/zanghz21/OnlineGGO)，ff6d830e，SUM_OVC | R4原作者任务及R5严格同任务800机器人比较均完成；与另一repo同名配置不得默认为同一算法 |
| OnlineGGO训练模型 | 同上，AAAI2025 on+GPIBT | 已真训练200候选及留出；主论文比较须足额训练/收敛分析或可验证作者权重，不能用未收敛模型代表方法上限 |
| RHCR/ADG类执行近邻 | 以最终问题匹配的作者原版为准 | 仍需共同问题的正式比较；不能只列文献而声称已比较 |
| REMAP v2、Should I Replan?等 | [近邻定位](../LEARNING_POSITIONING_20260930_R4.md) | 明确已有执行预测/价值学习；无作者工件时做方法差异分析，不造“官方复现” |
| WAIT、真实RR、概率/结构/历史规则、常量rank | 本项目内部 | 必需强消融；绝不标为发表baseline或SOTA |

查询多决策中的RR必须有循环cursor，不能把最小agent ID固定优先命名round-robin。模型含/不含历史需要相同训练数据、标签、容量与调参预算；另比较强条件统计规则，避免把“更多合法信息”混作“学习架构更好”。

最终论文的最低实质目标是：在明确定义的误差执行问题上，通过一个有解释的决策改进，在强正式方法和强内部消融面前产生稳定、可复核的任务收益，并交代安全、代价和失效范围。当前已关闭若干实现/公平性缺口，尚未满足完整投稿证据；这不妨碍继续三线机制与集成。
