本机证据：[HANDOFF](/home/lyh/MAPF_PIED_MDDR_RESEARCH/implementation_binding_evidence/paid_position_service_pair_20261001_r7/HANDOFF.md)。新长输入将前车 MOVE 长度从3改为27，重新绑定 geometry、session、29个资源 cell 和三份 guest ELF；沿用原查询时序与每段8,388,608供给。两臂相同输入/误差，正常 END 观测后的附加延迟为0。

|长输入配对|WAIT|付费 POSITION|
|---|---:|---:|
|前车原控制器自然 END|9|9|
|后车原 RUN|9|6|
|后车原控制器自然 END|9+√3|6+√3|
|目标内停稳1tick的 fixture 服务时间和|22|19|

付费 RUN 的 t6，前车实际进度 s=18、`closed=false`。原 guest 的 POSITION→owner/demand 更新→资源 guard→MovementReady 链完整执行，后车到达提前3；没有靠延迟 END 通知制造这个正例。这里 s 是离线物理观测，不冒充 guest 导出的 committed q。正常 END 和目标停稳服务仍为明确标注的 host fixture，不是生产 AUTH END 或作者 STATION。

长输入两制度均完整运行102段，真实收齐四 terminal、安装收据并通过 guest 可用报价检查/下一选择。Natural actual=charged **183,932,924**；Strict actual **183,932,025**、charged **855,638,016**。更长几何多用4个 startup 段，不能与 R6e 短输入98段当成同合同优化比较。WAIT 没有同样完整计费，故没有净费用优越结论。

短输入也完整保留：δ0 的付费脚本在正常 END 先到时不支持原生命周期，真实运行32段后退出，不能虚填其服务收益；δ3配对零收益，δ4/8仅为通知迟到下的1/5时间单位收益。初次长 session 的两次 binder 拒绝与其原始源独立保留；新单字节 session L 后继重新编译绑定再成功。最终登记15臂，另有3个首次长输入记录，均不作统计独立样本。

## 查询支线：真正在线、多候选、实际训练，但仍无学习任务优势

[完整报告](https://github.com/LYHrmer/MAPF_PIED_MDDR_RESEARCH/blob/explore/learned-query/exploration/learned_query/online_fifo_20261001_r7/REPORT.md)。采用持久作者 OBJ3 planner，在公开已承诺的离散 frontier 上生成后继，每agent最多4个未完成承诺；原 cell 访问依赖和实际资源 guard 保持。只展示当前 FIFO head，后继在真实服务和正常 END 后揭示。规划期间其他合法 MOVE 可继续执行，没有全队停稳屏障。

12机械臂加48统计臂共 **60次成功执行**，其中20次为完整留出。N=2/4/8/16机械验证后，N16新整run固定3train/1cal/2test任务种子；每test另作IID/SHIFT。训练/校准选每run最早2个单候选和2个多候选机会，选择规则只读公开候选数，然后对机会中全部候选运行一次查询与同前缀 WAIT 反事实。24标签为18train/6cal，20零、3正、1负，未筛掉无益查询。

两份同架构 ridge（有/无已交付历史）训练后冻结。以下为四个留出 world 的整体任务数，不把轨迹/决策条数作为统计重复：

|方法|IID 两world任务|SHIFT 两world任务|合计查询次数|
|---|---:|---:|---:|
|WAIT|90|90|0|
|RR|89|90|64|
|条件规则|89|90|64|
|历史 ridge|89|89|14|
|无历史 ridge|90|90|0|

无历史模型在这批留出全部选择等待。历史模型确实参与选择并减少查询，但任务数更低，不能宣布其更优；测试12个有预算多候选机会也全部等待，尚未证明学会竞争排序。固定初始每agent前4任务的受限完成时刻和另列报告，不替代全任务完成数。所有60运行在本128时间单位窗口内无死锁；这不证明一般无死锁，保守资源排他下的循环仍有可能。

独立70位Decimal/资源/FIFO/候选/特征/分数重放覆盖60运行；root再独立复算24反事实的完整前缀、标签、选样全集与增广最小二乘，分别见该目录 `AUDIT_ALL.json`、`ROOT_LABEL_AUDIT.json`。第一次12机械臂因任务ID超32位失败完整保留，改ID范围后的成功臂另存。公开作者地图/起点与实际作者planner不等于原作者完整 benchmark：本任务FIFO、连续执行接口及查询规则属于新实验环境，WAIT/RR/条件规则仅为内部消融。

## 第三线：新执行残差模型已通过“预测→动作→部分服务”链

[完整报告](execution_residual_20261001_r7/REPORT.md)。先将 R6c 的2,304,000 agent-tick守恒归因：约26.61%是全队同步等待，明确依赖等待约0.11%。这是该共同适配器的诊断，不能推广为原作者系统性能。

新模型仅从公开 proposal/admit/已接受 END 训练“整格动作从提议到最终 MOVE ACK”的超额耗时；输入包含转向、方向和该agent已完成的历史残差，排除私有位姿、控制器扰动与未来任务。它预测的时长加校准余量生成两步未来占用代价，作为非负项加入作者 OBJ3 的真实搜索边代价；官方优先级、其余算法对象与旧 OBJ4 对照保持。当前模型包含派发/依赖等待/转弯及两个半 MOVE，不应命名为纯运动速度模型。

两图×8机器人，每run400秒，完成 **12训练+6校准+24留出=42次真实执行**。6,062训练标签、3,010校准标签、94截尾分别保存。冻结模型在相同 hm 留出轨迹的2,904标签上 MAE **9.3860→6.8969 ticks**（相对同历史规则）；root独立从18份公开事件重建所有训练/校准标签和事前特征，再以不同求解法复算权重，见 [ROOT_MODEL_AUDIT](execution_residual_20261001_r7/ROOT_MODEL_AUDIT.json)。

|六个留出 world 合计|正常 STATION 完成任务|
|---|---:|
|原作者 hm+GPIBT / OBJ3|120|
|旧小预算 OnlineGGO / OBJ4 迁移权重|100|
|同历史统计规则代价|119|
|新训练残差模型代价|119|

模型相对同历史规则在 **4/6 world** 发生真实动作分叉，首次分叉前公开状态和物理轨迹相同。在 empty-axis，22个共同已完成任务中8个提前、12个相同、2个延迟，完成时刻和净少 **142 ticks（14.2秒累计值）**；另三个动作分叉world尚未改变已完成任务时刻。root从全部24原始日志独立复算服务和首次动作分叉，见 [ROOT_TEST_AUDIT](execution_residual_20261001_r7/ROOT_TEST_AUDIT.json)。这证明新模型有独立决策作用，尚没有相对原hm的整体性能优势：原hm还多完成1个任务。时间和诊断不把未完成任务删除后冒充总体流时。

42运行的共同正常 ACK/FIFO/服务检查通过，物理采样圆包络最小机间/障碍净空为0.303549m/0.371155m；采样全正不是连续安全证明。18次初始 sandbox socket 拒绝为0decision基础设施失败，完整另存，不作为算法失败。旧 OBJ4仅200候选训练预算，不能代表充分训练作者方法。当前仍有全队屏障，不能称已完成原异步 LMAPF 比较。

## 下一轮推进，按论文贡献而非模型大小安排

**主线：把普通 END 与付费 POSITION 放入同一真实计费事件循环。** 新增长度3/12/27事前配对，使短输入δ0也合法完成：END先到应释放原需求，过期POSITION按原生命周期处理，已发生费用仍结清。先补 WAIT 总成本，再把实际报价用于多source竞争。R7的gain=3给出了值得接入持续任务的机制依据，后续不再以微小数值优化作为主要科研进展。

**查询线：保留在线接口，扩大新的训练任务流，学习全任务边际价值。** 当前只有18个训练标签，20/24反事实无效，复杂网络没有数据依据。新采样按公开阻塞图的共享阻塞、关键后继、候选数分层登记，同时保留零候选和单候选覆盖；标签由合法同前缀续跑产生，评测权重仍按完整场景分布，不只展示有效机会。把 WAIT 明确作为动作，用“完成任务差+固定任务受限时间差+实际查询成本”检验效用；成本换算/阈值只能在新训练与校准中固定。先做轻量模型和同信息强规则，再考虑图模型。禁止在本4个测试world上调阈值后重称留出。

**第三线：优先完成局部依赖下的持续执行，再比较模型作用。** 先4agent含独立动作和依赖动作的机制场景：暂停一MOVE时独立动作应推进，依赖后继仍须等待原合法ACK；保留零扰动对照和不覆盖在途承诺的检查。通过后做“全队屏障/局部依赖 × 同历史规则/学习”的共同输入实验，分解预测精度、路径变化、等待传播和正常服务。R7两步占用近似和全队屏障都可能限制收益，属于待检验解释；不能从MAE改善直接推出瓶颈原因。模型仍使用合法已交付证据，处理不确定性与未知变化，安全约束继续由原执行机制承担。

**正式 MAPF/LMAPF 证据：** 固定作者版本、地图/场景、每agent FIFO、误差过程、可用信息与运行预算。至少新增 empty/random/warehouse 三类图、8/16/32规模、每组不少于10个独立配对任务种子，随后依据置信区间决定扩样；按完整run而不是MOVE记录作统计单位。主表比较正式作者 PIE-D、hm+GPIBT、经充分或明确等预算训练的 OnlineGGO，凡共同执行适配均给出适配差分与原作者R0复现。原版与误差版本按同一模型语义分别评价，不能跨时钟和观测条件拼任务数。内部规则只进入消融；报告完整成功/死锁/超时/删失、吞吐、固定任务完成时间、延迟传播与计算/通信/推理费用。

## 与已有研究的区别必须写实

[PIE-D，AAAI 2025](https://ojs.aaai.org/index.php/AAAI/article/view/34506) 已研究延迟下的并发规划与执行；[OnlineGGO，AAAI 2025](https://ojs.aaai.org/index.php/AAAI/article/view/33614) 已学习在线交通引导。另有 [REMAP / ExecTimeNet / ESADG v2](https://arxiv.org/abs/2511.21886v2) 涉及学习执行状态并用于规划/执行调度，[Should I Replan?](https://arxiv.org/abs/2604.25567) 以ADG特征预测重规划收益。后两项按当前页面列为预印本，不伪称正式期刊基线。

据此，本项目更值得验证的候选问题是：**在执行误差下，稀疏且有成本的进度证据怎样按后继任务价值分配，并在保留空间约束的同时改善持续服务？** 这是研究假设，尚不是已证明独特的新颖性。第三线可作为误差预测与引导的替代平台；仅把时长预测器塞进ADG或更换网络名称，难以与上述近邻区分。SCI二区/三区目标可以指导工程完整度和论文范围，录用仍取决于这个差异是否带来可信的完整任务收益。
