## 历史如何产生并先于决策可用

每个实际动力学条件各生成两个独立历史 episode，任务分别是一段长度 1、2 的原 MOVE。它们使用同一 footprint/Z 和真实 Geometry、PositionCommit、ReferenceController：先合法普通 full-cap 授予，再安装 cap/RUN，到原终点 closed、s=ell、v=0，最后提交 native END 并保留终点 resident。每个历史任务只有一段，未冒称完整生产任务分配/服务系统。

历史 episode 的全局起点为 0 和 4；原生 END 收据按已声明的 END+1/4 时间交付。两条收据均在评价全局时刻 10 前到达，并由代码检查。评价仍使用上一轮局部时钟：局部 t=0 对应全局 10，因此 blocker 原点、观察局部 t=5/2 和 4 完全不变。独立历史 episode 与评价没有混用局部零点；这里的固定 native 收据事件没有运行生产 AUTH 或消息传输。

交付给拟合函数的记录只有 run/MOVE 身份、公开长度以及开始、END、收到时间。私有 eta、World、Controller 和评价真值不进入拟合或选择。历史与评价的 run 身份不同。实验明确设定**该 requester 动力学条件在历史与后继评价间保持**；这是历史具有预测力的原因，不是从空历史免费得知 eta。

## 一个尺度参数

从两条已收到的历史记录计算 D_i=end_i−start_i，采用零截距的一参数闭式拟合：

`alpha = Σ(L_i D_i²) / Σ(L_i²),   D_hat(L)=√(alpha L)`。

匹配条件得到 alpha=3；快条件得到 alpha∈[1.173846,1.173847]。两个条件中，拟合结果都严格等于最后一条 END 的 `D²/L` 解析尺度，代码实际核对了这种相等；没有把它包装成独立的学习优势。

新预测器仅将 requester 的名义单段时长改为 D_hat(L)。运行器逐字检查除此之外的预测主体仍与旧版本相同：blocker 名义进度、epsilon、几何阈值、严格释放关系和公共观察日程均不变。校准仍不能写 q、删除 owner 或越过真实准入检查。

## 研究含义

上一轮同公开状态、零 requester 历史的两个条件不可逐例区分；本轮加入的是已交付、与未来具有明确关系的历史事实，因而公开信息不再相同。它验证了合法经验数据能改变安全层之外的性能预测，并改善一个真实执行选择。改进由简单解析校准即可取得，后续学习方法应在同样历史与决策器上证明额外价值。

该结果没有测试动力学在历史后漂移、证书交付延迟不确定或路线改变其它机器人行为，也没有计历史采集/校准/规划的完整费用。历史是独立完成的单 MOVE 任务，评价是固定三段路线，尚非连续 lifelong 服务实验。原 prefix 普通分支仍与 full-MOVE 相同；二维空间误差安全层未改变，scalar eta 的学习不能冒充对横向误差的替代。其余 native 安全与费用边界见 [mismatch 报告](MISMATCH_PRECHECK.md)及[原合同](RESEARCH_CONTRACT.md)。
