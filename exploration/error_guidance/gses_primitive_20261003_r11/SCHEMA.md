# Exact trace schema

Every raw gzip expands to one JSON object with `profile`, `graph` (unchanged author paths/current/offsets/type1/type2), `radius="1/10"`, `agents`, `makespan`, `sum_completion_time`, `completion_times`, `events`, `segments`. All times and segment coordinates are exact Python Fraction-compatible strings (`"7/4"`, `"0"`). Coordinates use the two author Location components consistently, Euclidean grid units.

Segments contain `agent:int,t0,t1,p0:[x,y],p1:[x,y],kind,from_state,to_state,yaw0,yaw1`. They cover every agent continuously from0 to makespan, including post-goal residence. Kinds: INITIAL_HOLD, WAIT, TURN, MOVE_HALF1, MIDPOINT_PAUSE, MOVE_HALF2, STATION, GOAL_HOLD. Positions are affine on segments; yaw records quarter-turn indices0..3, with deterministic shortest turn. `to_state` on a MOVE segment describes the committed destination, not accepted current state. State advances only at the ARRIVE event.

Events contain `seq,t,agent,kind` plus typed fields. INITIAL declares current vertex/cell. MOVE_START gives from_state,to_state,origin,destination,dependencies [(source_agent,source_state)]. RESERVE_DESTINATION and RESERVE_EDGE immediately follow. CELL_ENTER at progress2/5 adds actual destination footprint; HALF_END at1/2 retains both cells and original state; optional MIDPOINT_RESUME also retains both. CELL_EXIT at3/5 (plus midpoint hold, if any) removes source positive-interior footprint, then RELEASE_SOURCE relinquishes its reservation. Source/destination boundary contact at the exact event instant is allowed; body penetration is not. At full MOVE completion RELEASE_EDGE and ARRIVE record cell-center arrival and accepted new state. TURN_START/END and STATION_START/END never release the current cell. GOAL_COMPLETE follows final prescribed station dwell; residency remains until common makespan.

Dependency release is deliberately more conservative than physical CELL_EXIT: original type2 predecessor vertex must have actually ARRIVEd before the target MOVE_START. Initial already-executed current prefix satisfies any earlier predecessor. Resources add a geometry guard shared by all adopted author graphs. Events at one rational timestamp are processed before new starts; records have deterministic sequence order. Author_unit omits nonzero TURN/STATION segments and uses original pre-move hold delay semantics.
