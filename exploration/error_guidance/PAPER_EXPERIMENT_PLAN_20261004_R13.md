# R13 后的论文实验计划：有限证据下的合法后缀选择

这是下一阶段执行方案，不是已经运行的实验注册，也不是对 SCI 二区/三区录用的保证。R13 三个目录继续冻结；本文不启动额外科学运行。现有机制例足以支撑下一接口预检，不能充作正式统计留出。导师先提出范围，执行前仍须把具体文件、随机种子、误差表、预算、源码及停止规则写入新注册。

## 1. 统一问题与可证实命题

研究固定路径 MAPF 计划执行时，公开 END 与历史不足以确定开放 primitive 的进展、部分动作已经承诺且证据获取及搜索有成本时，是否应购买一次有效 POSITION，以及是否据此采用合法后缀依赖图。保持原完整路径、已执行访问、active MOVE、TURN/STATION 占用和原关系族；只优化未来依赖次序。暂定一次公开决策门、三个完整 option：保持原图；公开信息调用固定 Improved GSES；购买一次证据后调用同一 Improved GSES。GSES 同样保留为正式作者算法对照。三个 option 后的执行策略一致，不把单次标签反复用作多时刻策略。

主要命题必须是条件选择在新原始实例上改善平均完成时间，并遵守事前费用及可靠性约束。单纯学会预测 SOC 差、增加历史概率槽、保护承诺或者把原图换成作者优化图，分别已有近邻或属于必要平台工程。R13 中 ΣT 改善与 makespan 恶化并存，因此不作“各项均更好”的预设。若 paid option 与 public option 完全等价，应停止学习这个无差别标签，先处理信息到动作接口。

## 2. 三方共同执行合同

所有算法在同一初始路径集、同一公开决策门、同一外生误差表和同一精确事件执行器上比较。误差按完整 agent/occurrence 身份预生成，并在分支之间保持一致；不能按策略消耗 RNG 的顺序重新抽样。正常 END 的内容、公开路径、已发承诺、可见历史、POSITION 价格与合法性、无信息时的估计方法逐项列成表。

执行器和可信验证器可以知道真实位置用于安全与核验，但这些私有量不能自动成为 scheduler 或作者 solver 的输入。R13 第三线公开 arrived/occupancy 的每个字段必须标明可公开来源；若统一合同中只能付费取得，该字段应从公共输入去掉。查询不能免费泄漏将来 active 完成时刻、未来 pause 或误差类型。

**首先完成的版本只研究时间执行误差。** R13 第三线是沿固定格中心线的圆盘运动，扰动为持续时间改变与中途暂停；它尚未测试非零横向跟踪偏差，也没有统一主线精确控制器的空间误差 Z 信息合同。阶段 A/B 沿用这个可核验层级，只能结论于该时间误差与共同分段线性模型。把证据接口接上不等于两套运动控制器已统一。若研究空间误差，另立版本，把实际非零横向轨迹、控制反馈、Z 的可见性/证据来源和圆盘连续最小距离都接入同一控制执行层；放大名义半径只是保守包络，不能代替实测或仿真的偏移轨迹。阶段 C 的默认四类仍全是时间误差，不预支空间鲁棒性。

第一项实现是显式的“已核有效证书 → search-view”映射。当前 `online.py` 的 public 等值检查不接受额外证书视图；当前 STPG 的 `diff>=0`、启发式 `+1` 等语义也不允许仅把浮点残余传入便宣称保持原算法保证。先写清估计量、整数保守映射与证明适用范围，保留证书身份/时效验证及完整 lift/guard；不得将未来搜索边权直接作为物理时长。若保守量化吞掉所有证据差异，照实记为接口无效，不通过放松 ARRIVE/active 守卫制造收益。

模型、规则和作者方法都使用同一 guard 与失败回退。拒绝、无变化、超时和无合法门的原始实例全部进入结果；不得只分析采用成功例。候选生成、模型特征/推理、证书请求/核验/复制分别记账。公开方法允许不花证据预算；“相同预算”是可用上限一致，实际使用量须报告，不能强迫省钱方法花满预算。

第一阶段每条轨迹最多一次购买、一次 solver 调用。每次搜索上限 16 秒，host deadline 25 秒，使用同一机器/线程/内存限额与作者配置；两个数为沿用 R13 的候选预算，注册前根据未看效果的兼容性检查最终锁定。学习选择必须在生成测试候选前作出，不能免费运行两个 solver 再选择，却只记一次调用。TRAIN 反事实多分支可离线生成，但单独报告训练成本。

虚拟时间冻结的事务模式仅支持“物理完成时间与计算/证据成本分列”。若要声称实时收益，另加异步模式：求解期间机器人继续执行；返回候选对当前前缀重新校验，过时/冲突就回退；host latency、截止错过与计算竞争真实进入该模式。不用人为常数把 host 秒和运动 tick 相加冒充已测实时效果。

## 3. 正式作者基线与内部对照

|类别|方法与用途|可声称的实现身份|
|---|---|---|
|正式外部算法|固定原作者 GSES、Improved GSES；相同公开视图、相同搜索上限与共同执行层|固定 STPG commit 的真实算法；新增 adapter/guard/执行层单列，不等于原 CLI 原始性能|
|固定策略|保持原图；固定购买后 Improved GSES；仅公开信息固定 Improved GSES|本研究内部强规则，隔离调用、证据与采用价值|
|同信息规则|TRAIN 冻结的简单门控，在三个 option 里选择；阈值仅用 CAL|内部对照，输入与预算和模型一致；不得用 TEST 选择最佳规则|
|最近学习对照|公开 ADG 特征预测不调用/调用的完整执行差，再门控 Improved GSES|若仅依论文重实现，应称 Should-I-Replan-style 适配；未定位并运行作者代码前不称作者复现|
|模型及消融|三 option 完整价值选择；相同数据/容量/校准的 no-history 模型|内部新方法候选；消融精确说明去掉哪些输入，不能把尾策略仍用历史称为全系统无历史|
|现有查询线|C、LD、整程 WAIT、按预算 TRAIN 查表|模块对照与独立机制证据，不能填进正式外部算法栏目|

正式 TEST 首版锁定 8 策略：保持原图、公开 GSES、公开 Improved、固定 paid Improved、简单三 option 规则、public-only 二选一价值门控、学习三 option、学习三 option 的历史输入消融。规则和 public-only 门控同样训练/校准并冻结。不能仅赢保持原图就声称优于作者方法；主要比较对象预先锁定公开 Improved 与最强同信息规则。若需要新增 ESADG 的直接对照，应先完成其代码/预测器数据/调用预算适配资格，另立版本，不能用不完整本地替代品代表论文。

## 4. 数据、独立单位与误差采样

使用 MovingAI 官方地图及完整 scenario 文件；主表覆盖 `empty-32-32`、`random-32-32-10`、`maze-32-32-2`、`warehouse-10-20-10-2-1`。建议规模分别为 {20,40,60}、{20,40,60}、{10,20,30}、{40,80,110}。这些是待注册的绝对规模，不暗示不同地图的拥堵程度相等。另报自由 cell 数、占用比例、路径长度、冲突/依赖量和无解率。所有 agent 数都在所选官方 scenario 长度范围内。

原始 scenario 文件是保守的隔离与统计簇：同文件的不同 agent 前缀、路径求解 seed、误差 seed、checkpoint、预算和策略均不能跨 TRAIN/CAL/TEST。不能只改变 seed 或文件行 offset 就宣称地图外泛化。原始实例 key 至少绑定 map SHA、scenario SHA、初始 agent 前缀、路径生成配置；统计时再按上层 scenario 文件聚类。官方 random/even 类别分层；若发现跨文件完全重合的 starts/goals/path 集，用连接分量绑定到同一 split。R13 与历轮已见实例永久列为开发集，排除新留出。

先在未见结果的文件清单上按地图、random/even 分层，用固定盐的哈希顺序分配。每图 50 个官方文件先划出阶段 B 的 10 个开发/有限验证文件；其余 40 个供阶段 C，拟分为 20 TRAIN、6 CAL、14 TEST，总计 80/24/56 个正式文件簇；这是已见地图上的新实例泛化，不是新地图泛化。任何旧实验污染文件只可转开发集，缺额使用登记前列明的未见官方文件/新生成完整 scenario 批；不得观察运行效果后替补失败例。旧文件排除可能使每图不足 50；此时上述数量只是上限，注册前优先按同样分层比例下调文件配额并重算运行数。若采用额外生成的 scenario，必须另标“官方地图上的新生成场景”、冻结生成器与可行性规则，不能继续称原官方 scenario，也不与官方文件无区别地合并。新地图泛化应另留整个 map 文件，不将同图换起点写成跨地图。

候选误差族在所有策略间共用，建议先四类：E0 精确名义 primitive；E1 每个 MOVE 的独立随机减速；E2 agent 持久异质速度；E3 相关 burst/pause。注册中固定 E1 倍率、概率和 E2 agent 分配；E3 开始事件由外生 primitive 身份决定而不是策略到达的时间。一个可执行起始值是 E1 每 MOVE 概率 0.1 倍率 2，E2 概率 0.1 的 agent 全程倍率 2，E3 每 agent 概率 0.1 在预定 occurrence 产生 2 tick pause；TURN 与 STATION 名义合同单列。数值只允许在开发资格阶段作可行性调整，并在正式 TRAIN 前冻结；不是已测作者误差设定。

误差各两组登记 seed，均属于同原始实例的重复。域移另用不在 TRAIN/CAL 出现的强度或相关结构，作为整块外推 TEST，不与同分布主结论混合。固定主 decision 门可取原公开名义计划 makespan 的 1/4 之后首个合法机会；门条件依赖公共量、所有分支共享门前前缀。无门照常算完整结果，不补样。多个 checkpoint 只用于预检或预注册敏感性，不作为独立样本。

## 5. 指标与统计

固定批次且最终任务全完成时，主指标为每实例平均完成时间 `Σ_i T_i / n`，并报原 ΣT；跨规模总体先算实例差或相对差，再按登记权重平均，不能直接让大 N 决定 pooled ΣT。必须同时报告 makespan、失败/碰撞/死锁/超时、采用率、solver 调用数、证据次数、host 时间、可取得的真实 guest actual/charged 成本与峰值内存。QUERY 次数不是 guest 工作量。任务吞吐只在固定有限 H 的持续任务版本中作主项，不能在任务数恒定时宣传吞吐改善。

安全与成功是硬约束。固定批次先按失败率/完成率比较，再对未完工使用预先登记的 horizon 受限时间和删失标记；不得仅比较双方成功交集。共同 H 可由未看执行效果的名义计划上界确定，例如 `max(1000,10×nominal makespan)`，并原样用于所有方法。报告对 horizon 的预注册敏感性，不偷偷延长困难方法截止。

makespan 首版为必报次项和应用约束：若应用要求其平均相对回归不超过 2%，在 CAL 选模型时写入约束，TEST 报成对回归的单侧 95% 上界；超界则不声称适用该应用。2% 是待确认的工程容忍值，不是领域公认标准。费用同样使用事前预算上限与实际支出；未给应用兑率时展示时间—费用 Pareto 表，不给任意加权总分。

主要分析按 scenario 簇做分层配对 bootstrap（地图/生成类别分层，同簇所有规模/误差/预算保留），报告 95% 区间、地图和误差分层效应、胜平负及失败。正式 TEST 56 文件簇才是最大独立簇数，不是数千个臂。冻结两个主要比较并处理多重比较，其余消融标探索；不要用多个 checkpoint 当作扩大显著性的样本。除总体改善外，列出最差地图/误差层和 makespan 代价，避免平均值掩盖系统性退化。

## 6. 分阶段运行额度与停止规则

|阶段|固定规模与运行上限|进入下一阶段的条件|
|---|---|---|
|A 接口资格|2 地图 × 2 个开发实例 × 2 checkpoint × 2 误差 × 3 option = 48 完整分支；最多 32 solver 调用|完整独立资源/连续几何/前缀/费用审计全通过；至少两个不同原始实例出现可解释的 public/paid 候选或执行差异；拒绝/超时回退有效|
|B 有限学习|从正式清单先取每图 4 TRAIN、2 CAL、4 TEST 文件簇；每簇取规模表的低/中两档 × {E0,E1,E2} × 1 seed。24 TC 簇 × 6 × 3 option = 432 分支；16 TEST 簇 × 6 × 8 策略 = 768 分支，总 1200|完成训练、CAL、冻结、真实部署；所有实例保留。若输入有异质后果而模型未超固定策略，记录有限负结论，不在这 16 TEST 上调阈值|
|C 论文主矩阵|剩余 160 文件簇分为 80 TRAIN/24 CAL/56 TEST；每簇 3 规模 × 4 时间误差 × 2 seed。TC 104 × 24 × 3 = 7488；TEST 56 × 24 × 8 = 10752；合计 18240 完整分支|B 全部 40 文件簇保留为开发/有限验证，C 使用剩余新文件；不论 B 是否积极，均不把 B TEST 并入 C。C 注册前锁定最终模型/协议，不能混报成一次预注册大留出|
|D 异步/域外扩展|每项独立注册：异步 solver 过时处理、新地图外推、持续任务|仅在前阶段已建立有效接口和有界收益后启动；具体数目按前阶段方差及资源评估确定，不默认全开|

阶段 C 是建议上限，本轮没有启动；是否进入按接口证据、资源测算和新登记决定。若单臂 1–2 分钟、6 并发且无共享瓶颈，1200 分支约 3.3–6.7 小时，18240 约 50.7–101.3 小时；solver/审计/失败重试会增加实际成本。先用资格阶段确定资源上限与截止，再冻结批次。下一实际推进先完成 A；B 可按资源减少同簇重复规模/误差/seed，优先保留独立实例簇，不能把运行总数当作 MAPF 认可的门槛。CPU、内存和审计并发分别限额，不靠反复 OOM 后挑存活结果。

阶段 A 若 paid 视图被量化完全抹平，或无法保留原作者合法性，停止“付费证据价值学习”入口并报告原因；可继续作者共同执行平台，不能靠更多模型寻找伪差异。阶段 B 若取得证据有后果但最佳可行 option 相对固定作者基线的完整价值空间极小，报告候选空间限制；该事后诊断不称部署 oracle。若确有空间而模型不泛化，只允许重新立新版本/新 TRAIN/CAL/TEST，不能无限扩大同 TEST 找正值。阶段 C 在首次注册完成后无按显著性追加样本；误差修复导致重跑时保留失败与版本关系。

## 7. 何时才使用 LMAPF 名称

当前一次固定路径批次中反转依赖、重复 checkpoint 或长时间执行都仍是固定路径 MAPF 执行。只有加入预先公开规则的持续任务到达/分配、完成后新目标、滚动路径规划、FIFO/服务定义，以及跨规划窗承诺和安全验证，才构成此计划中的 LMAPF 扩展。该版本需重新定义 throughput、有限 H 的受限完成时间、队列稳定性和 planner 预算，并加入适用的原作者 lifelong 方法；不能把 GSES 的固定路径排序当成它们的完整替代。

## 8. 直接来源与发表边界

[MovingAI 官方 MAPF 基准说明](https://movingai.com/benchmarks/mapf.html)明确提供 random/even 两类场景及逐步增加 agent 的用法；[具体下载表](https://movingai.com/benchmarks/mapf/index.html)列出上述地图、场景数量及规模。本文在 2026-10-04 重新访问两页。它们支持基准来源，不规定唯一正确的统计检验、样本数或 SCI 分区资格。

[Improved GSES，AAAI 2025](https://ojs.aaai.org/index.php/AAAI/article/view/34487)和[固定作者 STPG README](https://raw.githubusercontent.com/DiligentPanda/STPG/25fb931eff03f1cce23a22a68ab42b7533f85ab3/README.md)本轮已复核，用于作者算法与工件身份。最近学习差异依据 Astra 本轮全文复核：[Should I Replan? §III-C/IV-B](https://arxiv.org/html/2604.25567v1#S3.SS3)学习完整执行 SOC 差，且另讨论算时，不能将其概括成只预测时长或忽略计算；[REMAP/ESADG](https://arxiv.org/html/2511.21886v2#S4.SS3)已有预测执行目标与固定路径图优化。具体证据及作者工件状态以[同目录近邻全文核查](NEIGHBOR_METHOD_AUDIT_20261004_R13.md)为准；未验证到代码不是代码不存在。

可争取的论文贡献是有明确信息缺口和获取成本、能影响合法动作、在新实例上可泛化的完整执行价值选择。可信接口、真实作者方法适配、精确重放和负控制是支撑证据；小规模 ridge 成功也不能单独满足新颖性。SCI 二区/三区作为投稿定位需要等统一对照、结果稳定性和具体期刊范围核对之后讨论，不由这份计划或实验数量保证。
