# 研究问题与首检合同

2026-09-24。状态：空间误差相关路径排序的有限可达见证通过；学习机制、在线接线、lifelong 任务收益和完整费用尚未验证。

## 问题与边界

研究问题：在相同机器人足迹、空间误差承诺、可信证据、安全准入和在线资源约束下，能否利用合法可见的信息预测局部占用/等待代价，以路径引导提高长期任务完成量？

空间误差指机器人实际足迹相对于名义路径的有界二维位置偏差，含横向误差。延迟或动作持续时间可能影响等待，但不能替代该空间约束。安全层始终对固定足迹与完整误差盒做几何占用计算；学习模块不能缩小误差盒、改足迹、直接删除 owner、放宽严格释放阈值或授予运动权限。

候选学习接口只输出路径边/区域的占用或等待代价建议，路径规划器生成候选，既有安全层检查实际准入。当前目录尚未实现该模型、特征数据接口或在线规划器，不能把有限参考路径的结果当作已存在的线上 guidance。

## 与相邻方向的区别

| 方向 | 决策对象 | 本目录采用或另行验证的部分 |
| --- | --- | --- |
| 既有 `explore/learned-query` | 在已存在需求/责任图上选择向谁查询进度；模型预测证书是否严格跨越释放阈值 | 保留证据与退休约束，但本方向改变路径选择；不能把原查询排序检查当作路径引导收益 |
| OnlineGGO | 在线交通信息驱动的格点 guidance；论文冲突模型采用顶点/交换冲突，优化训练包含 CMA-ES | 是学习路径引导的相关参照；空间误差、连续足迹及可信释放需要另接，不能把格点成功直接称为误差安全 |
| 当前首检 | 手工指定两条候选路线，在四个配对条件中真正执行有限组件过程并比较到达时间 | 仅判定误差相关等待是否可能改变排序；没有模型、在线最优选择或 lifelong 任务流 |

OnlineGGO 的上述定位依据论文 [§2.1 和 §3.2](https://arxiv.org/html/2411.16506v2)，官方作者仓库为 [zanghz21/OnlineGGO](https://github.com/zanghz21/OnlineGGO)。本次没有复现其训练/运行，也没有核验仓库最新状态。模型小不表示基于大量黑箱评估的训练便宜，后续需单独核算。

[S2M2](https://arxiv.org/abs/2012.09052) 可作为有界执行误差下安全规划的相关文献入口，不是本分支已复用或已验证的 lifelong 学习底座。

## 首检的可否证命题

命题：存在一组共同输入，使同起终点的两条候选路径在零误差与非零误差盒下均安全可执行，但因真实 owner 释放等待造成的到达时间排序不同。

必须同时满足：

1. 两候选都有完整可达运动，等待时有合法驻留足迹，每段完成同一个原 MOVE 后才结束并进入下一段。
2. owner、需求关系和阈值由真实 Geometry/Index 生成；只有真实 PositionCommit 提交的合法匹配下界可退休 blocker 责任，prepare 阶段不能提前释放。
3. 两条路径和两个误差条件保持共同足迹、资源划分、控制参数、阻塞机器人外生行为、证书精度与观察时刻；不得为某一路线另发观察机会或填任意代价表。
4. 到达时间由逐段实际 ReferenceController 运行和合法准入等待累计；事后参考结果不进入线上准入判断。

若出现初始资源重叠、等待驻留丢失、阈值不可严格跨越、终点责任妨碍后续、跨段原 MOVE 生命周期不相容、观察之前知识提前更新、任一路线无法完成，或结果不反转，该程序必须失败。失败记录保留，不能通过改输出/去掉 owner/调整单一路线观察时刻制造阳性。

## 自包含人工构造

空间使用同一 273 个闭方格：中心 x 为 −1 至 9、y 为 −3 至 3，步长 1/2，每格边长 1/2。覆盖范围 `[−5/4,37/4] × [−13/4,13/4]` 包含所有路径的足迹和误差扩张。所有机器人固定世界朝向，足迹均为实心方形 `[−1/10,1/10]²`。两条件的误差盒分别是 `{(0,0)}` 和 `[−1/5,1/5]²`；每组的请求者与阻塞者都同时使用本组相同 Z，并非只放大某一个机器人的占用。

机器人请求者从 `(0,0)` 到 `(4,0)`，选择上绕或下绕的三个直线原 MOVE。每个转折点先到达原终点且参考速度为零，再结束该原 MOVE、保留终点驻留责任，才开始下个原 MOVE；足迹朝向不随路线转向旋转。本例不处理非完整驱动小车的转向约束。

阻塞机器人固定从 `(2,3/2)` 运动到 `(8,3/2)`，原长度及本地已安装 cap 均为 6，行为不因请求者路线变化。初始先建立两机器人驻留责任，再检查其完整扫掠 mask 不碰请求者起点，才通过 native admitted-update 授予 blocker 全 cap。请求者每段也要检查所有将获取的资源为空或归自己，不能只因少几个 mask 元素就假设动作合法。

所有 ReferenceController 使用相同人工数学系数 `δ=1, a_lo=2, a_hi=6, a_launch=1, η=−1`。这些系数仅属于具名有限夹具，不是研究配置或机器人能力声明。程序实际推进原控制器的自主边界直到 closed，不直接填入段耗时。段长为 L 时该夹具产生到达时间 `√(3L)`；末尾的闭式表达式只独立核对实际结果，不参与等待/路线选择。

所有配对条件在 `t=4` 都获得同一次外生进度观察，不管本路线是否需要等待。真实阻塞控制器此刻尚未到原終点，下界取其精确进度 `24√2−28`；人工精确区间 `[s,s]` 满足声明精度 `1/100`。这里的证书精度与空间误差盒是不同量。证书捕获、交付和组件提交在该固定机会重合，没有据此设置研究通信延迟。

本程序只执行标量参考进度，不积分二维扰动 z。可选择盒内合法轨迹 `z=0`，把每段进度嵌入其固定直线路径，得到存在性的空间可达见证；占用安全检查仍覆盖完整非零盒。它不是二维扰动鲁棒性运行试验。

## 实际机制与结果

非零误差时，上绕第二段经过 y=1，其扩张包络与 blocker 的资源责任相交；真实 Index 返回一个 retirable 关系，严格退出阈值为 `61/20`。请求者在 `(0,1)` 静止，持有自己的驻留资源；即使私有 blocker 已经运动，中心 q 仍是 0，直到 `t=4` 的 POSITION 实际提交。prepare 时保持旧根，提交后再检查空关系与真实 owner 表无外国责任，然后授予第二段。

所有观察均检查 blocker 原终点资源仍由它持有，查询没有删除终点责任。请求者每段结束只删除属于该原 MOVE 的资源，随后把终点 mask 转成自己的 stationary owner。下一段开始前再次检查起点驻留资源。四次执行各完成三个原 MOVE，并各提交一次共同观察。

| 条件/路线 | 实际运动到达时间 | 因 owner 等证据的时间 |
| --- | --- | --- |
| 零误差，上绕 | `4√3` | 0 |
| 零误差，下绕 | `2√3+2√6` | 0 |
| 非零误差，上绕 | `4+3√3` | `4−√3` |
| 非零误差，下绕 | `2√3+2√6` | 0 |

这些值来自实际组件执行；并非预置一个任意学习 cost table。比较只在这两条给定路线、同一固定 blocker 和预先共同指定的 t=4 观察安排上成立。反转是误差包络 × 固定观察策略 × 保守准入规则的条件结果；更早观察可能恢复上绕优势。这不推翻本安排下的存在见证，但限制其对其他观察策略的迁移。没有枚举所有可能路径、观测策略、cap 策略或反应式多机器人行为，因此不是全局最优上界。构造旨在检验存在性，不代表真实地图中的出现频率。

完整原生输出、精确显示区间、实际命令和 SHA 在 [precheck_run_20260924_01.json](precheck_run_20260924_01.json)，共 790 项断言。源码只从 [source_pins.json](source_pins.json) 指定的本地主线头文件临时原样复制；本分支不上传主线源码。

## 哪些边界尚未闭合

`non_owner_eligible=true` 明确预设其他准入条件已满足。程序没有验证生产规划器、业务任务、服务机会、AUTH 或消息来源。证书是绑定真实可达控制器状态的人工 native admitted-source；END 则基于同 MOVE 已 closed、s=ell、v=0 的原生生命周期前提。PositionCommit 接口接受这些已准入输入，不替它们做来源认证。本例通过的是这些前提下的空间/运动/责任机制，不是生产全域资格。

到达时间只包含参考运动与等待，未含生成几何、搜索路径、观察请求/交付、推理、维护与服务的完整费用。四个条件观察次数相同仍不意味着观察成本等同或已计费。也没有任务完成服务、长期任务流、拥堵反馈、死锁/公平性或规模性能结论。

零误差与非零误差改变的是安全包络，不改变控制系数或把横向偏差换成动作延时。排序反转发生在它们对相同 owner/证据制度产生的等待差异上；实际执行时刻可以因合法等待而内生变化。

## 下一步先比较什么

先做共同观察时机对照，以及几何间隙/误差盒变化下的稳健性检查，区分只在特定观测安排成立的潜力与更广泛的路径选择价值；这两项尚未运行。随后保留无学习的长度/运动代价选择、使用合法已提交 owner 的简单误差感知代价，以及同一有限数据上的参考选择。若简单误差感知规则已获得全部可用改进，学习模块必须证明额外价值，不能把安全包络改造或更换路径评分本身归于学习。

未来模型输入只可使用选择时已知的几何/误差承诺、任务与路径候选、已提交 q/b/owner 关系、合法历史与已交付成本。已知原 MOVE 终点和已授中心 cap 可以作为合法信息；中心 cap 不能冒充本地已安装权限。私有真值、未来证书、未来实测阻塞行为和未执行候选的反事实结果不得进入线上特征。合法离线仿真产生的反事实结果可以作监督标签，但必须隔离标注来源，整次场景/运行一起切分留出，不能将本例四个近重复组合拆成训练与测试。

首要评价应是固定外生任务和资源条件下真实任务完成量，同时报告失败/安全检查、等待、查询与全部在线费用。有限到达时间、标签预测误差和更低拥堵分数只解释机制，不能替代该终点。当前尚未到这一阶段，也没有授权读取研究载荷或启动训练。
