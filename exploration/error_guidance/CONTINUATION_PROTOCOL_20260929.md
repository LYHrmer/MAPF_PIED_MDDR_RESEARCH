# 两任务几何等待判别：运行前冻结

2026-09-29。探索性 native 机制实验，不是标准 benchmark、真实机器人数据或全费用评价。继承固定 footprint、273 资源、原 Geometry/PositionCommit/ReferenceController、公开 blocker 运动先验和 requester 已交付 END 校准。

问题：相同 requester 运动校准和观察制度下，非零二维误差引起的 owner 证据等待能否改变连续两任务的路径选择？强解析是否仍留有可用于学习的残差？

任务1从 `(0,0)` 到 `(4,0)`，任务2在任务1真实 END/驻留交接后从 `(4,0)` 到 `(6,0)`；各自候选均为经 `y=1` 的上绕 U 或经 `y=-2` 的下绕 L，三段原 MOVE，固定世界朝向。任务2为预先公开、仅在任务1完成后激活的任务，不是偷看未来随机任务。四个完整组合 UU/UL/LU/LL 全部独立实际执行；离线结果不回输选择器。

固定实例表（笛卡尔积，不增删失败或不利条件）：

| 因子 | 固定取值 |
| --- | --- |
| 双方空间误差盒 | Z=0；Z=[-1/5,1/5]² |
| requester 历史及未来固定运动条件 | eta=-1；eta=+1，仅物理引擎可读 |
| 一次共同 POSITION 机会 | 5/2；4 |
| blocker END 制度 | 无后续 END 的诊断；真实 closed 后+1/4交付 native END |
| 完整候选组合 | UU、UL、LU、LL |

共16实例、每实例4组合。每实例先执行两个独立历史单MOVE（长度1、2；全局0、4开始，END+1/4交付），评价全局原点10。固定独立运行身份；选择器只接收长度、开始、END与收到时间导出的同一 alpha。历史条件与未来保持是明确仿真假设。拟合 `D²=alpha L` 与最后 END 的 `D²/L` 解析校准并列核对，不包装成学习优势。

决策器在任何评价路线执行前冻结：运动对照最小化同校准总运动；强解析利用真实公共 geometry/owner 阈值、严格越阈、已声明 observation 时刻与源精度、公开 blocker 先验以及 END 制度，先最大化预测完成任务数，再最小化两任务完成时间（未完成则已完成前缀时间），最后固定 U 优先破同值。安全授权始终来自实际 owner/Index 与 PositionCommit，预测不写 q、不退休 owner、不授 cap。

正常 END 必须来自实际 blocker Controller 闭合、原终点且静止的见证，再经过已声明1/4交付。交付前 owner 不因真实进度自动退休；交付时只删除该原 MOVE 的 owner，保留终点 stationary owner。终点占用不能借 END 消除。此新增 native 接口不声称实现生产 AUTH、网络或收费。

共同截止24是所有预声明自由运动路线的宽松观察窗口，不用于搜寻正收益。证据不足时继续合法驻留到截止，保留 pending 和 owner，不补查询；未完成的到达为 null。已完成结果记录两任务各完成时间、完成数、累计运动与 owner 等待；截止内完成状态、完整候选参照的选择损失、预测残差只在执行后计算。两个证据制度均报告，不能只报告缺END的极端设置。若强解析已解释全部变化，结论明确不支持新增复杂学习必要性。

运行上限：一次严格编译120秒；每个具名实例 native 60秒，超时/失败保留。不扫参、不修改旧源码/回执/固定主线头。原始stdout、命令、SHA与前后保护哈希全部保留。未知的正式外部基线、R0完整适配与全费用规模证据保持待补；已有隔离探索授权不等同正式选题通过。
