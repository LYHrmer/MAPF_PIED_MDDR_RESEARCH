# Fixed real planner/executor integration pilot

Declared before compilation/native execution, 2026-09-30.

Only two fixed trials: author LSMART front_fig_5x5, 2 robots at original smoke03 starts (row0,col0),(row2,col0), seed42, 200 ticks at 10Hz. The map transform is author ARGoS x=-row, y=-col. Trial nominal has no added disturbance; trial pause holds robot0's controller/wheels during ticks30..49 inclusive. This is a physical execution pause, not a spatial-error experiment. Native PID tracking remains present in both trials, so nominal does not mean mathematically zero tracking error.

Use official Guided-PIBT commit7f4b91e4 (existing disclosed seed42 successor), GP-R100-Re10-F2, unchanged algorithm objects. A persistent stdin bridge calls one official plan() only from the latest LSMART public task/state view at jointly finished and settled boundaries. Native LSMART parser/ADG/controller/ARGoS remain the execution chain. New synchronized invocation semantics are an R1 adapter and are not author native asynchronous throughput or R0 conservation. LSMART is a testbed, not a competing algorithm.

LSMART get_location normally returns a future commit cut. Here all prior ADG nodes must have actual controller acknowledgements and both queues must be empty after a previous zero wheel command before querying it. No future nominal grid rollout is supplied as measured state. One visible goal per robot is assigned by the author OneGoalTaskAssigner, sampled by its original seeded task source at query time. The planner never receives pause condition/future pose/next task labels.

Build steps limited to120s each; whole integration trial60s. At most two implementation-debug retries per failure are allowed, retained and disclosed; no parameter search or selecting best results. Independent replay checks plan adjacency/obstacles/vertex/edge conflicts, action acknowledgements against delivered controller poses, task ownership/location/END causality, samples/residence and sampling-only separations. Negative trace corruptions must be rejected. Record all failures, pending actions/tasks, costs and hashes. End-of-horizon is censoring, not synthetic END.

Before final native runs: build_bridge first link omitted boost_thread and was corrected. nominal_attempt01 was blocked by sandbox sockets and retried through explicit escalation. nominal_attempt02 executed one real joint action then official LNS crashed on its next invocation: default group_size10 exceeds N2 and flow.cpp still indexes group_size entries. The sole support adjustment is the author's exposed LNS group_size=2, set after initialization; original algorithm object files stay byte-identical. This is GP-R100-Re10-F2 with group2, not the prior group10 R0 configuration. Joint settled additionally requires actual sampled displacement<=1e-6m over the preceding tick with a previous zero wheel command. These are corrections, not performance tuning. All failed attempts are retained.
