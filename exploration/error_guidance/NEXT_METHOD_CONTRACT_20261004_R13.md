# R13 后的方法合同：学习有限证据下的完整执行价值

下一阶段把三条线连接到同一个决策问题：公开执行历史已经存在、预算有限、部分动作已经承诺时，购买额外执行证据是否值得，以及取得证据后是否应改变后续执行。这里的贡献候选是信息、承诺和任务后果之间的关系。更换回归器或增加预测头只是实现选择。

本文件是下一阶段设计，不代表以下统一接口和训练已经在 R13 完成。R13 已完成的事实以三线报告为准；旧 TEST 保持冻结，不能改成新训练的验证集后继续宣称留出。

## 主线：从已封闭接口走向共同决策点

保留 R13 的 verifier 私有 SOURCE/history 与 scheduler 公共 END 接口、完整 occurrence 绑定、原 POSITION 证据安装和 Natural/Strict 分账。不再把只改初始化/复制的微优化作为下一轮主要工作。

先建立共同决策点的数据适配合同，列明正常 END、公开路径/已发承诺、已观测资源状态、付费 POSITION 及私有核验数据。第三线当前直接公开的 arrived state/occupancy 必须逐项说明来源；不能在统一实验中把本应付费才可知道的开放进度免费传给决策器。将付费证书送入真实候选生成/认证释放，再由原 guard 检查采用。仅拷贝预测数值到日志不算接入。

验收要同时看完整调用来源、原始费用归属、当前身份的证据安装、真实后续 RUN/service 和失败回退。模型推理、特征生成、验证与复制如果进入同一收费 guest 就全部入账；在接入以前，查询线的 query 次数和 host inference ns 仍不得换称主线生产费用。

## 查询线：保留已有学习对象，扩大证据而不按 TEST 调模型

继续以实际已测 C/LD 完整尾策略、真实半预算晚点、任务数优先和固定 FIFO 完成时间为对象。R13 模型、阈值和原始 TEST 全部封存。本轮结论决定下一轮应扩展哪种机制，但任何新学习器、更多候选或阈值都须在新 TRAIN/CAL 上确定。

下一轮至少要回答三个问题：条件模型是否胜过固定 LD；剩余预算是否改变最优尾策略；历史概率是否比仅公开几何和预算提供额外选择价值。当前 no_history_prob 仅移除两个概率槽，不能据此判断整个系统历史无用。先按独立 scenario/error family 报成对任务、时间和 query 差异，再做 family 层不确定性估计；两个预算不是两份独立样本。零 gate、未触发第二个 SKIP、超时和退化都留在意向策略结果中。

R13 中 C、LD、WAIT、预算查表属于内部强对照。正式论文必须另有同问题、同信息、同物理误差和同任务流的作者方法比较；不能用自设弱策略代替领域基线。扩展地图、密度、误差结构前先保证作者方法接口与公平预算，避免把更大运行数量当作泛化证据。

## 第三线：从真实异图采用走向代价敏感选择

R13 已证明作者候选能在执行中合法采用，而且真实后果有正有负。固定批次所有任务完成时，主要目标采用平均完成时间 ΣT/n，同时保留原 ΣT；不能用恒定任务数伪造吞吐标签。makespan 另设预测/报告项。若应用要求 makespan 不退化，则在训练前固定允许回归阈值，并使候选选择遵守该阈值；不能看完测试再挑主指标。

下一步的最小完整 option 集为：

1. 保持当前合法图并继续执行。
2. 只用合法公开信息调用固定作者 GSES，经过同一 guard 后采用或回退。
3. 购买一次合法 POSITION，使用所得证据更新有依据的当前执行估计/认证条件，再调用同一作者 GSES，经过同一 guard 后采用或回退。

这里不能把 POSITION 当成 ARRIVE，不能提前提升 current 或绕过 active 承诺。最小候选方案先只用证据改善当前未完成边的搜索代价估计，实际执行图的 type1 与原 guard 保持。证书输入先独立验证，再生成 search-view；R13 现有 `public == public_input(engine)` 检查会拒绝直接篡改视图，需要显式的新接口，不能就地改原 public 字段。

源码资格也必须先过：作者 COST_TYPE 是 float，但当前冲突/终止判断与启发式含单位步长假设；R13 validator 还要求当前边整数≥1、未来边=1。第一项机制实验只测试事前确定的 ceil/max(1,·) 当前边估计，未来与type2保持单位权重，lift后恢复真实执行type1。取整可能吞掉所有证书增量，必须记录此结果。若需要分数边权，则另立明确算法适配、启发式/终止正确性验证及作者原版对照。若要改为证书认证的提前资源释放，同样须另改执行语义并核验连续几何，不能声称当前 ARRIVE 型 guard 已自然允许。

固定每个 option 后的继续策略，以完整后果监督 ΔΣT/n、Δmakespan 和费用/预算消耗。超时、拒绝和无变化候选也进入标签，不能只拟合成功优化样本。购买选项必须先通过少量完整成对运行证明它确实改变候选或后续执行；若完全等价，先修改有依据的信息到决策接口，不急于增加网络规模。

第一版可用透明的线性价值模型，再将小型 MLP 作为训练集内确定的容量比较。需要固定原图、固定作者 GSES、只用公开状态的调用门控、固定购买和条件购买对照；GSES/Improved GSES 均保留作者源码版本，适配补丁单列。训练与测试按新原始实例划分，不能把同一实例的 checkpoint/profile 当独立留出。

求解器耗时当前发生在冻结的虚拟检查点。要主张实时收益，后续必须独立实现求解期间机器人继续执行、结果可能过时和重新核验的实验层。当前先将 host 时间、真实 guest 费用和物理完成时间分别报告；没有事前应用兑率，不把它们随意相加。

## 对发表工作的取舍

R13 近邻核查见 [文献记录](LITERATURE_CHECK_20261004_R13.md)。Should I Replan 已研究从公开执行状态学习重规划调用价值；执行时间预测与图重排也已有近邻。若第三线只做公共状态上的“GSES 或不 GSES”，区别仍然偏弱。更值得验证的是有限付费信息如何改变受执行承诺约束的合法候选价值，以及这种收益能否覆盖获取和计算成本。

主线提供可信信息与收费接口，查询线提供完整后续价值学习经验，第三线提供真实作者优化及异图执行。优先形成一条共同问题和可复核的作者基线实验链，再决定哪一支单独成文；不因 SCI 二区/三区目标降低对基线、实验单位和结果归因的要求。
