# 根独立复核范围

本目录只存根编写的R13第三线复核，不导入候选executor或候选guard来代替验证。复用已冻结R11根几何审计的精确有理数线段算法，保持其来源哈希；事件与图采用检查针对本轮初始图、候选图、实际采用event_seq和完整轨迹另行实现。

核验项：作者输入来自决策时已公开的state/承诺/路径；原路径、type1、初始current保持；新type2仅在原合法反转族内，已执行/active incoming保持，无环；采用之前使用原图依赖，之后使用实际选定图依赖；同checkpoint前缀与活动MOVE未来承诺保持；各MOVE真实到达才释放type2，CELL_ENTER=2/5、CELL_EXIT=3/5，TURN/STATION与goal保留占用；每agent全程连续覆盖，圆盘轨迹在各段内部也不相交；从原始完成事件复算sum completion和makespan。

没有新图、作者失败/超时、守卫拒绝均完整保留并核原图回退。图改变、实际采用、完整执行改变、目标改善分别计数，不相互替代。计算调用在暂停的仿真事务内执行，host耗时单列，本轮不证明包含真实计算延迟的实时改善。固定路径一次执行也不能称作持续任务LMAPF。

根只核已登记的两个case、两个时点、三profile、三种continuation，共36条完整执行与24次真实作者调用，不按结果增加输入。当前为有限执行接口与研究适配验证，不是新heldout性能比较。原R11所有审计文件保持字节不变。
