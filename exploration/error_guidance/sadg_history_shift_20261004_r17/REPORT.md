# R17 SADG：历史失配可使位置有调度价值，年龄与目标取舍限制收益

本轮完成预登记的3条件×3输入共9条记录，**新增1次原作者MILP、3条唯一事件后缀**。其余8个求解输入与已有模型完整相同，精确复用；短暂停滞的两条真实状态后缀也直接复用R16。没有重复原生回归、旧地图实验或事后扫参。

**稳定历史条件下位置无增量；历史之后发生短暂停滞时，位置改变顺序并减少累计完成时间；持续减速时新鲜位置改善累计完成时间，但恶化 makespan。** 年龄0.25的位置改善预测误差，却在本次作者平局选择下产生零执行收益。结果只能说明这个固定路径单次调度机制，不能写为LMAPF吞吐、付费净收益、真实机器人安全或泛化改进。

## 同一强公共模型下的结果

公共模型使用全部已交付 END 历史：A/B各一个2m/1s动作，当前启动A=0、B=0.25；所有未完成动作的预测时长均1s。无测量与测量臂使用同模型，POSITION只更改当前残余边界。decision/delivery=0.75；测量新鲜或捕获于0.5后延迟0.25。年龄推进点预测采用公开历史速率，真实后续速度不输入优化器。

ΣT从共同decision状态计算两agent各自完成余下路径的时间之和，makespan取最大值；不是先验模型目标。作者MILP含EPSILON=0.01，不能直接把目标13.24当上述真实ΣT。持续半速新鲜臂ΣT减少5.5同时makespan增加0.25，应作为两个目标的取舍报告，不能笼统称所有指标改善。

年龄0.25的半速捕获为p(0.5)=0.25，公开速率外推至0.75得到0.5，而真实p(0.75)=0.375。此输入恰使两车预测残余均0.5，两种方向的预测目标形成平局；所固定作者CBC旧解选A先。根R16独立HiGHS枚举的两方向目标分别为13.239999999999997、13.24000000000931；差约9.31e-12是浮点误差，精确有理数关键路径为5.60+7.64=13.24，两方向互换agent后完全相同。**该零收益依赖此可复核平局解，不代表所有求解器/平局规则下年龄必然消除收益。** 没有按更有利方向重求平局。

## 捕获、年龄、作者调用与执行链

`public.json`保存已交付历史与START；`worlds/`保存预登记分段真实执行。模拟捕获积分只截至capture：停滞世界age0.25的capture正文p=0，而age0正文p=0.25；半速世界分别p=0.25与0.375。捕获对象附审计前缀解释，但传入预测器前明确剥除该私有解释。`predict(public, evidence)`不接world、决策真值或未来速度；`inputs/`没有这些字段。

测量下界不推进，上界按公开最大进度速率1外包，点预测才用历史速率推进。本轮所有真值落在记录区间内，但它只来自登记的合成速度边界，**不是生产POSITION/AUTH，不授予cap或几何释放权限，也不给有限完成ETA保证**。生产SOURCE链由主线R17另行验证，不能拼接两世界的身份。

`run_chain.py`调用作者真实 Plan 和隔离 compiler，再调用原SADG.optimize；原optimizer的文件与60秒上限未改。共同 `isolated_k0_plus_all_heads` 来自R16，所有9条记录使用相同编译路径。新的求解输入只读取公开预测progress及duration，实际truth直到求解/guard结束后才用于误差与后缀。每条候选核全部14 vertices、12 type1、1组type2、DAG、共享访问保护和两个IN_PROGRESS承诺；guard不查看truth。

新call为 `speed_shift_position_age0`，OPTIMAL，objective与bound均13.240000000037252，全部约束通过；观察到solver入口返回约0.01149秒，包含同步LP导出，author wall约1.5267秒，不能解释为生产延迟。其余8条完整graph_before（所有状态、时长、进度、forward/reverse、可切换与horizon资格）相等才复用旧模型。age0.25半速输入与R16 `mini_stub`恰好相等，这是旧求解工件的身份复用，**性能对照始终是完整公共历史，未把stub作为强基线。**

后缀按真实当前进度和预登记未来速率驱动作者 `can_execute/set_status/get_next`，没有自写优化器。相同执行图/真实状态/速率复用同一后缀，预测duration不进入实际时长。保存完整开始/完成事件，WAIT和完成后GOAL_HOLD覆盖共同makespan。3条新增后缀用有理数精确检查所有跨agent重叠段，最小点距平方分别4、4、121/20，均无点碰撞。足迹、加速度、ROS时间量化没有建模，不能外推物理控制安全。

## 范围、可复核性与导师判断

冻结协议见[PROTOCOL.md](PROTOCOL.md)，输入/代码hash见[REGISTRATION.json](REGISTRATION.json)，全部结果见[RESULTS.json](RESULTS.json)和[SUMMARY.csv](SUMMARY.csv)。[ARTIFACT_AUDIT.json](ARTIFACT_AUDIT.json)独立于runner重读捕获积分、完整模型复用链、所有保存的线性约束残差和后缀hash，不重跑求解/后缀；这是同代理输出交叉核验，父代理独立核验另记。没有失败科学调用，所有零结果完整保留。

复用记录的 `result.input_sha256/content_key` 继承原求解工件，代表历史输入而非本轮捕获/历史输入。这一字段命名歧义由根审查指出；冻结result不覆盖，以[REUSE_PROVENANCE.json](REUSE_PROVENANCE.json)逐条区分 current_input_sha256、registration_current_input_sha256 与 reused_solver_input_sha256，并保留完整graph等值绑定。根[独立审计](../r17_root_review/SADG_CHAIN_INDEPENDENT.json)已通过9个当前输入/前缀/年龄、8份历史完整模型复用、1新模型两方向HiGHS核验，以及5个唯一真实后缀的有理数依赖/速度/全时域驻留和点距离复算；独立审计未新增作者求解或执行。

相对R16的实质新增是**有明确公共历史/真实前缀依据的失配和年龄链**，以及稳定与持续半速的3条新执行后缀。短停滞实际状态恰与R16旧后缀相同，复用而非伪装新增独立样本。三条件仍在同一手工交叉几何上，不能按9记录当9独立样本或作显著性推断。新的表没有推翻R16“历史1.25条件下测量无增量”；本轮公共历史为真实已完成1.0，然后才改变当前执行。

科研导师后判仍为 **CONDITIONAL**。本轮把“额外信息可能有合法调度价值”的未知关闭为该合成机制中的有条件支持，同时暴露位置正确也不等于残余时间正确：半速新鲜位置误差已为0，但当前残余仍低估0.625，未来动作时长仍系统失配。下一值得做的是同信息、同预算下可解释的残余/未来时长模型及动作价值校准；不能凭这张表直接升级到大网络或宣称提出SADG新贡献。必须先定义独立地图/冲突形状与未看过的速度变化条件，并保留公共历史、平局稳健性和指标取舍。

每测量臂信息次数1、公共臂0，年龄如表；没有生产服务账户、带宽收费或有偿查询净效益，`production_cost=null`。此次公开历史规则是输入adapter，外部算法主体仍是已发表作者SADG；没有声称该规则本身是已发表基线。作者版本、许可、依赖沿用R16可审核工件。
