# R8：分层查询价值数据、真实多源决策与规模留出

R8没有证明历史特征带来独立的部署收益。N16八个新留出world中，history/nohistory都完成345项任务，低于WAIT346和未分段RR/condition350；N32两个规模world中，history166，低于nohistory168和WAIT171。更多训练数据、原生模型评分和实际多候选选择已经建立，但不能把这些实现进展写成学习有效。

本轮完成195次尝试：183次成功物理运行全部到达H128、零死锁；另外12次原N32输入上限拒绝被完整保留。成功运行包括123个训练/校准WAIT与单次查询反事实、48个N16留出臂和12个兼容修复后的N32规模臂。规模修复没有生成新独立测试集。

## 方法与数据的实质变化

使用公开MovingAI empty-32-32和random-32-32-10两张地图。每图3个新训练run、1个校准run；测试每图2个新任务家族，各配对IID/SHIFT；规模留出每图1个新N32 IID家族。FIFO目标由预注册seed从free cells均匀生成，不冒充原作者任务流。地图、scenario行组、全部任务/噪声seed和方法在运行前固定。18个world的起点、未来储备目标及64,854条free-cell有向邻边的闭膨胀sweep均通过障碍预检；实际每个官方动作继续核对地图。

继承未修改的作者OnlineGGO OBJ3持久bridge及配置，保留最多4MOVE公开承诺frontier、current-head FIFO256、cell访问依赖、原exact Geometry/Index/PositionCommit和full-cap ReferenceController，没有全队物理END屏障。原R8的完整Move3/World3及choose之前的END/20feature代码与R7去尾空白后逐字相同。新增native策略只处理名称归一和公开时间预算准入。这仍是frontier适配实验，不是作者按实测当前位置调用的完整benchmark复现。

把H128分成四个公开时间段，每段分别取最早2个单候选和最早2个多候选机会，并标注所选机会的全部候选。8个WAIT训练/校准run保留4243次零候选、522次单候选、34次多候选事件，未选机会也保留在raw中。最终115标签覆盖88机会、65个不同source MOVE：训练87行/67机会/49MOVE/6run，校准28行/21机会/16MOVE/2run。相邻机会可共享MOVE，不能当115个独立样本。

每行执行同一完整前缀下的单次query，之后WAIT到H128。目标为：全run完成任务差，加固定每agent初始前4项的受限完成时间改善除以`2*H*N*4+1`。未完成固定任务计H；次项绝对值严格小于1/2，因此候选间一项任务的差别不会被次项反转。时间次项来自日志区间中点，主任务计数为整数。WAIT定义为独立的零advantage动作，不添加伪造的零特征WAIT训练行。

history/nohistory使用同20维架构、同标签和每机会总权重1；nohistory只屏蔽10..17历史槽。仅训练数据计算加权均值/尺度；固定lambda1、截距不惩罚，标准化模型折回21个raw系数后舍入1e-9用于原生有理评分。阈值固定0，校准不选超参数或策略。模型SHA为`c7d744e6a5dce31c41cd458d5a6894a416388e7fab8cfda28d01dafab29e6004`，在任何测试调用前冻结，兼容重跑也未改变。

全部非WAIT容量16。paced condition和两个paced ridge只允许四时段累计使用4/8/12/16单位，未用额度结转；RR与原condition保持未分段。condition获得同一END历史和声明误差law。这些是内部查询规则，不是虚构的发表基线。查询计数不是生产COST。

## 标签信号与其缺口

训练87行包含73零、14正；校准28行包含25零、3正，没有负标签。4行正值增加1项全run任务，其余正值只改善固定前缀时间。4个任务正例集中在2个训练run，其中相邻机会相关。

存在真实的同机会候选差异：random_train_86101机会23和24中，查询source2完成40项，而查询source12及WAIT都39项；完整反事实前缀一致。但校准集的多候选目标全部并列，没有非平凡候选对可独立检验排序。history/nohistory加权校准RMSE为0.152260/0.151231，history没有优势。

训练目标的后续策略是WAIT；部署后续是至多16次自适应查询。115个probe均核实没有第二次query，而实际部署可在第一次之后继续15次。扩大这类标签不会自动消除后续策略与状态分布失配，也没有学习未来预算机会成本。零负标签尤其不能解释成查询无害。

## N32原始失败与确定性兼容修复

|原失败批次|尝试数|结果|
|---|---:|---|
|empty N32六策略|6|继承的N<=16 constructor guard拒绝；未进入物理执行|
|random N32六策略|6|同上；任务性能不适用|

前期地图预检没有覆盖这个输入上限，是本轮适配检查遗漏。所有原183attempt、12份拒绝input/raw/receipt/stderr、原native源码和模型保持原字节。`scale_guard_successor/`在新注册后仅将native的`robots.size()<=16`改为`<=32`；runner只适配嵌套目录的依赖搜索路径。12份输入与原被拒输入逐字相同，模型同SHA，精确源码diff、二进制摘要与父绑定保留。这是事后兼容修复，不是因性能选择新世界，也不构成额外独立测试家族。

## 核验与结论边界

183个成功臂全部完成独立70位Decimal物理、闭几何、官方访问依赖、真实FIFO服务、候选全集、20feature、有理评分与pacing重放：211,523次原始MOVE、209,348次物理END、253,926帧、895次POSITION。115个标签的完整前缀、主次目标和全候选选择独立通过；增广lstsq重拟合最大系数误差2.55e-13，标准化/raw表达最大预测误差2.22e-16。9项futurehead/history/漏候选/预算/证书区间/依赖/服务/pacing/障碍负控全部拒绝。root另行从raw重算原始60attempt及successor有效60臂，不导入实现runner/pipeline。

本轮的实质进展是新增第二张地图、按公开竞争与时间分层的115个完整反事实、实际多源模型决策、任务首要目标和真实N32规模留出，并获得了更明确的负证据：当前单query后WAIT价值回归及固定pacing不能支持历史增强有益的结论。没有因为结果为负而换seed、删world、修改模型或放宽物理内核。

测试只有4个N16任务家族和2个规模家族；IID/SHIFT配对相关，两张地图都出现在训练中，不能作跨未见地图或总体显著性宣称。规则和学习策略都可能在具体world上减任务。模型实现正确、资源安全通过和学习性能有效是不同结论。

所有原始证据分装TRAIN_CAL及TEST_SCALE两包，后者同时保存12原guard失败与12兼容重跑；每成员SHA核验。R7冻结工件、原legal fixture、9个生产头及作者planner对象继续按父pin核对。4→8并发仅调整作业调度，N16试测进程峰值RSS约481/668MB；900秒elapsed guard不是阻塞readline的硬中断。查询仍是计数预算，不声称已接通生产货币COST或AUTH。
