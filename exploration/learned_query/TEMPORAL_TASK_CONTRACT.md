# 时序历史进入有限任务查询：固定方法与实验合同

2026-09-29，在首次编译/运行之前写定。本后继只修改本探索分支的新文件，旧夹具与回执保持。目标是检验可见历史在何种条件下改变任务完成导向查询，以及简单方法是否已足够。不是正式 benchmark，不按结果挑参数，不承诺学习胜出。

## 冻结的方法接口

沿用 `calibrated_task_fixture.cpp` 的 `completion_value` 和 `choose_probe`，运行器逐字校验两函数所在块未变：窗口6、最多两次查询机会2.5/2.75、WAIT可选、按当前已分配任务的预测完成数量比较，同数量时少查询优先。公开周期服务从8开始，不向决策器提供评价终点16。安全几何、非零误差盒、PositionCommit、原MOVE ReferenceController、END/驻留/READY交接和服务条件不变。每次评价真实完成9个任务、12个requester原MOVE。blocker条件固定，所有未查询者正常交付END。

六个历史episode各执行一个真实完整cap、不中断MOVE，长度依次1、2、1、2、1、2，全局启动时刻0、4、8、12、16、20，native END交付延迟1/4。全部已交付后在全局32启动留出评价，评价局部0映射到全局32。历史与评价run身份隔离。历史记录仅含run/MOVE身份、长度、启动/结束/收到时刻；没有私有eta、条件名、评价真值或未来任务。每个episode中条件恒定；六个历史episode之间可以改变，评价episode的12个MOVE共享该episode条件。这是明确的人工持续性假设，不声称能处理任意时变扰动。

设每条已交付历史 `alpha_i=(end_i-start_i)^2/L_i`。六个预测器统一输出当前episode的alpha，并在测试之前冻结：

| 预测器 | 固定规则 |
| --- | --- |
| 固定先验 | alpha=3 |
| last END | alpha_6 |
| mean3 | 最近3条alpha的算术均值 |
| median3 | 最近3条alpha的中位数 |
| lag2 | alpha_5；强季节朴素对照 |
| AR(1) OLS | 用五个历史转移拟合带截距的 `alpha_(i+1)=c+b alpha_i`，预测下一项；常值退化时回退mean3，输出截到六条历史alpha的闭区间 |

所有预测器使用同一已交付历史。固定先验选择忽略它。AR不会接收隐藏eta或当前实际标签；离线预测误差在真实MOVE完成后记录且不回流模型。模型仅替换公开长度上的运动时长 `sqrt(alpha L)`，不能修改q、cap、owner、严格阈值或执行授权。若AR与lag2相同，报告为没有独立学习增量。

## 六个预声明实例

慢/快仅描述私有实际控制扰动eta=-1/+1，都处于允许范围[-1,1]，仅native世界生成器接收；选择器看不到这些名字。

| 实例 | 六episode历史 | 下一episode | 目的 |
| --- | --- | --- | --- |
| 0 | 慢快慢快慢快 | 慢 | 有周期信号的慢后继 |
| 1 | 快慢快慢快慢 | 快 | 有周期信号的快后继 |
| 2 | 快快快快快快 | 快 | 稳定、历史足够 |
| 3 | 与实例2完全相同的记录及身份 | 慢 | 无可见预警的隐藏突变；负结果对照 |
| 4 | 与实例0同一历史 | 慢 | 共享初始化观察与人工native报价诊断 |
| 5 | 与实例1同一历史 | 快 | 共享初始化观察与人工native报价诊断 |

每实例比较六预测器＋同AR预测的单步完成规则＋原SRDC＋两步准入规则＋WAIT，共10臂。实例4/5另保留RR，共11臂。单/两步完成共用同模型，区别仅搜索深度。每臂从相同初态执行同一外生任务源。历史在同实例各臂共享，实例0/4及1/5共享同一历史条件，实例2/3字节级历史相同；这些不是62个统计独立样本。只报告具名有限配对证据，不算置信区间或总体泛化率。

原SRDC的生产完整COST尚不可用。实例0—3保留无报价RR回退；实例4/5在**所有臂**共同收到t=1、1.5的A/B/C真实POSITION后，装入明确人工admitted native诊断报价。六次初始化观察分别计数，不算策略免费信息；进度1/2、9/8均低于最小严格阈值33/20，不提前准入。报价单位为人工诊断单位，work=1、publish=0、capture=1/8、commit=1/4、delivered=1/2，所有候选共享同profile；不是生产COST、不是B1费用，也不把旧不完整工作负载收费移植到新profile。运行时要求原SRDC确实进入PositiveScore，而不是仅灌报价后仍回RR。这个诊断只测试正常评分路径及决策差异。

## 评价、失效与解释

完整保留服务时刻8—16的累计曲线、九任务流时总和、末任务服务时刻、查询序列/数量、共同初始化观察数、12个MOVE的事后alpha误差。流时定义为当前任务服务减其实际分配时刻；补任务在前任务服务后才公开。按完整曲线与流时解释任务效果，不以某个有利截止概括吞吐优势。积分未完成任务量只作同日程描述。查询次数及模型维护均没有生产收费，不宣称净成本节省。

成功要求严格编译、六个固定实例全部完成且旧文件/九头前后哈希一致；Python从原始事件独立重算任务计数、曲线、流时、查询序列与MOVE数量。失败回执不覆盖、不删除。任一实例native上限60秒，编译120秒；不扩大搜索规模以追求正结果。允许结果表明没有学习优势、浅搜索已足够或历史突变造成损失。

论文工作主张应聚焦“有界空间误差下，面向任务完成的查询与安全执行”：空间几何决定责任及严格证据门槛，查询决策权衡合法证据对真实服务的提前价值。模型是可替换性能层。SCI二区/三区是投稿目标，分区和录用取决于具体期刊与投稿年份，本合同不作保证。需要后续补足共同生产费用闭环、非手工地图/任务组、可观察非齐次残差及按完整episode留出；当前六组不能独立承担论文新颖性或经验充分性结论。
