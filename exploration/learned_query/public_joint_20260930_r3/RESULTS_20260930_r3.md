# 四机器人共享执行与原生 END-only 查询：R3 实测结果

本轮完成了可运行的联合接口：同一公开作者 trace 的四个机器人共享一个资源表、Index、PositionCommit、精确事件时序；actor 原生从公开 END 解码、拟合和更新，选择后用真实 Controller 证书改变占用和任务服务。首次严格编译通过，63/63 个预注册完整运行通过。查询确实能改变这个联合支持域的任务完成；当前方向概率排序没有独立学习收益，一次查询时 RR 胜过它。没有在看到结果之后调整策略、预算、源支持域、扰动或 seed。

本包是**公共来源、四机器人局部 R1 与内部方法消融**。它不是原 PIE-D 的 100 机器人在线运行、原离散延迟 R0 重演、正式外部 benchmark 横比或生产 COST 评估。它只执行四个当前已揭示 head，不补未来任务；49 终点驻留阻塞 59 时保留真实死锁。没有把两个 crop 的独立服务量拼成全局量。
