# 历史时长拟合进入查询—任务闭环

2026-09-24。**本次实际训练了一个标量回归模型，并将它用于真实组件的查询/等待选择。** 严格编译和原生运行首次均退出 0，4376 项检查通过。两个合法运动条件、各五种策略，共十次有限任务运行；每次完成 9 个任务和 12 个 requester 原 MOVE。

实际结果：较快条件下，固定解析先验仍查询 C，历史拟合模型选择不查询，任务完成曲线相同；较慢条件下，两者都查询 C。模型已经能够利用先前可获得的执行记录改变决策。**单样本解析校准也取得完全相同的结果**，因此当前进展是有效历史适配的闭环见证，尚未证明复杂学习模型的独立价值。

## 学的是什么

沿用[连续任务夹具](TASK_CONTINUATION.md)的几何、非零误差包络、公开任务、查询机会和任务服务规则。只让 requester 的合法常值参考扰动分别取 eta=-1、eta=+1，均在 delta=1 的允许范围内；blocker 一直为 eta=-1。两种条件分别测试，不在评估中把隐藏 eta 交给选择器，也不声称模型处理了任意时变扰动。

每个条件先运行两个独立历史 MOVE，长度分别为 1、2。实际 ReferenceController 从静止、完整 cap 出发，经自主边界到达原终点；生成带 run/MOVE 身份、公开长度、启动时刻、结束时刻和 native 接收时刻的 END 记录。两段历史全部完成后才构造该条件的测试世界。时间使用各次独立运行的本地时钟，测试开始于 0 不意味着历史尚未交付。交付延迟 1/4 是声明的人工接口，未运行生产 AUTH/网络服务。

选择器只收到从这些历史记录拟合的 alpha。拟合使用特征 L 和标签 D²，最小化 `Σ(D²−alpha·L)²`，截距固定为零：

```
alpha = Σ(L·D²) / Σ(L²)
predicted_duration(L) = sqrt(alpha·L)
```

这是闭式最小二乘参数学习，有实际训练标签和测试隔离；不是神经网络、世界模型，也没有使用现有六维二分类器假装做回归。公开动力学形式提供 sqrt(L) 的结构先验。模型仅替换 requester 当前任务的路段时长；blocker 的 END 预测仍为原 `sqrt(3L)+1/4`，避免错误地把 requester 的更快模型套给阻塞者。

原 MOVE 完整 cap、无中断、同条件内常值动力学是本例的范围。训练历史与测试执行来自同一稳定条件，且 requester 共用运动配置，这是明确的可预测性前提。每个条件有两条训练运行记录，不是用当前测试未来标签训练，也不是对新动力学条件的跨分布泛化。

## 对照与结果

同一窗口 6 的完成导向决策器分别使用固定 alpha=3、最后一条 END 的解析校准 `D²/L`、两条 END 的最小二乘拟合。另运行原无报价 SRDC（真实 RR 回退）和无查询策略。各臂的任务源、历史信息可用性、安全规则和实际运动条件相同；固定先验选择忽略历史。

| 实际条件 | 预测/策略 | alpha | 实际查询 | t=8、10、12、14累计服务 |
| --- | --- | --- | --- | --- |
| 较慢，eta=-1 | 固定先验 | 3 | C | 1、4、7、9 |
| 同上 | 单 END 校准 | 3 | C | 1、4、7、9 |
| 同上 | 两 END 最小二乘 | 3 | C | 1、4、7、9 |
| 同上 | 原 SRDC/RR | 不适用 | AB | 0、3、6、9 |
| 同上 | 无查询 | 不适用 | 无 | 0、3、6、9 |
| 较快，eta=+1 | 固定先验 | 3 | C | 3、6、9、9 |
| 同上 | 单 END 校准 | ≈1.173846 | 无 | 3、6、9、9 |
| 同上 | 两 END 最小二乘 | ≈1.173846 | 无 | 3、6、9、9 |
| 同上 | 原 SRDC/RR | 不适用 | AB | 3、6、9、9 |
| 同上 | 无查询 | 不适用 | 无 | 3、6、9、9 |

表格仅作摘要，较慢条件 SRDC/RR 与无查询在其他服务时刻不同，完整曲线保存在回执中。较快条件所有策略在时刻 8/10/12 依次完成3/6/9任务；拟合和校准均比固定先验少查询一次，比原RR少查询两次。未查询 blocker 仍正常 END，这项收益不依赖让未查询者永久阻塞。

模型没有按隐藏条件切换规则：从实际历史得到 alpha≈1.173846 后，它预计不查询时最慢首任务也能在约7.237322到达，赶上服务行8；于是查询不能再增加窗口内任务数，WAIT获选。较慢历史得到 alpha=3，查询C则能把首个服务从9提前至8，因此仍查询。这比“永远不查”多了一项由合法历史驱动的条件决策。

当前确定性齐次动力学下，两历史样本完全落在同一条缩放曲线上，最小二乘与单END校准理论上就会一致，实跑也相同。**不能把胜过固定失配先验写成胜过解析方法。** 减少查询次数也不是完整净费用结论：拟合、维护、规划和通信成本尚未进入生产计费。

## 下一步具体问题

现在值得研究的是：完整cap、稳定时长缩放以外，哪些合法历史特征能够预测到查询是否带来额外任务提前？下一项应让历史与当前执行存在合法变化，保留最后END校准、滑动平均和拟合模型，在同一决策器中看谁减少选择损失。若公共历史没有条件信号，只能估计分布或采用稳健策略，不能逐例还原隐藏扰动。

同时要接主线真实报价和资源消耗，评价任务累计曲线、流时、查询与维护总成本。当前10次运行是具名有限机制对照，条件内共享历史，任务之间还存在续接依赖，不作统计独立样本或LMAPF总体性能证据。
