# R16 查询线导师判断：动作价值成立，当前学习优势未成立

本轮完成了真正改变信息购买后果的实现及验证。STOP 在同一个公开 late gate 后不再买 POSITION，机器人继续普通 END、合法 FIFO 和原执行器到 H128。最终29次新增原生运行（24 TRAIN STOP、2个必要C兼容、3 CAL STOP），30个原C完整后果引用，以及3个另立身份的 CAL STOP16 语义别名。没有修改旧模型/TEST，没有因结果补样，也没有新增大网络。

## 证据允许说什么

TRAIN 12族、24预算上下文中，C与STOP都完成1077任务；查询从285减为144，但STOP的受限T约增加102.388秒。逐上下文有2个任务增加、2个任务减少、20个任务不变；事前材料性口径下有2个偏好STOP、9个偏好C、13个中性。因此剩余购买既不是在所有状态都有效，也不是在所有状态都浪费。这些是可学习价值的必要条件，不是可学性或泛化的充分证明。

两处STOP的TRAIN任务增加都伴随受限T退化：停止购买改变完整未来执行，单纯预测位置误差或只看局部释放，不足以代替完整任务后果。任务风险与同任务时间价值应该分开看；不同单位不能任意混成一个“收益”。本轮保留任务优先、时间次之，费用单列。

依预登记激活的深度1树只用剩余时域 feature8 分裂：较晚的门选STOP，较早的门选C。这个可解释规则是探索假说，不是已确认的机制定律。它在三族CAL的六个上下文中选STOP三次：相对C多1个任务、少20次查询，T少约3.509秒；但固定STOP同样完成238任务，只花36次查询，且T比树少约90.775秒。**当前学习器被固定STOP在同任务下的时间与查询同时支配，不能宣称学到了优于固定策略的购买决策。** 不根据CAL结果改阈值、叶数、特征或重训练。

## 重要的去重成果

在当前冻结condition规则下，C8与STOP16都买前8次，随后不再买。12个TRAIN族的完整物理/公共投影逐事件一致；区别仅在预算相关actor日志。CAL前进一步验证了三族前8个QUERY完整正文、真实C16 gate、对应C8状态和非预算候选特征，三条B16 STOP因而可用真实C8后果作有证明的别名，省去三次重复原生运行。

别名不是伪造STOP日志或复用旧键：CAL_ALIAS_REGISTRATION保留source world/policy/receipt/raw SHA和target gate来源。今后同合同下必须优先做这一层语义去重，再花时间扩展新查询时机、对象或误差条件。真实gate特征来自C16，不能把C8在更早半预算门的特征误配给它。

## 下一步的具体取舍

保留“同真实门、完整后缀、任务风险/时间/成本分报”接口及别名缓存。不要在这24个已看TRAIN及6个已看CAL上下文上改树来追认收益。下一轮先注册独立场景文件和公开状态覆盖，尤其要让查询对象/时机真的有不同执行后果，并同时保留固定C、固定STOP、固定LD作为强内部对照；需要共同合同的已发表基线后才讨论论文优势。

若继续探索学习，应在新TRAIN/CAL建立分别可解释的任务风险和等任务时间目标，固定公共状态分层与完整后果标签；先做小模型，再看新的独立TEST。现有CAL中等任务约92秒的改善是后验机制线索，只能用于提出新假说，不能挑选相似赢家冒充新评估。三个family不足以支持稳健或显著性的声称。

本轮无需撤销查询线：它已经证明“多买信息可能改变任务完成”，也识别了预算重复的无谓运行。但应停止宣称当前树有新增科学收益。研究价值来自可核验的决策差异和适用边界，不来自增加模型复杂度。

数值来源为 TRAIN_PAIRS、CAL_PAIRS、CAL_SELECTIONS 和完整每臂CSV；T为固定前四项FIFO任务的受限完成时间和，并非完成集合变化后的无条件ΣT。原始服务ΣT、释放后受限flow、等待分解、查询及host时间都单列。导出上下界是数值包围区间，不是统计置信区间。文献身份沿用R15已有核验，正式稿仍需人工确认作者/许可、数据口径及导师/期刊要求。
