# 分开检验预测和决策规则

2026-09-24，接续首版 `eba26c3`。本页记录可重算的人工有限图诊断，未运行原系统实验，也未以诊断结果冒称学习模型性能。

## 改动

首版 `solve` 同时用真实概率评分和计算收益，不能比较预测质量。现在 `solve(case, lookahead=..., estimates=...)` 使用两个分离的递归：

- `plan` 只按传入估计定义每个观察分支的动作，包括估计概率为零的意外观察。
- `evaluate` 固定执行该策略，用 `case.probabilities` 加权真实结果；任何一步都不按真值重新选择。

省略 `estimates` 明确表示使用准确概率的诊断配置，并不是实际系统取得真值的方法。`decision_ablation.py` 在每个固定真实分布中比较“人为粗估／准确概率 × soft A/P／预算前瞻”。这里没有拟合新的预测器，不能把“粗估到准确”的变化写成学习收益。

## 实际解析结果

以下数字均为预算内期望准入需求数，成本相同、每owner至多查询一次、无外生图变化，结果在有理数上精确计算。

| 控制情形 | 粗估 + soft A/P | 准确 + soft A/P | 粗估 + 前瞻 | 准确 + 前瞻 |
| --- | ---: | ---: | ---: | ---: |
| 两个单owner需求，预算1，粗估颠倒优劣 | 1/5 | 4/5 | 1/5 | 4/5 |
| 两需求共需A/B，另有C，预算2，粗估C=1/2 | 1/1000 | 1/1000 | 2 | 2 |
| 同上，粗估C=0，真实C=1/1000 | 2 | 1/1000 | 2 | 2 |
| 同上但预算3，足以查询全部owner | 2001/1000 | 2001/1000 | 2001/1000 | 2001/1000 |

第一行隔离预测排序的作用：单步时不制造前瞻收益。第二行隔离组合决策的作用：预测改善而排序不变。第三行给出启发式下概率更准确却收益更低的明确例子，其平均概率平方误差从 `1/3000000` 降至零。第四行说明差距依赖受限预算，不能外推到所有长期运行。

`mean_squared_probability_error` 是估计概率对人工指定真实概率的误差，既不是观测标签 Brier 分数，也不是经验校准结果。表中“前瞻”在所给估计和有限图下优化，只有估计等于真实模型时才是该有限目标的参考最优。准确概率加启发式不是上界。粗估规则亦非主线割线预测的复现。

## 验证与限制

33 项联合软件检查通过。新增检查不只验证首选，还固定估计、改变真实分布，验证第二步不会偷偷改选真实收益更高的对象；也检查在估计认为不可能的成功或失败之后仍有完整策略。

```bash
rtk proxy python3 -B -m exploration.learned_query.decision_ablation
rtk proxy python3 -B -m unittest exploration.learned_query.test_model exploration.learned_query.test_shadow exploration.learned_query.test_integration exploration.learned_query.test_decision_structure -v
```

没有将图准入量映射到任务吞吐，没有计入新搜索、维护和推理的实际费用，也没有建立几何可实现性或真实场景频率。当前比较器不复刻原系统全零收益时的 RR 回退。它是精确的小图诊断，不是生产调度器。

## 对下一步的影响

不以校准误差下降作为学习成功的终点。先按[数据接口契约](DATA_INTERFACE.md)建立最外层成功提交后的可见状态导出，核查实际阻塞结构与时限；再在固定决策规则下检验学习的额外价值，并计入全部在线成本。

目前可以证明的是四种机制在诊断中能被区分，尚不能选择在真实场景中表现最好的方法。继续保留小模型和原影子评分作对照，不通过任意概率截断掩盖机制问题。
