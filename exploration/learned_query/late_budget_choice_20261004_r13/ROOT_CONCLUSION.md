# R13 独立结论：学习已实际改变晚点选择，完整模型尚未超固定 LD

本轮完成全部 160 次原生执行，64 TRAIN/CAL 与 96 TEST 均保留；原物理/策略审计全部通过。根另从全部原始事件独立复算真实晚点门、十维目标特征、精确分数、C/LD 动作状态机、FIFO 服务、查询集合、共同前缀和相同宏的完整轨迹。导师独立从 raw 重建 64 标签、以 Fraction 复算四头 44 个系数、复核 CAL 与 96 TEST 部署参数/时间链。没有按 TEST 修改模型、门槛或场景。

## 从 R12 到 R13 的实际变化

选择从首次机会移到首次已用至少半预算且仍有候选/容量的真实晚点。模型只选择一次完整 C/LD 尾策略；LD 在门处跳过最高条件分候选，再在后续最早合法机会跳过一个不同完整 occurrence。之后继续原 condition。门前公共物理轨迹相同，预算 8/16 的门前轨迹允许不同；本轮没有学习门时刻，也不是通用多步预算控制器。

24 个登记场景块/误差 family 按 12 TRAIN、4 CAL、8 TEST 分组，每族两预算。TRAIN 的 24 个 LD−C 标签有 3 个任务数正收益、2 个负收益、19 个任务数零差；其中 13 个时间目标非零。四头真正拟合。登记 CAL 规则选出有限门槛 0.1，模型在 TEST 真正选择不同完整尾策略，不再像 R12 一律回退 C。概率屏蔽模型的两个预测头重新拟合，但共享 full 的 CAL 门槛；候选资格、排序和 condition 尾仍使用合法历史。

full 比 condition 多一个任务，时间和减少区间为 [4.963687, 4.965088]，但固定 LD 已取得相同任务收益。full 对固定 LD 的总时间改善界为 [−0.000700, +0.000702]；这是原始时间记录的数值包络，**不是统计置信区间或显著性检验**。在 random132302/B8，full 选 C 比 LD 快约 0.5834；在 random132304/B16 又慢约 0.5834，二者相抵。不能把总和相近写成逐轨迹相同。

no_history_prob 保持与固定 LD 相同的 713 任务/192 次查询，总时间少 [0.713076, 0.714478]。相对 full，它在 empty131303/B8 选择 C，额外时间改善 [0.713734, 0.713818]；另外两个正负条件仍相抵。这个窄消融有有限独立时间收益，可作为新的假设，但不能在看到 TEST 后把它升级成已验证最优模型，也不能说整个系统去掉历史更好。8 个 family、两个已有地图类型仍是小规模留出。本轮 family 来自同一地图 scenario-2 文件的不同行块和不同误差 seed，并非 8 份独立官方 scenario 文件；没有文件级或跨地图留出。

两模型都在 16 个 TEST 条件推理一次，full 实际触发 20 次 SKIP、mask 18 次。全部非 WAIT 策略均用尽 192 次 QUERY，本轮没有查询节省。推理计时含目标排序、十维特征与评分，不含原始候选特征构造；没有接入生产收费，不能把这个计时或 query 数说成主线费用。

## 解释与下一推进

本轮支持继续学习已有可执行动作的条件价值：真实任务标签不再全零、冻结模型实际改变后续动作，且有一个窄模型的独立时间信号。它不支持 full 已优于固定 LD，也不足以把学习本身写为主贡献。

固定模型和门槛下，事后只去掉时间评分项，32 个模型决策均不改变。见 [ROOT_MODEL_DIAGNOSTICS.json](ROOT_MODEL_DIAGNOSTICS.json)。这是解释性读数，不是重新训练/标定的时间头消融；不能据此宣称完成时间信息无用。下一版应在新 TRAIN/CAL 上检查任务数稀疏标签、时间目标与选择门槛的作用，而不是在这份 TEST 上重设门槛。

保留固定 LD、condition、预算查表和 WAIT 强规则，并在新独立实例上检验模型相对这些策略的增量。它们都是内部控制，不能充当已发表外部算法。与第三线的真实作者 GSES/Improved GSES 接口结合后，再推进有价证据改变合法候选与完整执行价值的共同问题；具体下一合同和作者基线设计在第三分支 R13 文档中。

全部旧冻结合约与本轮核心源保持。六个根原始日志篡改控制被拒绝；其余候选侧机械控制及发布归档结果各自有回执。归档离线重放由 offline_replay.py 核验 9 包、960 原始成员并重现全部根审计结果；具体是否完成以 OFFLINE_REPLAY_RECEIPT.json 为准。
