# Astra R12 非盲技术后评

2026-10-04。由实际 GPT-6-Astra/ultra 工作代理形成。本人参与事前设计和只读源码审查，并读取冻结模型、完整TEST与根/导师独立审计，因此这是非盲技术判断。本次只写本文件，未改模型、阈值或追加native。

我的判断是：**本轮没有证明学习选择器带来任务或服务改善；B16的固定预算宏存在应保留的小规模留出信号。** 值得继续检验条件时间价值，但下一步应缩小到实际预算分配时点的可辨识选择，不应直接增大网络。

## 模型完成了训练部署，但没有独立收益

152次登记运行全部完成，执行失败0：96个TRAIN/CAL完整宏分支、56个冻结TEST部署。原物理/策略与根原始宏审计均152次通过；导师独立重建96行标签、30个ridge头、780个量化系数及56次部署一致。TEST只有四个独立family，各配对B8/B16；八个预算世界和56个策略臂不能当作独立重复。依据：[报告](REPORT.md)、[根宏审计](ROOT_MACRO_AUDIT.json)、[导师审计](MENTOR_MODEL_AUDIT.json)。

|TEST策略|两预算合计任务|QUERY次数|实际宏|
|---|---:|---:|---|
|整程WAIT|340|0|八次W|
|condition|340|88|八次C|
|TRAIN预算查表|340|52|B8四次W、B16四次LD|
|full及三个消融，各自|340|88|八次C|

共同CAL门槛为无穷大，四个学习变体虽然各进行了八次原生评分，最终完整服务记录都与condition一致。full相对WAIT的T改善[45.138129,45.138801]、相对查表的改善[12.935803,12.936475]，来自原condition已有行为，不能归给学习器。T仅为每机器人固定前四项任务的受限服务时间和，未完成记128；全FIFO任务数另算。

TRAIN的60个非condition宏标签和CAL对应标签，任务差全部为0；15个任务头及其390个量化系数也全为0。因此本轮没有学习吞吐差异的监督信号，任务预测误差为0不代表有用预测能力。tasks_only即使采用有限非负门槛也会选择C。这个发现不推翻R11不同family中的+1任务空间，但该信号没有在本批TRAIN中提供学习依据。

时间头有非零预测，宏也有实际时间后果。问题出在条件排序：CAL的低门槛四次全选W，较大门槛全选C，任务均166。C比W快[0.990494,0.990814]，却用了48次而非0次查询。按登记的任务优先、时间其次、查询数末级平局规则，选中无穷门槛符合协议；这不证明查询的生产净效用为正。

CAL内W在empty两预算各慢约19.9022，在random的B8/B16分别快约35.8508/2.9630，冻结full却给empty更高的W优势分数。需要检验的是条件识别能力，不能为了模型激活而事后降低门槛。根诊断中full时间头的TRAIN平均绝对误差折回T单位约0.671，CAL约10.012；六个TRAIN family下的这种落差不足以归因于网络容量。

三个消融被同一个无穷门槛关闭，没有部署决策差异，所以本轮未识别历史、预算特征或时间头的作用。不能把同结果写成这些信息无用。tasks_only还共享full的时间感知CAL门槛，不能称独立的无时间校准方法。依据：[冻结模型](MODELS_FROZEN_BEFORE_TEST.json)、[根模型诊断](ROOT_MODEL_DIAGNOSTICS.json)。

## B16局部正向与B8损失需要同时保留

TRAIN查表在TEST前已固定B8→W、B16→LD。根原始服务复算得到：

|查表相对同预算condition|任务差|T改善区间（正值更快）|QUERY：查表 / C|
|---|---:|---:|---:|
|B8：W|0|[−17.009079,−17.008743]|0 / 32|
|B16：LD|0|[4.072604,4.072940]|52 / 56|
|两预算合计|0|[−12.936475,−12.935803]|52 / 88|

B16四族保持170任务，八个计划SKIP均实际触发。时间正效只来自random122302，T少[4.072733,4.072811]，查询仍16次；其余三族完整服务记录与C一致，其中两个empty各少两次QUERY。一个TRAIN事前选定的简单宏在留出中保留了时间/次数改善，这比仅有TRAIN后见最佳更有意义。

但只有一个family贡献时间收益，不能推广为LD普遍占优或吞吐提升。B8查表在三个family损失时间、一个略有改善，聚合损失抵消了B16收益。不能只展示B16便称整张查表成功，也不能因总和为负抹去局部事实。查表利用了TRAIN数据，却没有学习基于当前公共状态的条件选择；它的收益不属于full模型。依据：[根TEST结果](ROOT_TEST_RESULTS.json)。

## 下一最小检验

我建议另行预登记一个小研究，保留当前物理、安全、B8/B16和完整宏尾策略，把学习问题缩到：**在晚点预算机会继续condition，还是执行固定的晚点双SKIP。** 不扩展coupled问题，不复用本轮TEST作为新留出。

在首次已用floor(B/2)、仍有预算且存在合法候选的公共时点，只作一次二选一。两枝此前共享condition完整前缀，此后分别condition到底，或按固定LD规则完成两次公开SKIP后condition到底；第二触发不再调用学习器。标签仍来自两条完整真实续策略，无机会family完整保留。

输入改为这个实际决策点目标候选的少量公开量：释放概率/年龄、被挡当前任务的剩余路径、剩余预算及距H时间。先用简单模型检验这些量能否区别正负时间后果。首机会候选均值是否过早、是否遗漏宏目标差异只是待检验假设，不是本轮已经证明的原因。

C、固定LD、整程WAIT和原预算查表都应保留为简单对照，两个预算分别报告。尤其固定LD应成为强基线：只有新family上的条件选择超出它，才显示学习的必要性。任务数继续是原始主项，所有任务损失保留；若任务标签仍全0，就如实承认可学习目标只是同任务下的时间差，零任务头不能提供风险保证。

先证明模型在公开输入下作出并兑现不同决策，再投入完整的信息消融；若CAL再次关闭模型，按预设规则报告，不为获得“活跃模型”追调阈值。当前没有证据支持硬上复杂网络，也没有理由放弃已经产生真实后果的有限预算时间价值问题。

## 论文与计价边界

本轮保留了完整宏标签与部署匹配、真实预算变化、旧注册及零科学运行下的前缀/边界修订，建立了可信的训练部署链；完成工程和审计仍不等于学习贡献成立。四族pilot不能支持普遍优势、最优预算分配或论文级规模结论。

任务、T和QUERY次数须分别报告。B16在这些观察量上有局部改善，但QUERY次数不是生产计算费；涉及C与WAIT的时间—次数交换时，不能据未计量费用宣布净收益。32次host评分计时也不包含特征构造，更不是物理时间或生产COST。最终打包与离线复现由根另行报告，本文的科学判断依据是已核对的冻结模型、原始服务和独立审计。
