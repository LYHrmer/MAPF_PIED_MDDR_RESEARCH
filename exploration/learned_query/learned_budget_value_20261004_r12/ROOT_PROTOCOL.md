# R12 根协议：给定预算下的完整策略宏选择

用户在R11完成后明确选择“先学习已有实测空间的条件选择、预算分配和完成时间价值”。本轮将其落实为实际训练、冻结和原生部署；只推进查询支线，不改旧实验、生产物理代码或原稿。该设计是在看到R11结果后提出的新探索，旧结果仅用于设计依据，不作为本轮留出。

## 方法与信息

模型在首个非空、预算仍正的合法公共查询机会只调用一次，选择一条完整策略宏：condition、整程WAIT、early单SKIP、late单SKIP、early双SKIP、late双SKIP。early为首机会，late为首次已用预算达到floor(B/2)的合格机会。SKIP目标采用原condition公开精确分数与完整身份排序；双SKIP第二点是首动作之后最早有预算、存在不同(agent,occurrence)候选的公共机会，以同一排序选目标。宏之间/之后沿用原condition，WAIT宏保持全程WAIT；持久SKIP只在匹配的accepted normal END后清除。

模型选宏发生在处理首动作之前，之后不再重选。无首机会、late未触发、第二次无合法触发均完整保留，不按结果替换时点。因为所有宏在首机会前均未查询，训练中的六条整程结果可在核验共同前缀后作为该状态的完整后果标签；不能把一次干预标签反复部署造成不同尾策略。

输入为首机会全部合法候选原24维公共特征逐槽均值，加candidate_count/N，共25维。禁止agent/task/地图ID、seed、未来任务、私有进度或未来END进入模型。选择器history消融删除10..17；budget消融删除20/22/23。原0、19是无历史统计的解析prior及其结构乘积，不删为历史泄漏。预算消融保留真实硬预算和宏规则；历史消融保留公共资格与原condition尾的历史计算。因此两者是选择器特征消融，不是完全无历史或无预算的执行系统。

同family B8/B16在首机会的非预算特征须逐字相同；无预算选择器的分数和选宏也应相同。不同预算下同一宏后果仍可不同。总预算由协议外设，模型学习其使用方式，不学习自主选择总预算，也不是持续在线强化学习。

## 数据、训练与预算

6个TRAIN、2个CAL、4个TEST独立任务family，两张公开图平衡分配。每族均运行B=8与16，N16、H128、FIFO256，原未切换的9:1私有执行误差规律保持。empty使用另行固定的官方scenario2六块，random使用已取得的scenario2新六块；具体offset、seed和输入哈希由实现合同在科学运行前登记。旧family、旧TEST及R11收益不得参与本轮拟合、校准或样本筛选。

TRAIN/CAL完整执行六宏，共8×2×6=96次。TEST固定七策略：WAIT、condition、TRAIN按预算分别固定最佳宏的两项查表、full、nohistory、nobudget、tasks_only，共4×2×7=56次。总计152次native，最多6并发，独立审计最多2并发；不因结果增加family、宏或时域。增加的tasks_only八臂已在新运行前由根明确授权，用于隔离完成时间价值头的作用。

每个非condition宏拟合两个完整后果差：Δtasks，以及(T_condition−T_macro)/16385。T为每robot固定前4项任务的受限完成时间和，未完成记128，不能替代全部FIFO的任务主指标。采用固定ridge λ=1、未惩罚截距、仅TRAIN加权标准化，每个family两预算各权重1/2；量化到9位小数后以有理系数部署。full为两头相加，无历史和无预算模型分别重新用掩码TRAIN拟合；tasks_only复用full任务头，删除时间头。

只用full模型在CAL选择一个共同激活margin，候选为0、1e−4、1e−3、1e−2、1e−1、+∞。预测最佳宏相对condition的优势严格大于margin才激活，否则condition；固定宏顺序解决同分。共同margin原样应用于三个消融，不分别再调。tasks_only因此是共享校准下的时间价值头消融，不称完全没有接触时间指标的独立校准算法。

CAL按全体任务数优先、固定FIFO时间区间的严格减少其次、查询更少、margin更大顺序选取。不能跨family直接用sum J代替任务绝对优先；若时间区间重叠，按事前固定的平局规则处理。TRAIN预算查表也按该预算的总任务、时间区间、查询数和固定宏顺序选择。不增加逐CAL格零任务损失的否决条件；所有负例和逐族损失照实报告，校准不提供安全或风险保证。源码、输入、特征、拟合/选择规则在TRAIN前冻结，系数、margin和查表在TEST前冻结。

## 根独立检查与实际结论

根不使用实现方的价值汇总来代替验证：从原始服务复算任务、T有理区间及完整宏标签；从TRAIN输入独立重拟合、核标准化/量化/掩码，再复算CAL选择与按预算查表。原始TEST逐次核首机会特征、所有宏分数、唯一选择、合法SKIP触发、尾策略与实际预算使用。保留没有模型机会或未兑现宏的运行，明确“发生推理”“改变宏”“改变服务”三个不同数量。

实现方保留原物理、几何、资源、FIFO和特征审计，补宏选择与完整后续行为核验、破坏输入的拒绝检查及父版本哈希。模型不能授权不合法的查询或释放；原作者planner不改变。推理耗时仅为宿主计算元数据，不换算物理时间或生产COST。

TEST统计单位是四个独立family，两个预算是族内成对条件。逐family×预算给全任务差、固定FIFO时间区间和查询数；族级汇总不将策略臂或预算条件当独立样本。目标是检验冻结学习选择器是否超出原condition、WAIT及简单预算查表，并判断历史、预算和时间头的作用。四族pilot不能支持广泛优势、当前组合阻塞学习或论文级规模结论；本轮完成的训练/部署本身也不等于任务收益。无论结果如何，全部运行、失败、模型与冻结记录保留。
