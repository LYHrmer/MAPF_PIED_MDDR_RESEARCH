# R12 科研导师实施前评估：给定预算下的完整宏选择

判断：支持按已批准的 **152 次 native 上限**完成一次真正训练、冻结、部署和独立留出的有限 pilot。一次公共首机会选择一条完整后续宏，比把单次干预标签反复用于整程决策更合适，标签与部署行为可以严格对齐。本轮研究对象是给定 QUERY 预算时的完整宏选择；它不学习总预算 B，也不等于多时刻在线强化学习或一般预算分配。当前接口无需出现即时 coupled claim。

本评估沿用已读 research-mentor，只给设计与验收判断，不运行 native、不修改实现或 Git。第三线及 R10/R11 冻结工件不动。152 的范围由 root 在实施前明确确定，为 96 TRAIN/CAL 加 56 TEST，不能在看结果后补族或换模型。

## 固定实验设计

|分区|独立 family|预算|每个 family×B 的运行|native 上限|
|---|---:|---|---|---:|
|TRAIN|6|8、16|完整 K6|72|
|CAL|2|8、16|完整 K6|24|
|TEST|4|8、16|七条已冻结策略|56|
|合计|12|族内配对|不因缺触发填满或另补样本|152|

沿用 N16、H128、原 FIFO 和私有执行误差生成合同。两预算是同一任务族内的处理条件，不是两个独立族；策略之间使用同一族的扰动索引机制。分区按完整 family 键完成，不按轨迹、候选或预算拆分。模型不能读 seed、任务 ID、agent ID、scenario/offset 或 map 名字来识别族。公开几何特征仍可使用，但不声称在新地图类型上泛化。

K6 为：condition、整程 WAIT、early SKIP、late SKIP、early SKIP 后下一不同 occurrence 再 SKIP、late SKIP 后下一不同 occurrence 再 SKIP。late 以 spent≥floor(B/2) 为公开触发条件；目标排序、完整 occurrence 身份、晚锚及第二锚的资格、没有触发时的行为都应在协议中逐项写死。SKIP 仍持续到接受正常 END，仅等待一次不得偷换为持久 SKIP。宏外的动作继续使用原 condition 尾策略。

学习器只在首个合法公共机会推理一次。该机会本身已有 END 历史且此前没有 QUERY；必须从真实运行独立核对 K6 的共同前缀。尤其要证明从此选择 WAIT 尾与整程 WAIT 的任务/物理前缀一致，才可使用整程 WAIT 结果作相应标签。没有首机会的运行不能伪造一个模型输入；晚锚和第二 SKIP 不可达时也不能记录成已成功干预，全部保留实际状态与完整运行。

模型输入为候选公开 24 特征的均值及候选数，不使用私有位置、未送达 END、未来任务或任何分支结果。聚合表示只能选择宏，不能据此声称学习器直接优化了候选排序。最小模型固定 ridge 正则和预处理，不再在本轮比较深度、宽度或模型家族。每个 option 的任务差和时间差标签来自同一 family×B 的完整真实尾执行，例如

`ΔN_k = N_k − N_condition`，`ΔT_k = T_condition − T_k`，

`predicted advantage_k = predicted ΔN_k + predicted ΔT_k / 16385`。

其中 T 是固定每 agent 前四项任务的限制完成时间和。真实 J 的任务优先性不等于预测器不会误判任务损失，所以最终 ΔN 与 ΔT 必须分开报告。TRAIN 有 72 条运行，并不意味着有 72 个独立公共上下文；同族同预算的宏共享选择时刻，上下文量和有效变化维度都应如实列出。

## CAL 和对照选择

已确定的 margin 网格为 `{0, 1e-4, 1e-3, 1e-2, 1e-1, +∞}`。仅 full 模型在 CAL 选择一次统一 margin，其余消融全部复用。预测最优宏的 advantage 超过 margin 才激活，否则 condition；预测同分和宏顺序必须预先固定。`+∞` 是真实的 condition 回退，不得在 TEST 后去掉。

CAL 采用已真实运行的 K6 后果评价各 margin：总任务数优先，其次按预先写定的 FIFO 时间区间比较，再看 QUERY 次数，最后偏好更大 margin。区间重叠时的确定规则必须写清，不能仅靠不稳健中点差作选择。CAL 不再选择 λ、特征、K6 成员或数据族；计算与系数序列化精度也应在使用 TEST 前固定。只有两族 CAL，不能把这个经验规则解释成风险保证或统计校准保证。

**保留的导师分歧：**我更倾向增加“任一 CAL family×B 不丢 condition 任务”的经验 veto。root 决定不采用，以免两族 CAL 造成过度回缩，而允许按总任务数选择 margin。我接受这个有限 pilot 取舍，但它允许一格收益抵消另一格损失。因此本轮不能预先承诺“各场景保持吞吐”，必须报告每族每预算的任务损失、收益和最坏配对差。这个分歧不是新增审批条件，也不要求偷偷在代码中补回 veto。

TEST 的七条策略为 whole WAIT、condition、**按 B 分档的 TRAIN 最佳固定宏**、full、nohistory、nobudget、tasks_only。固定宏仅用 TRAIN，分别为 B8/B16 选一条，对所有该预算的新 TEST family 使用同一条；其任务/时间/查询同分规则也预先固定。这是同信息条件下的强简单宏规则，用来区分学习上下文选择与单纯找到一条较好宏，不是测试后逐族挑选最优宏。

nohistory 必须去除所有 END 派生输入，而不只是原始历史计数。按 R11 原 24 特征定义，10..17 包括历史条件概率、最近记录、方向经验和历史交互项；任何新增的历史 score/ETA 派生量也不能遗漏。nobudget 必须去除 B、remaining、spent 及其衍生项；按原特征定义至少包含 20、22、23，21 是公共时间，不应仅因相邻而误删。最终以实际 R12 特征表逐项核对。两消融都保留真实预算执行约束，以及宏尾 condition 所需的原信息；准确名称是**选择器的历史/预算输入消融**，不是整个系统完全没有历史或预算。

tasks_only 使用与 full 相同的任务头，只去除时间头，且完全复用 full 的 CAL margin。准确称为**共享校准的时间价值头消融**。它没有自己的最佳阈值，不能把结果说成所有最优任务模型的上界或下界。

## 必须看见真实部署与完整留出

训练只读 TRAIN；预处理统计也只来自 TRAIN。CAL 后固定模型、margin、规则宏及全部源码/输入哈希，再开始 TEST。需记录模型训练结果和实际 native 模型选择，而非仅在离线表中把最优宏结果当作模型结果。

每条 TEST 日志应能核验：公共首机会、聚合特征、屏蔽后的消融输入、六个预测值、margin、实际选择的宏、激活或回退、宏的每次实际 SKIP、未触发原因、预算消耗和最终任务服务。应统计推理发生次数、非 condition 选择次数、真正执行的干预次数及推理耗时。若全部回退 condition，这是有效负结果，不能称模型已通过主动选择产生收益，也不能看完 TEST 后再降低 margin。

独立检查重点是模型输入无未来泄漏、原物理与证据释放语义不变、共同前缀、完整身份的 SKIP 生命周期、晚锚/第二锚资格、真实 QUERY 预算、FIFO 服务与精确分数/数值格式。同族 B8/B16 在首查询前的非预算选择器特征应相同，适合作为预算屏蔽机械检查；历史屏蔽也应使用明确的同状态反事实输入检查，避免把下游路径差异误认为输入隔离失败。

## 能证实什么，不能证实什么

首要方法问题是 full 是否在新 TEST family 上优于预算分档固定宏；同时完整给出与 condition、whole WAIT 的配对差。若只胜 condition 而不胜固定宏，不能归功于上下文学习；若 full 与 nohistory/nobudget 相同，也不能声称相应输入必要；若和 tasks_only 相同，不给时间头虚构贡献。

独立统计单位只有 **4 个 TEST family**。每族分别报告 B8/B16 的任务、T 区间、J、QUERY 次数、宏选择和失败，再按预先固定权重形成族级配对效应。不能将八个预算格、多个候选或七种策略当独立样本。小样本可以证明代码已形成真实学习决策链，并提供有限的新族效果证据；不承诺总体显著性、稳健跨分布泛化或论文分区。

R11 提供的是弱但真实的条件选择和完成时间空间，既不是全无可学，也不是已有稳定收益保证。本轮应把完整训练与留出跑完，让结果决定这种有限选择是否成立。QUERY 次数、模型 wallclock 与生产 COST 分列；尚未定义工作步和运动时间兑换，不能声称综合经济净收益。无论结果正负，都不追加挑样、扩宏或调参来寻找正值。
