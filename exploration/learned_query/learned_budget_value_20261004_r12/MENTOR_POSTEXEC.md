# R12 科研导师独立后评：训练与部署闭环通过，新增学习收益未成立

本轮完成了事前登记的 152 条科学运行、真实模型训练、冻结校准和 56 条新 TEST 部署。我的独立复拟合与部署审计全部通过。但四个学习变体在 TEST 都选择 condition，模型相对原 condition 的任务、固定 FIFO 完成时间和服务轨迹没有改变。因此准确结论是：**训练与精确原生推理已完成，部署没有产生额外干预，未获得新增学习收益。** 这不是相对 condition 的负效用，也不证明价值模型已经正确。

本评估沿用 research-mentor，独立于候选拟合与汇总实现。只新增本后评、独立审计脚本及其结果；实施前评保持原样，R10/R10b/R11 冻结目录、原稿、入口文档和 Git 均未改动。以下科学判断针对本次有限 pilot，不升级为论文级一般结论。

## 留出结果与归因

T 是每个 agent 固定前四项 FIFO 任务的限制完成时间和，未完成项取 H=128；全程完成任务数使用完整 FIFO。下表是 4 个独立 TEST family、每族两个预算的 8 格总和，不把它们当作 8 个独立样本。

|策略|完成任务|T 区间|QUERY|实际宏选择|
|---|---:|---:|---:|---|
|whole WAIT|340|[45120.685662, 45120.685998]|0|W×8|
|TRAIN 预算规则|340|[45088.483336, 45088.483672]|52|W×4、LD×4|
|condition|340|[45075.547197, 45075.547533]|88|C×8|
|full|340|同 condition|88|C×8|
|nohistory|340|同 condition|88|C×8|
|nobudget|340|同 condition|88|C×8|
|tasks_only|340|同 condition|88|C×8|

condition 的 T 总和比 WAIT 少 [45.138129, 45.138801]，比预算规则少 [12.935803, 12.936475]。full 继承这些结果，但未超过 condition；不能把原 condition 的时间收益写成“学习比 WAIT 更快”的方法贡献。相同完整服务记录支持相对 condition 的实际零差异，独立时间包络相减出现的微小正负区间只是界运算，不是新的效果。

聚合也不能掩盖异质性。以下按每族两个预算等权平均，正数表示 full/condition 更快；每格任务差均为零。

|TEST family（简写）|相对 WAIT 的平均 T 节省区间|相对 TRAIN 预算规则的平均 T 节省区间|
|---|---:|---:|
|empty 121301|[13.881595, 13.881679]|[6.9407765, 6.9408605]|
|empty 121302|[3.221340, 3.221426]|[1.6106485, 1.6107345]|
|random 122301|[0.875119, 0.875207]|[0.291677, 0.291765]|
|random 122302|[4.5910105, 4.5910885]|[−2.3752005, −2.3751225]|

random 122302 的 B8 中，condition 比 WAIT 慢 [0.677512, 0.677590]；B16 中，预算规则的 LD 比 condition 快 [4.072733, 4.072811]。这些是真实的局部选择空间，不能因总和偏向 condition 而省略。

尤其应单列预选预算规则的正向留出结果：**B16 的 LD 在四个 TEST 族保持 170 项任务，QUERY 从 condition 的 56 降至 52，T 总和减少 [4.072604, 4.072940]。** 时间改善来自 random 122302；其余三族服务记录完全一致，两个 empty 族各少 2 次 QUERY。它是仅用 TRAIN 预选的简单规则在新族上的有限正向证据，不能被学习器回退结果掩盖，也不能归功于未激活的条件价值模型。B8 的 W 则保持 170 项任务、QUERY 从 32 降至 0，T 慢 [17.008743, 17.009079]，所以两预算合计仍慢约 12.9361。

汇总预算规则减少了 36 次 QUERY，WAIT 减少了 88 次，但本轮没有把 QUERY、主机耗时与运动时间兑换成生产 COST，因此也不能宣称 condition 的经济净收益最大。

## 为什么回退，哪些问题仍未回答

TRAIN 的 60 条非 C 任务差标签全部严格为零。因此 15 个任务头全零是实际标签的结果，并非拟合失败；CAL 的 20 条非 C 任务差也都为零。12 个 TRAIN 上下文均有合法首门，未触发“全 TRAIN 无门”的预注册零模型回退。其余 15 个时间头实际完成拟合，60 条时间差中有 23 条非零。本轮没有吞吐优势训练信号，却有正负完成时间信号。

CAL 并不是每一格都只差一点时间。以 `T_condition − T_WAIT` 为正向收益：

|CAL 任务族|B|WAIT 相对 condition 的 T 收益区间|
|---|---:|---:|
|empty 121201|8|[−19.902236, −19.902150]|
|empty 121201|16|[−19.902236, −19.902150]|
|random 122201|8|[35.850715, 35.850789]|
|random 122201|16|[2.962943, 2.963017]|

full 在 margin=0 和 10⁻⁴ 时四格全选 W，在 margin≥10⁻³ 时四格全选 C。两组任务同为 166；C 的 T 总和较 W 少 [0.990494, 0.990814]，所以先通过时间准则，再在同样的 C 行为中按“较大 margin”规则选 +∞。这是注册规则的正常产物，未在 TEST 后改变阈值。选择器在这两个 CAL family 之间没有分离出实际的 C/W 时间偏好；“整体只差约 0.99”不能概括各格效应。

这一结果说明当前拟合和统一阈值未把已存在的条件差异转化为留出学习干预。它没有证明时间价值不可学习、历史无效、预算无效，也没有证明换一个更大的模型就会有效。只有 6 个 TRAIN family，首门均值表示是否充分、正负时间效应能否从公开信息稳定识别、宏触发的可达性是否需要单独描述，都仍是待检验假说。[ROOT_MODEL_DIAGNOSTICS.json](ROOT_MODEL_DIAGNOSTICS.json) 的 TRAIN/CAL 误差和事后最优宏仅是诊断，不能当作新留出或可部署 oracle。

共享 +∞ 使四个学习变体的行为都被固定为 C。故本次消融只能确认屏蔽实现和部署链正确，不能归因历史、预算或时间头的效用。nohistory 仍保留公共资格及历史驱动的 condition 尾；nobudget 仍保留真实预算和宏阈值；tasks_only 复用 full 任务头及同一个时间感知 CAL margin。尤其 tasks_only 的全零任务分数本就会回退 C，不能称其已学到一条有效任务策略。

实施前我偏好逐 CAL 格不损任务的经验 veto，root 选择不采用。实际本轮所有 CAL 宏任务数相同，这个 veto 不会改变选择，不能用这项设计分歧解释当前回退。也不应现在降低 margin、挑一个 TEST 族或追加宏来制造模型激活。

## 方法与论文判断

|资格或主张|本轮判断|
|---|---|
|可复查的原始结果→标签→模型→校准→冻结→实际部署链|PASS|
|完整宏标签与实际完整宏执行一致|PASS；避免了把单次干预收益重复用于不同尾策略|
|新增学习任务收益或完成时间收益|未成立；相对 condition 实际为零|
|历史、预算、时间头各自带来收益|本轮行为被共同阈值固定，无法识别|
|时间条件选择仍有研究价值|保留；CAL 正负异质性和 TEST 局部对照差异是实证依据，可学性仍未证|
|一般预算分配或多时刻 RL 方法|不成立；B 外部给定，只在首个公共机会选择一个有限完整宏|
|正式论文新颖性与跨分布性能资格|仍 CONDITIONAL/UNKNOWN；没有外部查询学习基线、只有 4 个新 TEST family|

我支持把本轮作为严谨的有限负结果和可复用验证基础保存，但不建议将当前 ridge 宏选择器列为核心性能贡献。标准回归、收益标签、历史输入或校准门限本身不足以建立新颖性，本轮尚未完成已发表外部方法的同问题对照。更明确的增量是公开证据与给定 QUERY 预算下，完整尾宏的标签、执行和费用约束可以严格对应。该增量目前主要支撑实验可信度，尚未形成已证实的新学习算法收益。

若继续这条用户选定的方向，应先解释“公开状态中哪些因素能区分宏的正负时间效果，以及预测宏在后续是否真正有机会执行”，再确定下一轮的表示或学习目标。可以把公开、可获得的剩余路径与机会结构、动作可达性作为候选接口，给出一项具体可推翻的条件假说；不能将它们未经测试就写成解决方案。新设计需重新登记并使用新的 TRAIN/CAL/TEST，保留 C、WAIT 和预算分档规则，继续让真实任务优先、固定 FIFO 时间其次。当前数据可用于明确假说，不能再作下一轮独立留出。

这个建议不要求强造即时 coupled claim，也不把本轮有限宏接口的失败推广为所有多智能体图特征或学习无效。现阶段应保留主线已有的可验证系统工作，查询线据此形成更具体的价值接口问题，第三线冻结适配器继续作为工程基线；不从本次零增益结果虚构论文性能优势。
