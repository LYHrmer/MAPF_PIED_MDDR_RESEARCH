# R12 根结论：已有时间与预算信号，条件模型尚无新增收益

本轮已完成用户要求的实际学习验证：96次完整TRAIN/CAL策略运行、30个价值头拟合、模型和共同阈值冻结、56次原生TEST部署。152次执行无失败；根独立原始事件审计与导师独立标签、Fraction重拟合和部署审计均通过。实验改变的是查询策略选择，原作者planner和原执行物理层保持冻结。以下结果来自四个独立留出任务family，每族配对B8/B16；不是八个独立样本，也不是完整外部论文benchmark。

表中时间显示精确区间的中点；完整上下界和逐族结果见[配对结果](ROOT_TEST_RESULTS.json)及[结果图](figures/r12_test_comparison.png)。T预先固定为每个机器人前四项FIFO任务的受限完成时间和，未完成记128；全FIFO任务数仍是主指标。查询次数不代表包含推理、维护在内的生产COST。

**学习模型没有新增收益。** 六个TRAIN family的60个非condition任务差标签全为零，15个任务头全零；15个时间头完成了真实拟合。CAL低阈值时full在四格全选WAIT；较高阈值时全选condition。两者均完成166任务，condition的T合计好约0.990654，但多48次查询。预先登记的“任务优先、时间其次、查询数再后”规则选择condition，最终按阈值平局规则选到∞。这不是数值错误、无合法门或测试后改参。

四种学习策略在TEST都选择condition，32次实际推理未改变宏、查询分配或任务服务。因此不能把condition相对WAIT的时间改善归给模型，也不能凭消融结果相同断言历史、预算或时间头没有作用。本轮这些消融被共同∞阈值阻断，没有形成行为归因。

**预算查表出现了值得保留的局部结果。** B16的LD是在TRAIN选定、TEST之前冻结的；四个TEST family均没有任务损失。两个empty family各少2次查询且全部服务记录相同；random122302在同16次查询下T改善区间为[4.072733,4.072811]；另一个random family服务记录也相同。B16汇总T改善区间为[4.072604,4.072940]。这是简单预选宏的留出结果，不是条件价值模型的增益，也不是四族都取得时间改善。B8选择WAIT则在三个family变慢、一个变快，汇总变慢约17.009，不能用B16的正向点掩盖它。

## 从这些结果推进

根判断与[Astra独立判断](ASTRA_POSTEXEC.md)、[科研导师判断](MENTOR_POSTEXEC.md)分别保留，不用多数意见代替数据。根建议保留学习支线，但暂不把当前模型写成论文创新点。已有证据支持继续研究“相同任务完成量下，何时值得花查询、何时应保留预算”，而不是宣称已经学到了吞吐改进。

下一轮的第一问题应是**能否识别时间收益的条件差异**。CAL中WAIT在两个empty条件各慢约19.90，在random两预算分别快约35.85和2.96，当前full低阈值却一律选择WAIT；这说明已有后果异质性没有被当前选择器利用。首门候选逐槽均值丢失状态差异、过早选择导致历史不足，以及六个TRAIN family不足以支持25维多头拟合，都是待检验解释，尚非已确定原因。应先在新family中比较少量有物理含义的状态统计和预算交互，以及同信息的小型线性/树模型；保留condition、WAIT和TRAIN预算查表，不能换成更弱对照来获得正结果。

目标的时间—查询权衡也须事前明确。目前CAL宁愿多48次查询换约0.99的T改善，是既定排序的结果，并非测得的综合经济价值。可在后续设计中报告任务数、T和查询用量的Pareto关系；若要用费用惩罚或允许时间损失上限，参数应来自外部使用要求或主线实测收费，不能用本轮TEST倒调。保持现有四族TEST封存；本轮没有为改善结果追加样本、改宏、调阈值或训练更大模型。

结合Astra的具体建议，根优先下一项可辨识的小实验：把二选一放到首次已用过半预算的合法机会，使用那一时刻的少量公开状态，选择继续condition或执行固定LD后续。两枝在选择前共享完整condition前缀，之后一次选定完整尾策略，避免重新引入标签与部署不一致。固定LD本身必须列作强对照；未到达晚点机会的运行保留。这个方案检验“把选择移到实际预算分配时点，能否识别时间效果”，而不是假定较晚选择一定更好。具体样本、特征和校准规则需另行登记，本轮没有实施这项新实验。

下一次实验应以“新留出中能否胜过简单预算规则”为去留依据。若仍主要复制固定宏，就保留更简单的方法，将模型留作探索记录。B16的小幅正向点提供了继续验证的对象，但规模与收益还不足以单独支撑SCI二区/三区的有效性主张。
