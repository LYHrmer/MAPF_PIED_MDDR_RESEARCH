# 完成导向查询与连续任务服务：有限后继

2026-09-24。新夹具通过 **3488 项检查**，严格编译与原生执行均退出 0。八种策略均在同一人工任务源下完成 9 个任务、12 个 requester 原 MOVE 和全部 END/驻留交接。它把旧的“获准运动、原 MOVE 完成”比较接到了多段任务、真实服务条件和任务续接；没有运行学习器或生产付费服务。

主要发现有两个：完成导向规则只查询 C，即可得到单步准入规则查询 C、A 的同一任务完成曲线；AB 与 C 的累计完成排序则随时刻交替，最终完成量相同。前者是本例中省去冗余查询的机制证据，后者说明不能靠选择某个有利截止来宣称吞吐优势。

## 执行与任务如何接起来

复用未修改的 [合法几何夹具](legal_and_fixture.cpp) 和九个固定主线组件头。A/B/C 阻塞机器人仍沿原轨迹运动，D1/D2/D3 保持稳定 agent 身份。每个 requester 的首个任务目标设在原 MOVE 终点以外一个单位，必须先后完成两条原 MOVE；此后的第二、第三任务在相邻目标间往返，每个任务一条 MOVE。因此中间 MOVE 到达不会计为任务完成。

真正执行由原 ReferenceController 的自主边界推进。新任务只在前一任务服务后补入，世界不重置，未来任务不进入查询预测。每条新 MOVE 都重新建立 occurrence 和 Geometry，检查实际全段责任与外部 owner 互斥，通过 PositionCommit 授权后运行。END 删除旧活动责任，只将终点 mask 保留为 resident；下一 MOVE 等待 native READY 消费与驻留交接。END 自己完成交接，不暗加一次最终 POSITION 查询。

本夹具使用声明的非零误差包络和实际 z=0 见证。服务检查当前已分配且未完成的任务、原 MOVE 静止终点、参考顶点等于任务顶点，以及实际完整方形足迹的四个顶点位于闭服务区域内。服务时刻统一为整数 8 至 16；同一行先判断所有旧任务头，再统一记账与补任务，新任务不能当行再次服务。任务 ID 去重，最终每个 agent 恰好服务三次。

**任务服务不等待中心 READY。** 人工 END 交付延迟统一为 1/4；例如短窗口策略下，D3 在约 7.946152 物理到达，在 8 服务任务，而 END/READY 至约 8.196152 才交付，下一 MOVE 随后启动。代码分别记录物理 END、任务服务、END 责任交接、READY 消费和下一 MOVE，防止把软件知识当成物理服务的必要条件。

此前夹具只关心两次查询窗口。本次所有未查询 blocker 也会在物理结束后正常交付 END（本例为 3.25）。无查询对照因此也能完成全部任务，不以永久保留它们的责任人为制造收益。

## 选择器与公平比较

所有策略共享初态、目标、实际控制、两次可查询机会 2.5/2.75、服务日程与 END 交付规则。原 SRDC/RR 实际调用原 `choose`；SRDC 没有历史实付报价，仍是合法 RR 回退。准入单步/两步保持之前相同的单位成功预测。

新增完成预测只接收已提交关系、当前任务剩余公开路段长度、共同查询机会、当前时间与滚动窗口。名义单段时间为 `sqrt(3L)`，中间 END 交接先验为 1/4，未来服务机会来自公开周期日程。未查询 blocker 的名义 END 也作为正常释放途径参与预测。预测不到安全释放的非退休关系不当作可解除。窗口分别为 6、7；预测接口没有最终评估停止时刻、实际 Controller、未交付证书、未来任务或真实完成时间。

每次查询提交后重新决策，WAIT 是真实可选项。两步搜索穷举本例剩余至多两个机会的不同查询/等待序列；完成数相同时，用更少查询作确定性选择。这只是查询次数指标，不冒充货币、B1 或全服务费用。当前并行请求几何互不相交，执行中任务对候选的常数贡献未放入搜索；不是通用多机器人冲突滚动规划器。

## 对后续研究的含义

当前更合适的目标是查询带来的**边际任务提前价值**，同时考虑不查询也会发生的 END、后续任务与查询成本。完成窗口变化显著影响选择，应先固定评估目标，保留完整累计曲线、任务流时和等待年龄；不能选完结果再挑窗口。待有不同合法执行条件的独立运行后，可将小模型用于越阈证据可用性、END/交付时刻或解析剩余时间的校准，在同一决策器中比较解析与学习预测。无需先证明两步搜索胜出才开始学习数据接口。

本次补上的是有限人工任务服务链。任务知识在服务后同一行瞬时交付，END 与 READY 在同一 native 点折叠；路径手工预定，未接生产 R0 规划或严格后继付费消息。当前没有完整在线成本、正常带历史报价的 SRDC、训练、未知扰动泛化或 lifelong 净吞吐结果。下一轮应扩展合法先验偏差和持续任务条件，并接入主线真实成本，检验这次省去的查询是否仍产生可重复的净收益。
