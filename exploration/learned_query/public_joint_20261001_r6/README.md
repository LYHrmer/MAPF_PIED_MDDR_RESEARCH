# R6 query-value history pilot

[REPORT.md](REPORT.md) contains the result and scope. [RESULTS.json](RESULTS.json), [HELDOUT_RESULTS.csv](HELDOUT_RESULTS.csv), [MODELS.json](MODELS.json), and [TRAIN_CAL_LABELS.json](TRAIN_CAL_LABELS.json) expose every result and the genuinely fitted models.

Six complete16-agent source groups, three FIFO heads each; six train/two calibration/eight heldout error worlds. 64 statistical native arms plus six mechanical arms finished. History improves calibration prediction but has no IID/shift task or closed-loop advantage over nohistory/RR. Its only extra restricted-time improvement is one additional query in an eta0 diagnostic. All eight test worlds eventually deadlock in fixed offline routes; finite terminal residency and lost original global ordering are explicit limitations. No online replanning, standard MAPF/LMAPF benchmark or published external baseline claim.

[CONTRACT.md](CONTRACT.md) fixes source/support and shared components; [STATISTICAL_CONTRACT.md](STATISTICAL_CONTRACT.md) freezes seeds, labels, ridge and heldout evaluation. [EXECUTION_REGISTRATION.json](EXECUTION_REGISTRATION.json) binds scientific source/code/binary/input hashes. [MODEL_FEATURE_SCHEMA.json](MODEL_FEATURE_SCHEMA.json) gives current-head/END-only/age/survival features. Known9:1 law is equally disclosed; same architecture nohistory zeros the eight historical slots. The compiled actor reads no actual eta, progress, future task or offline frame.

[prepare_support.py](prepare_support.py) independently reconstructs SUPPORT from the frozen R5 author200 source. [mechanical_culling.py](mechanical_culling.py) builds the exact original shared native components and runs fixed8/16-agent mechanical cases. [pipeline.py](pipeline.py) performs all WAIT-prefix/singlequery continuations, true ridge training, model freeze and native heldout closed loop with12 independent processes. These scripts reject conflicting outputs and preserve original receipts; their registered directories are frozen, so new research uses a separate successor directory.

[AUDIT_ALL.json](AUDIT_ALL.json), [MODEL_AUDIT.json](MODEL_AUDIT.json), and [NEGATIVE_CONTROLS.json](NEGATIVE_CONTROLS.json) cover all70 actual runs, independent continuous motion/masks/owners/normalEND/current-head features/rational selection, exact ridge refit and malformed-causal-input rejection. [GEOMETRY_CULLING_PROOF.md](GEOMETRY_CULLING_PROOF.md), [GEOMETRY_DIFFERENTIAL_RECEIPT.json](GEOMETRY_DIFFERENTIAL_RECEIPT.json), and [GEOMETRY_CULLING_PREFIX.json](GEOMETRY_CULLING_PREFIX.json) justify the equivalent spatial resource filter; full-map inputs and old300s timeouts stay intact.

Lossless RAW_R6_*.tar.gz archives contain complete input/raw/receipt/compiled-native identities, old attempts and full offline registration. [RAW_ARCHIVE_MANIFEST.json](RAW_ARCHIVE_MANIFEST.json) gives every uncompressed file hash; [ARCHIVE_VERIFIED.json](ARCHIVE_VERIFIED.json) confirms all members round-trip. Original raw files remain local for root review. Restore archives with `rtk proxy tar -xzf <archive>`; replay an arm using the exact four native command arguments in [NATIVE_RECEIPT.json](NATIVE_RECEIPT.json), with the archived native ELF or the compile receipt/unchanged production pins. Required FLINT host SDK and frozen source inputs are shared with earlier packages. Direct commands start with `rtk proxy`. Cache and individually duplicated raw logs are excluded from publication.

[PUBLICATION_MEMBERS.json](PUBLICATION_MEMBERS.json) is the exact top-level publication list. [FROZEN_MANIFEST.json](FROZEN_MANIFEST.json) also binds all retained local files. Old R5/R5b432/76 files and nine production headers are unchanged.
