# 当前总体研究决定

2026-10-18，两线决定。此文是唯一当前总体计划，覆盖旧空间接口方案、分支README和历史交接中的选题约束。两线都保持`CANDIDATE_TOPIC`：方向范围已确定，独立算法增量尚未成立。本轮按research-mentor的选题与方法适配要求做针对性判断，不重开全面审查。

## 共同核心与范围

共同核心是已有合法MAPF方案的路径质量与总计算预算。SCI优先在标准离散模型中形成可检验的方法；大论文引用同一优化器，先考察运动适配，再考察空间误差对可行性、等待和收益的影响。传统章可以先使用名义模型，v2不是SCI前置条件。两线共享必要输入协议、完整成本和失败语义，不强求共用全部历史实现。

目标是2026年形成SCI稿件；以纯仿真支撑主要结论。GNN、监督学习、RL均为工具候选，不预设任何一种优于规则。LIMO非前置条件，不升级系统、购置设备或采集大量实物训练数据。

## SCI：有限总计算预算下的路径质量改善

**候选问题：** 给定一个合法的多机器人路径方案，如何在有限总计算预算内进一步改善路径质量？减少无收益修复、复用搜索信息、分配计算资源均为候选办法，由强基线后的诊断决定，暂不锁定“减少无效搜索”或“学习跳过SIPP”。首版采用标准四邻域、单位离散步成本、顶点/对向边冲突和永久终点驻留；局部修复时邻域外路径固定。

**实现主干明确为ADDRESS。** 以成熟论文的完整邻域生成、在线学习和修复循环为起点，优先交付一项针对性机制改进；BALANCE提供轻量在线资源选择参考，TACKLE约束种子选择的新颖性，确需神经表示时再考虑NNS。ADDRESS已是传统搜索与在线学习结合，不为体现学习另搭深度RL系统。

具体源码线索来自ADDRESS固定提交`b3d35c431ce03834f95e834d87986f2f341394a1`的PP修复。该调用点逐车累计已规划成本，尚未将剩余车辆静态最短路下界纳入接续预算。它支持一个可实现差异，**不证明该开销已经是实际主要瓶颈**。

设旧邻域整数成本为C，已修复前缀成本为g，未修复车辆最短路下界为h。严格改善要求总成本≤C−1。若`g+sum(h)>C−1`，终止当前前缀的修复；下一车j的允许成本为`C−1−g−sum(h_except_j)`。该经典下界先作为增强传统对照，不单独认定SCI贡献。它只排除当前优先顺序和前缀下的改善，不证明所有顺序均无解。静态距离缓存与低层求解由各臂共享，费用计入完整尝试。

已交付修复预算、完整终态、固定顺序宿主、共同离散validator及未修改的作者SIPP回调。第一批8车六臂证据固定`c0bd134`：原控制共48次搜索，增强臂根节点全部拒绝，最终完整计划一致；三个初解SOC均等于同模型静态最短路和。保留经典界作为后继所有方法共有的强基线，停止将该搜索减少作为独立贡献、停止零余量任务上的学习。

用户随后明确回复“授权继续”，第二批16/32车六任务已完成，证据固定SCI`535ee1a`，许可已消费。共197次实际SIPP搜索、17次当前cap/固定前缀下穷尽、3次接受，maze16/32的局部组分别改善SOC 1/2步，random32的全体逆序改善1步；另外三任务达到同模型下界、无改善。它们是既有传统策略的完整功能结果，支持继续诊断，但不是独立性能样本或新算法优势。完整ADDRESS自适应LNS未复现。有限cap空返回仍依赖作者SIPP语义，不是本项目独立完备性证明。

### 下一机制候选：有限预算的后段失败恢复

在保留ADDRESS邻域生成及外层搜索的条件下，检查组内PP失败后能否调整少量顺序、可靠保留一部分已算路径，获得完整改善。离线记录失败车辆、失败位置、当前cap、已完成前缀及旧路径受到的时空限制。旧17次失败只来自固定ID组和剩余下界cap宿主，不能直接声称完整ADDRESS已有同样瓶颈；132次先返回路径也不证明可挽救。新离线核验为13/17处于后半段，7项旧路径无新前缀冲突但超cap、10项旧路径在cap内而被新前缀阻挡；三种情况分开讨论，不把所有失败都归于顺序阻塞。

候选只做有限个局部顺序调整，保留未受影响前缀，重算受影响后缀；复用路径必须仍满足新的约束和成本条件，失败、未知或截止时返回已有完整合法解。对照直接放弃、相同预算的随机重排及公平适配的优先级搜索；同时报告诊断/复用验证/重算/最终全检费用。具体定位规则与次数上限由离线诊断固定在SCI报告中，未经新授权不运行比较。

原生ADDRESS实际runPP没有旧探针的剩余h cap，恢复触发和收益判断必须按其真实实现重新适配。正常空返回的位置标签、成本截断、起点阻塞和截止分开；SIPP本身无内部时钟，准备后/搜索后均须检查原绝对期限。共享诊断的abandon只能作机制对照；完整成本还须对照不强加恢复诊断开销的根界增强ADDRESS。额外搜索会改变后续随机流，不能假称端到端邻域序列相同。当前原生恢复扩展仍无科学结果。

回退和优先级搜索均已有基础。待验证差异只能落在调整位置定位、可复用计算的条件或完整预算下的有效收益；若简单规则/既有搜索已做到，停止该具体机制。只有“回退哪里、尝试多久”存在跨任务稳定且规则难利用的信息，才引入一种轻量学习。

## 硕士论文：局部修复收益如何进入运动执行

条件式组织为共同问题与基座、传统方法及仿真、确有必要的学习辅助、运动与误差验证。学习不预先承诺独立RL章节；是否形成三个独立创新点取决于导师要求与实际结果。传统部分须有自己的方法或分析，系统部分至少回答适用条件或性能问题，不能以平台截图替代。学校/导师对章数与创新点的具体要求尚未核定，不把参考论文当规定。

师兄林威《复杂环境下多智能体系统的有效覆盖控制》（2024）是区域覆盖、未知目标覆盖两项研究，再接平台验证，没有独立学习章。其外部相机/ArUco定位条件也不同于当前LIMO。仅借鉴“问题—方法—仿真”逐章闭合和系统验证结构。

**已有交付（硕士`6771137`）：** 冻结DEV日志的离线轨迹对齐导出器，产生262条同刻记录及10条接受且送达END支持的完成记录；属于已有证据再导出，无新实验。按车与采集时刻关联参考、真值、定位、控制、公开状态和送达时间；区分跟踪偏差、定位偏差、通信送达滞后与轨迹时间偏差。没有独立真值的实物记录相应列为空，不以定位减参考冒充真实跟踪误差。不从采样轨迹推出连续安全或硬界。

**新增实质交付（硕士`32db58f`）：** `inspect_sci_paths.py`通过14个固定Git对象消费SCI`535ee1a`的六份输入/输出/收据，输出完整运动结构分解，没有复制优化器或进行新搜索。maze16/32与random32的SOC分别减少1/2/1步，内部方向转动量却增加11/18/108个四分之一圈；计入任意共同首末朝向后，方向序列的转动增量仍分别在[8,14]、[16,20]、[80,136]。其余三任务变化为0。该几何结论只适用车头沿格边移动、方向变化采用最短旋转的解释，不是物理时长或连续安全结果。

**具体候选问题：** 哪些离散路径改善能转化为声明运动模型下的收益，空间误差又会改变哪些约束？先解析等成本改路与转向增加，比较保留原路径和转向感知等简单选择规则；等成本改路可能为其他车让路，任何替换都必须重新检查完整多车方案，不能逐车恢复旧路径就认定合法。

**当前实现（硕士`aea4ffa`）：** 旧六任务已按等成本改路/变长/变短分解；random32的29条等成本改路合计增加113个四分之一圈，另外两条路径净减少5个，最终净增108。作者SIPP未以朝向/转向为目标和状态，这是核查线索，尚非逐次选路的因果证明。`plan_selection.py`已实现SOC、保留等成本原路径、转向感知三种整方案选择：混合候选一次性做全车冲突与终点驻留检查，非法则拒绝整案；没有逐车恢复后直接接受。当前仅完成软件核验，未做新的任务比较，也不是转向最优搜索器。代码固定引用SCI`535ee1a`的原验证器。

原v2必要资格也已离线筛查：若统一尺度且每条格边映射一个原MOVE，仓库地图任务的最大相对位移与原MOVE最短长度无法同时满足原v2条件；maze/random仅留下必要尺度区间，不代表控制、车身净空和绝对坐标等条件通过。不静默扩大8m位移域或改变原语，先完成无误差运动适配，再明确选择适用任务或另行建立来源条件。详见[硕士诊断](https://github.com/LYHrmer/MAPF_PIED_MDDR_RESEARCH/blob/aea4ffad2dfdf59a163436a21ee35c0f7b75c333/tracks/thesis/PATH_DIAGNOSTIC.md)。

2. **空间误差扩展。** 在无误差流程成立后，对同一允许初态集合比较固定外包与传播外包，保持运动模型、反馈信息和调度器一致。明确是哪一处扩大占用导致新增等待、路径/顺序不可行，及原收益保留多少。无差异就保留适用性分析，不把接入模型本身算作创新。

误差工作分三类分别报告：①误差处理算法（需方法差异）；②误差敏感性分析（相同算法改变已声明条件，不冒称新算法）；③实物可执行性（命令/反馈/END等系统闭环，不证明误差硬界）。首版优先复用v2，但逐条核对新路径的地图尺度、坐标/相对位移、动作、速度和停等条件。每车同一初始位置与朝向参数贯穿全任务、跨动作保持关联，不逐段重置；真实与参考须同实际输入并同步暂停/恢复/切换、等待无漂移。它仅支持初始位姿不确定性引起的运动偏差，不覆盖滑移、持续输入偏差或闭环纠偏。确需持续扰动时只选一种明确来源和控制模型重新传播，不同时叠加多种噪声。

两台Ubuntu18 LIMO只有自身定位/里程计，不能用作独立真值或真实误差上界核心校准。首版主要证据由明确声明的仿真模型支撑，实物可选且不阻塞SCI。
