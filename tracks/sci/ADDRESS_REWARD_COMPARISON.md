# ADDRESS 学习反馈：旧日志诊断与下一项比较

2026-10-22。候选问题收紧为：给定完整合法初解，在有限总计算时间内分配局部重规划机会，使最终保留的完整方案更好。主要目标仍是 SOC；makespan 单列，不能把更多修复或更多成功事件当作任务改善。本轮没有新的 ADDRESS 科学运行。

## 旧日志已经说明什么

[可复算派生产物](derived/reward_feedback_diagnosis.json)由 [reward_analysis.py](reward_analysis.py)读取四份已完成日志，先核对原收据中的字节数/SHA、逐调用记录与完整任务成本，再重算奖励谓词。原文件未修改。

| 原批次/任务 | 修复次数 | 正的回滚前差额、但实际提交为零 | 实际 SOC 改善 |
|---|---:|---|---:|
| attempt trace / maze s01 n32 | 16 | 第5、16次 | 7 |
| phase profile / 同一 maze 任务 | 16 | 第5、16次 | 7 |
| attempt trace / random s01 n32 | 5 | 无 | 0 |
| phase profile / 同一 random 任务 | 4 | 无 | 0 |

迷宫第5次只返回1/6条新路径，随后正常空返回；第16次返回3/8条后空返回。作者 PP 循环此时的 `old_sum_of_costs - sum_of_costs` 分别为368、392，最终均回滚、实际收益为零。固定作者 `b3d35c4` 的 `src/LNS.cpp:518–528` 在回滚前以这一差额是否为正更新 Bernoulli 参数，因而**部分前缀的正差额不等于完整候选改善**。旧日志没有逐次 seed ID/后验快照，本次只重建该谓词，不能据此量化被污染的具体臂、后续选择或最终质量损失。

其余成本停止不能一概称为错误正奖励：trace 批的17次成本停止均已返回整组路径，其中9次等成本、8次变差，正谓词均为假；旧日志仍没有新的联合候选校验凭据。两次真实提交改善分别为2和5步，二元反馈均记作成功，说明它丢失改善幅度，但不证明幅度奖励更好。上述四份日志只有两个任务；同一迷宫的同种子轨迹重复不能当作跨任务稳定证据。没有观察到预算截尾的这几条修复记录也不能证明截尾语义无关。

复算命令（输出必须使用新文件名，不覆盖既有派生产物）：

```bash
rtk proxy python3 -B tracks/sci/reward_analysis.py --legacy-output /tmp/address_reward_diagnosis_review.json
```

## 本轮实质实现

已有 C++ 奖励事务、源代码 overlay 和二进制保持原样；[共同运行器](run_address_adapter.py)现在接通 `reward_contract`，要求明确三模式协议和固定构建来源。每次选择必须且只能结算一行；外部核对 selection/repair ID、完整候选与部分前缀、SOC 连续账本、截尾、未选中种子、逐种子窗口与原生汇总。实际收益之和必须等于初始 SOC 减最终完整 SOC，记录不能靠自报 `SUCCESS` 通过。旧科学清单及其源文件版本仍按原提交保留，当前代码不伪装成旧 SHA。

日志核对和序列化都在总准入预算内。修复次数 trace 与细分 phase profile 关闭，三臂均开启同样的 reward trace/完整候选检查；总费用覆盖初始化、筛选、构组、搜索、回滚、候选/最终校验、输出及工件哈希。选择区间和日志 I/O 是其中的嵌套项，不能相加到总时间上。原奖励臂也承担这套共同检查，因此称“共同适配的作者奖励对照”，不称未修改的作者性能复现。

[现有离线汇总器](repair_profile.py)已接入奖励账本和预定配对差值；被外层杀死而缺终态 JSON 的任务计入失败，后续项记为未运行，保留部分日志，未知费用不补造。软件夹具覆盖重复/遗漏结算、部分候选假奖励、截尾记零、错误提交、逐种子窗口、缺终态失败和停批分母；这些不是新 MAPF 性能结果。

## 只做两个差异判断

| 模式 | 学习使用的反馈 | 记忆 |
|---|---|---|
| author | 固定作者原回滚前更新；新账本旁路审计实际提交 | 原累计 |
| cumulative | 每次已选种子、未截尾的完整结算，`1[实际提交SOC收益>0]` | 累计，Beta先验(1,1) |
| window | 与 cumulative 完全相同 | 每个种子最近16次合格结算，先验仍为(1,1) |

author→cumulative 比较的是**结算语义整体**，同时涉及回滚前谓词、空构组和截尾处理，不把结果单独归因于某一个字段。cumulative→window 才只改变记忆长度。普通失败/空构组属于零收益；截尾单列且不进后两模式的学习记忆，但其成本不能删除。排除截尾不能自动得到无偏成功率估计。author 模式中 arms 汇总是实际提交的旁路审计，不是其真实后验参数。

所有模式都用 positive_delay 初始种子规则，零延迟车仍可作为邻域成员；top-k等于车辆数，邻域上限8，PP/SIPP与缓存、随机源、初解、预算完全一致。相同种子不保证相同邻域序列。W=16是未调参的先验选择；本批不加入幅度/费用奖励、邻域大小学习或神经网络。

ADDRESS已有种子学习，BALANCE已有幅度反馈，TACKLE已有规则/反事实学习和候选变化处理，DyMAB已有近期窗口。三模式是针对性对照，**不作为新算法贡献**；论文/source细节复用[已有近邻核对](REFERENCE_REPRODUCTION.md)，不重开全面综述。

## 未参与本轮规则设计的任务与决定

已按任务ID预选 maze/random 两地图各 scenario4/n16、scenario5/n32，均来自原R18 test分区，完整初解及原DATA_FREEZE已核。它们与s01设计任务分开；不是新地图、未触碰过的全新数据或四种地图布局。每个场景只取一个规模，避免16/32嵌套前缀计为独立任务，但规模与场景混杂，不能单独估计拥堵/规模效应。三个求解器种子只是各任务内重复。

[有限清单](ADDRESS_REWARD_CHECKLIST.md)固定4任务×3种子×3模式，共36项；全部未运行。主要报告每任务/种子的最终完整SOC配对差值，附makespan、全部费用、失败/截尾和修复数。四任务是小规模迁移核验，不据此作显著性/泛化或SCI创新成立结论。

若两项配对仅增加修复次数，或最终质量没有稳定方向，停止该奖励/窗口候选，不调W、不追加种子挑正例。只有多个任务在同预算下改善最终SOC，并能解释退化、截尾和费用，才扩大独立场景；届时只针对仍存在的决策瓶颈选一项增量。费用归一化奖励和剩余预算策略保持未实现，后段恢复继续停止。
